## 1. 这个面板现在负责什么

`参数回测` 面板只做一件事：  
围绕多周期动量、MACD、权重和交易阈值，跑历史快照回测，在指定的优化目标下，找出当前样本区间内更优的参数组合。

它不再负责：

- 盘中校验
- 验收验证
- 方向分组
- 交易复盘
- 诊断实验

## 2. 使用顺序

建议按下面顺序操作：

1. 先选 `快照类型`
2. 再选 `开始日期 / 结束日期`
3. 调整基础参数
4. 调整 `优化设置`
5. 先点一次 `运行回测`
6. 再点 `参数扫描` 或 `贝叶斯优化`
7. 在结果页里看“哪组参数在当前目标下排第一”

## 3. 面板上新增的 3 类可选项

### 3.1 优化目标

现在面板支持 4 种优化目标：

- `综合最优`
  - 按 `Score` 排序
  - 适合希望同时兼顾收益、回撤、稳定性时使用
- `胜率优先`
  - 优先看 `winRate`
  - 同时兼顾交易数和收益，避免只做 1 笔交易就 100% 胜率的误导
- `收益优先`
  - 优先看 `totalReturn`
  - 同时参考胜率和回撤
- `赚钱效应优先`
  - 优先看 `Expectancy(R)`
  - 适合你更关注“单笔交易平均赚钱质量”时使用

### 3.2 尝试组数

这个值决定优化时会尝试多少组参数。

- `参数扫描`
  - 对应 `maxCombinations`
  - 组数越大，尝试越多，耗时越长
- `贝叶斯优化`
  - 对应 `nIterations`
  - 组数越大，局部搜索轮数越多，耗时越长

建议：

- 快速试水：`12 ~ 16`
- 正常筛选：`24 ~ 32`
- 更细的搜索：`48+`

### 3.3 参数范围

面板上的“参数范围”决定优化器允许搜索的上下边界。  
当前开放给面板可调的是这些范围：

- 入场置信度
- 最大入场排名
- 最少支持信号数
- 止损
- 止盈
- 最大持有 bars
- `MACD Fast`
- `MACD Slow`
- `MACD Signal`

理解方式很简单：

- 你在主参数区填的是“当前基线参数”
- 你在优化区填的是“优化器允许在什么范围内搜索”

## 4. 两个优化按钮分别做什么

### 4.1 参数扫描

`参数扫描` 是离散组合扫描。

它会从你设置的范围里取代表点，然后组合成候选参数，再逐组回测。

当前实现采用的方式是：

- 每个范围通常取 `最小值 / 中间值 / 最大值`
- 再组合出候选参数
- 最后按你选定的“优化目标”排序

适合：

- 你想看清楚不同参数点之间的大致差别
- 你想做一个比较直观的粗筛

### 4.2 贝叶斯优化

当前按钮名仍叫 `贝叶斯优化`，但实现上更接近：

- “基于当前参数的局部迭代搜索”

它不是严格意义上的高斯过程贝叶斯优化。  
它现在的工作方式是：

1. 第 1 轮先用你当前参数跑一次
2. 后面每一轮都基于“当前最优参数”做小步调整
3. 每轮回测后，按你设置的目标更新当前最优解
4. 跑完后，把所有候选结果按目标排序

适合：

- 你已经有一组大致可用参数
- 想在这组参数附近继续细调

## 5. 结果页怎么看

结果页里最重要的是这几项：

- `排序目标`
  - 表明这次是按什么标准排的
- `尝试 N 组`
  - 表明这次一共测了多少组参数
- 第 1 行
  - 表示在“本轮候选参数里”排第 1 的参数组
  - 不是全宇宙最优，只是这次搜索里最优

如果你当前目的是“找胜率最高的参数”，那就应该：

1. 把优化目标切到 `胜率优先`
2. 再看结果表的第 1 行
3. 再顺手看：
   - 交易数
   - 总收益
   - Expectancy(R)

不要只盯着 100% 胜率，要确认交易数不是太小。

## 6. 当前写死在代码里的默认搜索规则

下面这些规则是当前代码里的默认实现。

### 6.1 默认优化目标

如果你不选，默认是：

- `综合最优`

对应代码：

- `src/services/ParameterOptimizer.ts`
- `resolveOptimizationGoal()`

### 6.2 默认尝试组数

- `参数扫描`
  - 默认 `24` 组
- `贝叶斯优化`
  - 默认 `13` 组

对应代码：

- `gridSearch()` 里的 `maxCombinations ?? 24`
- `bayesianOptimization()` 里的 `nIterations ?? 13`

### 6.3 默认搜索范围

如果你不改面板里的搜索范围，系统会按“当前参数附近”生成默认范围：

- 入场置信度：`当前值 - 6` 到 `当前值 + 10`
- 最大入场排名：`当前值 - 20` 到 `当前值 + 20`
- 最少支持信号数：`1 ~ 4`
- 止损：`当前值 - 2` 到 `当前值 + 2`
- 止盈：`当前值 - 4` 到 `当前值 + 4`
- 最大持有：`当前值 - 8` 到 `当前值 + 8`
- `MACD Fast`：`当前值 - 3` 到 `当前值 + 3`
- `MACD Slow`：`当前值 - 6` 到 `当前值 + 6`
- `MACD Signal`：`当前值 - 3` 到 `当前值 + 3`

并且会被系统限制在合法边界内，例如：

- `entryConfidenceThreshold` 只能在 `50 ~ 95`
- `maxEntryRank` 只能在 `10 ~ 80`
- `macdFast` 只能在 `4 ~ 30`
- `macdSlow` 只能在 `8 ~ 60`
- `macdSignal` 只能在 `3 ~ 24`

### 6.4 参数扫描的候选生成规则

当前 `参数扫描` 会对这些参数做组合：

- 入场置信度
- 最大入场排名
- 最少支持信号数
- 最大持有 bars
- `MACD Fast`
- `MACD Slow`
- `MACD Signal`
- 强共振开关

每个数值范围通常会取：

- 最小值
- 中间值
- 最大值

然后组成候选参数池，最后截取你指定的尝试组数。

### 6.5 局部优化的单步扰动规则

当前 `贝叶斯优化` 每一轮在当前最优参数附近做如下小步调整：

- 入场置信度：每轮 `±2`
- 最大入场排名：每轮 `±5`
- 最少支持信号数：每轮 `±1`
- 止损：每轮 `±0.5`
- 止盈：每轮 `±0.5`
- 最大持有 bars：每轮 `±2`
- 买入阈值：每轮 `±0.02`
- 卖出阈值：每轮 `±0.02`
- `MACD Fast`：每轮 `±1`
- `MACD Slow`：每轮 `±2`
- `MACD Signal`：每轮 `±1`
- 四类权重：每轮 `±0.03`

## 7. Score 是怎么来的

`综合最优` 用到的 `Score` 不是单一指标。  
当前代码会综合这些因素：

- 总收益
- 最大回撤
- Sharpe
- ProfitFactor
- Expectancy(R)
- 交易数稳定性

所以：

- 胜率最高，不一定 `Score` 最高
- 收益最高，也不一定 `Score` 最高

如果你的目标非常明确，比如只想冲胜率，就不要用 `综合最优`，直接切到 `胜率优先`。

## 8. 推荐用法

### 8.1 想找胜率最高的参数

建议这样做：

1. 先手动设一组基础参数
2. 优化目标选 `胜率优先`
3. 尝试组数先设 `24`
4. 把 `MACD Fast/Slow/Signal` 范围设窄一点
5. 跑一次 `贝叶斯优化`
6. 看第 1 行结果，再继续缩小范围做第二轮

### 8.2 想找综合更稳的参数

建议这样做：

1. 优化目标选 `综合最优`
2. 先跑 `参数扫描`
3. 找到一组较好的基线
4. 再用 `贝叶斯优化` 在附近做细调

## 9. 当前局限

当前实现还有这些边界：

- `贝叶斯优化` 名称保留了，但实现是局部搜索，不是严格数学上的标准贝叶斯优化
- 范围开放的参数还不是全部参数
- 权重范围目前还没有放到面板上单独配置
- 第 1 名只代表“本轮候选中的第一名”，不是全局最优
