# 异动精灵 L1 异动规则口径

本文记录桌面版 `tools/YiDongJingLing` 当前所有异动类型的判断和计算逻辑。规则入口在 `tools/YiDongJingLing/Events/L1EventEngine.cs`，默认阈值在 `L1EventRules.cs`，GUI 可配置项在 `SettingsForm.cs` 和 `MainForm.ApplyEventRuleSettings`。

## 通用口径

- 数据源：`python-bridge` WebSocket 的 L1 行情和标准五档盘口。
- 只在连续竞价时段触发普通盘中异动；首次行情和非连续竞价时段只建立基线。
- 金额单位：行情 `amount` 为元；五档挂单金额按 `价格 * 手数 * 100` 估算。
- 同一只股票同一批行情可能命中多个规则，最终会经过 `EventDeduper`。除“竞价弱转强”外，同股同批通常只保留最高优先级事件。
- 同股同类默认冷却 180 秒；打开涨跌停、即将打开涨跌停、竞价弱转强冷却 30 秒。
- 启动或切换股票池时会清空行情状态、规则状态和去重状态，避免旧池信号混入新池。

## 涨跌停限制

`ResolveLimitPct` 按代码和名称粗判涨跌幅限制：

| 股票范围 | 判断 | 限制 |
|---|---|---:|
| ST / *ST / 名称含 ST | 名称包含 `ST` | 5% |
| 创业板 | 代码 `30` 开头 | 20% |
| 科创板 | 代码 `68` 开头 | 20% |
| 北交所 | 代码 `8` 或 `4` 开头 | 30% |
| 其他 | 默认 | 10% |

涨停价和跌停价均用昨收价乘限制幅度后四舍五入到 2 位小数。当前没有单独处理新股上市前几日、临停、退市整理等特殊制度。

## 规则明细

| 异动类型 | 触发逻辑 | 阈值来源 |
|---|---|---|
| 封涨停板 | 最新价到达涨停价，买一价到达涨停价且买一量大于 0；上一状态不是封涨停。 | 涨跌停限制 |
| 打开涨停板 | 上一状态为封涨停，本次不再满足封涨停。 | 涨跌停限制 |
| 即将打开涨停 | 本次和上一状态都封涨停，当前买一封单金额明显走弱。走弱条件为：当前封单小于近 10 秒高点或上一帧的 35%，或当前封单金额不高于 500 万，或买一量不高于 1 万手。 | `UpcomingOpenWindow=10s`、`UpcomingOpenSealWeakRatio=0.35`、`UpcomingOpenMinSealAmount=500万`、`UpcomingOpenMinSealVolume=1万手` |
| 逼近涨停 | 未封涨停，当前涨幅在涨停幅度下方 1% 以内。 | `NearLimitDistancePct=1.0` |
| 封跌停板 | 最新价到达跌停价，卖一价到达跌停价且卖一量大于 0；上一状态不是封跌停。 | 涨跌停限制 |
| 打开跌停板 | 上一状态为封跌停，本次不再满足封跌停。 | 涨跌停限制 |
| 即将打开跌停 | 本次和上一状态都封跌停，当前卖一封单金额明显走弱。走弱条件与即将打开涨停对称。 | 同“即将打开涨停” |
| 逼近跌停 | 未封跌停，当前跌幅在跌停幅度上方 1% 以内。 | `NearLimitDistancePct=1.0` |
| 封单增强 | 涨停看买一封单，跌停看卖一封单；当前封单金额达到上一帧封单金额的 1.5 倍。 | `SealIncreaseRatio=1.5` |
| 封单变弱 | 涨停看买一封单，跌停看卖一封单；当前封单金额降至上一帧封单金额的 0.5 倍或以下。 | `SealWeakRatio=0.5` |
| 大幅拉升 | 当前当日涨幅跨过涨幅阈值，且这只股票此前未触发过同一或更高涨幅档。GUI 当前将多档覆盖为单一“涨幅突破 %”。 | 设置页“涨幅突破 %”，默认 7% |
| 大幅跳水 | 当前当日跌幅跨过跌幅阈值，且这只股票此前未触发过同一或更高跌幅档。 | 设置页“跌幅突破 %”，默认 7% |
| 快速拉升 | 本地历史计算 30 秒、60 秒、5 分钟价格变化，任一窗口达到上行阈值即触发。 | 30 秒 2%、60 秒 3%、设置页“5分钟涨跌 %”默认 5% |
| 快速跳水 | 本地历史计算 30 秒、60 秒、5 分钟价格变化，任一窗口达到下行阈值即触发。 | 30 秒 -2%、60 秒 -3%、设置页“5分钟涨跌 %”对应负值，默认 -5% |
| 竞价弱转强 | `09:20:00-09:20:30` 保存不可撤单初始基线，`09:24:00` 附近保存临门基线，`09:24:50-09:25:10` 保存确定基线；`09:25:00-09:29:59` 量价齐升先给候选观察，`09:30:00-09:35:00` 结合开盘承接判断。强播核心看 `09:20->09:25` 价格抬升、成交额相对放大、`09:24->09:25` 临门确认和未高位回落；`09:25` 最终涨幅不要求翻红，固定成交额、前弱上下文、支撑跌破、无量价核心等只影响风险和评分。股票池只决定监听范围，不自动注入前日弱势分数。V7 将控制拆为三层：(1) 硬阻断 — 6 类（事件开关、静音、冷却、时间窗口、基线缺失、价格无效）；(2) 风险标签 — 覆盖率低、画像缺失、价量未确认等只标记不静音；(3) 语音控制 — dryRun（仅时间戳不可信或用户显式演练）、preopen_candidate 候选不播。 | `OpeningWeakToStrongRules` 固定规则 |
| 低开长阳 | `openGapPct=(open-preClose)/preClose*100` 小于等于负的开盘跳空阈值，且 `bodyPct=(lastPrice-open)/open*100` 大于等于长阳长阴阈值。 | 设置页“开盘跳空 %”默认 1%；“长阳长阴 %”默认 4% |
| 高开长阴 | `openGapPct` 大于等于开盘跳空阈值，且 `bodyPct` 小于等于负的长阳长阴阈值。 | 同“低开长阳” |
| 翻红 | 上一帧涨跌幅小于等于 0，本帧涨跌幅大于 0。 | 无额外阈值 |
| 翻绿 | 上一帧涨跌幅大于等于 0，本帧涨跌幅小于 0。 | 无额外阈值 |
| 创日内新高 | 当前最新价高于工具启动或切池后的最高价。 | 本地状态 |
| 创日内新低 | 当前最新价低于工具启动或切池后的最低价。 | 本地状态 |
| 成交额跨档 | 当前累计成交额跨过成交额门槛，且此前未触发过同一或更高金额档。GUI 当前将默认多档覆盖为单一“成交额 万”。 | 设置页“成交额 万”，默认 10000 万即 1 亿 |
| 成交增量加速 | 最近 30 秒成交量增量达到前 30-60 秒成交量增量的 2 倍；两个窗口各至少有 2 条行情，且前段增量大于 0。当前使用 `Volume`，不是成交额。 | `VolumeAccelerationRatio=2.0` |
| 出现大买挂盘 | 买一价和买一量有效，买一挂单金额大于等于门槛。 | 设置页“挂单额 万”，默认 1000 万 |
| 出现大卖挂盘 | 卖一价和卖一量有效，卖一挂单金额大于等于门槛。 | 设置页“挂单额 万”，默认 1000 万 |
| 盘口买压增强 | 五档买量和五档卖量都大于 0，五档买量达到五档卖量的 2.5 倍。 | `PressureRatio=2.5` |
| 盘口卖压增强 | 五档买量和五档卖量都大于 0，五档卖量达到五档买量的 2.5 倍。 | `PressureRatio=2.5` |
| 买卖价差异常 | 买一价、卖一价、最新价有效，`(卖一价-买一价)/最新价*100` 大于等于 1%。 | `SpreadPct=1.0` |

## 设置页注解

设置窗左侧“异动类型”列表现在在事件名后追加简要注解，例如“封涨停板 - 涨停价+买一封单”。注解只影响显示，不参与保存；配置仍按 `L1EventType.ToString()` 存储，兼容既有设置文件。
