# 异动精灵 V2 使用说明

## 启动

双击 `tools\YiDongJingLing\publish\win-x64\YiDongJingLing.exe`。软件启动后会自动尝试启动并连接本地行情桥。

## 监控板块

点击顶部“加载板块”，选择通达信 `T0002\blocknew` 下的一个或多个 `.blk` 文件。也可以在“监控板块”页选择目录、扫描、勾选板块后点击“加载选中”。

“监控板块”页的“股票池来源”支持二选一：

- `TDX自选股`：读取通达信 `T0002\blocknew` 下已勾选的 `.blk` 文件。
- `八平台热榜`：从本地代理 `http://127.0.0.1:3000` 拉取东方财富、同花顺、开盘啦、通达信、雪球、财联社、淘股吧、大智慧热榜，合并后订阅行情桥。代理未运行时会尝试自动启动 `proxy-server`。

切换股票池来源后会清空当前列表基线并重新订阅行情桥。

## 盯盘状态

异动列表最多显示 100 条。底部状态栏显示监控数量、行情桥状态、记录数、今日累计、最近行情时间、交易时段和语音模式。

非连续竞价时段只建立行情基线，不触发静态行情异动。

## 即将开板预警

当前版本按 L1 五档盘口计算开板预警，直接把买一/卖一作为封单数据使用：

- 即将打开涨停：买一价为涨停价时，买一量按封单量处理；封单金额在 5-10 秒内明显下降，或封单量/封单金额低于阈值时触发。五档数量按通达信常见“手”换算为股。
- 打开涨停板：最新价低于涨停价，或买一不再为涨停价时触发。
- 即将打开跌停：卖一价为跌停价时，卖一量按封单量处理；封单金额在 5-10 秒内明显下降，或封单量/封单金额低于阈值时触发。五档数量按通达信常见“手”换算为股。
- 打开跌停板：最新价高于跌停价，或卖一不再为跌停价时触发。

这里的盘口封单口径来自 L1 可见五档，不代表真 L2 十档、逐笔委托或完整队列。

## 竞价弱转强

当前版本新增早盘“竞价弱转强”信号：

- `09:24:50-09:25:10`：行情桥对当前订阅池强制广播采样元数据，桌面版和网页版记录 `09:25` 附近最后可见价。
- `09:30:00-09:35:00`：检测价格是否从竞价偏弱快速上移，并结合成交额、距涨停距离和形态族评分。
- 当股票池来源为 `TDX自选股` 时，已加载 `.blk` 候选股会作为前日弱势上下文参与 `strong_open_board_attempt` 判断；八平台热榜不会自动获得该上下文。
- 命中后类型显示“竞价弱转强”，桌面表格使用专属高亮，Dragon Board 主表名称旁显示“竞强”徽标并行级高亮。
- 桌面版和网页版都会把信号上报本地代理 `/api/opening-signals`，由代理返回 `voiceOwner`，避免两端重复语音。

该功能仍使用 L1 行情，不代表真 L2 十档、逐笔委托或完整集合竞价队列。第一轮早盘建议在 `09:20` 前启动行情桥和工具，盘后重点检查 `09:25` 基线覆盖率、`09:30-09:35` 首次触发延迟和是否重复播报。

## 语音模式

设置页可以选择：

- 只播强信号：默认模式，弱盘口信号只进列表不播报。
- 播报全部：所有启用事件都参与播报。
- 静音：只显示列表，不播报。

## 异动参数

设置页“异动参数”区域支持调整从 TDX 行情桥迁移来的雷达规则：

- 涨幅突破 / 跌幅突破：使用行情桥 `changePct`，达到阈值后分别触发“大幅拉升”“大幅跳水”。
- 5分钟涨跌：使用本地 5 分钟价格历史，扩展“快速拉升”“快速跳水”。
- 成交额：使用行情桥 `amount`，达到门限后触发“成交额跨档”。
- 挂单额：使用买一/卖一价格和数量计算，达到门限后触发“出现大买挂盘”“出现大卖挂盘”。
- 开盘跳空 / 长阳长阴：使用 `open`、`preClose`、`lastPrice` 推导“低开长阳”“高开长阴”。

自由流通股占比、分时线金叉/死叉、单笔大成交等依赖额外股本数据或稳定逐笔数据的规则，当前版本没有迁移。

## 同步消息

设置页勾选“同步消息”后，桌面版捕获到新的异动会复用网页版“异动雷达”的飞书机器人通道，把消息提交到本地代理 `http://127.0.0.1:3000/api/notifications/event-radar/events`。代理未运行时会尝试自动启动。

该功能使用 `proxy-server\.env.local` 中已有的飞书配置：

- `FEISHU_EVENT_RADAR_ENABLED=true`
- `FEISHU_EVENT_RADAR_WEBHOOK=...`
- `FEISHU_EVENT_RADAR_SECRET=...`

飞书发送仍遵守代理端的冷却和批量窗口配置，例如 `FEISHU_EVENT_RADAR_COOLDOWN_MS`、`FEISHU_EVENT_RADAR_BATCH_WINDOW_MS`。如果代理或飞书配置不可用，桌面版只会在诊断日志记录失败，不影响行情监控和语音播报。

窗口置顶开关已取消。旧配置里即使保存过置顶，新版本启动和保存设置时也会忽略。

## 托盘

最小化窗口会进入系统托盘。托盘菜单支持显示窗口、静音/恢复、退出。关闭窗口会退出软件并断开行情桥。

## 导出

异动页底部“导出记录”支持带表头的 CSV 或制表符文本，字段顺序与列表一致。
