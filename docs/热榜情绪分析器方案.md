# 热榜情绪分析器方案

## Summary

新增一个独立的 `HotListSentimentAnalyzer`，作为 `DragonBreathAnalyzer` 的补充，不替代它。  
当前已统一情绪周期标准，热榜情绪和龙息情绪都以 `src/types/emotion.ts` 为唯一阶段入口。
定位：

```text
DragonBreathAnalyzer = 全市场情绪宽度
HotListSentimentAnalyzer = 热榜池交易情绪
RankTrend 状态 = 个股处理类型
```

三者观察对象不同，但情绪阶段语言一致：

```text
冰点 / 启动 / 发酵 / 高潮 / 退潮
```

热榜情绪不再用拍脑袋权重打总分，而采用“市场宽度经典指标 + 热榜状态结构 + 三日对比”的规则型阶段判断。

参考依据：
- TRIN/Arms Index 用“上涨/下跌家数”和“上涨/下跌成交量”判断资金是否流向上涨股票，公式为 `(Adv/Dec)/(AdvVol/DecVol)`，低于 1 偏强，高于 1 偏弱。参考 StockCharts: https://chartschool.stockcharts.com/table-of-contents/market-indicators/arms-index-trin
- Zweig Breadth Thrust 用 `上涨家数 / (上涨家数 + 下跌家数)` 的 10 日 EMA 判断广度推升，经典阈值是从 40% 以下推到 61.5% 以上。参考 TrendSpider: https://trendspider.com/learning-center/zweig-breadth-thrust/
- New High/New Low 属于宽度尾部指标，用于判断极端强弱扩散。参考 SDK Trading: https://sdk-trading.com/en/trading-knowledge/indicators/breadth/new-highs-new-lows/

本项目不照搬美股 10 日参数，第一版按 A 股热榜池做三日对比。

## Key Changes

- 情绪阶段统一固定为 5 类：
  - `冰点`
  - `启动`
  - `发酵`
  - `高潮`
  - `退潮`

- 阶段定义统一由 `src/types/emotion.ts` 提供：
  - `DragonBreathAnalyzer` 不再维护旧阶段。
  - `HotListSentimentAnalyzer` 不再维护本地阶段配置。
  - 不保留 `低迷期 / 震荡期 / 平稳期 / 活跃期` 旧阶段兼容。

- 新增三日对比口径：
  - `T`：当前热榜池
  - `T-1`：昨日日级快照
  - `T-2`：前日日级快照
  - 重点看热榜池数量、前100留榜率、状态迁移、资金承接变化、昨日强票今日表现。

- 不采用固定权重总分作为核心判断。
  - 输出可以有 `confidence`，但阶段来自规则证据。
  - 阶段主方向优先由盘面强度、成交承接、机会扩散决定。
  - 风险压力和持续性不直接决定阶段，只决定风险等级和警示。
  - 只有风险压力被弱盘面或弱承接确认时，才允许覆盖为 `退潮`。
  - 每个阶段输出命中的证据列表，而不是只给一个分数。
  - 龙息侧的 `overall`、情绪指数、因子分只作为温度和证据展示，不再作为唯一阶段判定来源。

## Core Metrics

第一版计算这些指标：

```ts
interface HotListSentimentResult {
  stage: '冰点' | '启动' | '发酵' | '高潮' | '退潮'
  riskLevel: '低' | '中' | '高'
  confidence: number
  summary: string
  metrics: HotListSentimentMetrics
  signals: string[]
  warnings: string[]
}
```

核心指标分组：

1. 热榜宽度
   - 当前热榜池数量
   - 前100上涨/下跌家数
   - 前100上涨比例
   - 热榜池数量相对昨日、前日变化

2. 热榜 TRIN
   - `hotTrin = (上涨家数 / 下跌家数) / (上涨成交额 / 下跌成交额)`
   - `hotTrin < 1`：上涨股票获得更多成交额承接
   - `hotTrin > 1`：上涨家数存在，但成交额承接不足

3. 状态结构
   - `主升确认 / 点火观察 / 强资确认 / 新入观察 / 高位拥挤 / 资金背离 / 转弱预警 / 样本不足` 数量与占比
   - 前20、前50、前100分别统计
   - 前20代表核心前排，前50代表主线扩散，前100代表热榜池交易宽度
   - `强资确认 + 点火观察` 代表有效机会扩散
   - `资金背离 + 转弱预警` 代表风险压力
   - `高位拥挤` 代表热度强但追击赔率下降

4. 三日持续性
   - 今日前100中昨日仍在榜数量
   - 今日前100中前日仍在榜数量
   - 昨日强资确认今日留榜率
   - 昨日强票今日平均涨幅、正收益率、转弱率
   - 昨日高位拥挤今日转弱/背离比例
   - 今日新入前100数量
   - 今日新入且强资确认数量

5. 龙头/涨停补充
   - 涨停数、连板数、炸板数、昨日涨停表现只作为第二版补充证据。
   - 补充口径必须限制在热榜池内，例如当前热榜前100、昨日热榜强票、昨日热榜涨停票。
   - 不直接把全市场所有涨停、连板、炸板数据纳入热榜情绪阶段，否则会把全市场宽度噪音混进热榜池交易情绪。
   - 全市场涨停、连板、炸板仍由 `DragonBreathAnalyzer` 负责，热榜情绪只使用其与热榜池交集后的结果。

## Layered Metrics

当前热榜情绪面板展示三层结构：

```text
前20：核心前排
前50：主线扩散
前100：交易宽度
```

每层展示：

- 上涨比例
- `主升确认 + 点火观察 + 强资确认` 的有效机会数量与占比
- `高位拥挤` 数量与占比
- `资金背离 + 转弱预警` 的风险数量与占比
- 热榜 TRIN
- 平均涨幅

分层统计的作用是避免只看前100导致信号被摊薄：

- 前20强、前100弱：通常是核心票抱团，扩散不足。
- 前20强、前50强、前100改善：更接近发酵或高潮。
- 前20拥挤高、前50风险升：追击赔率开始下降。
- 前100风险高：热榜交易质量恶化，优先防守。

## Yesterday Strong Performance

“昨日强票”定义为昨日热榜前100中处于以下状态的标的：

```text
主升确认 / 点火观察 / 强资确认
```

不把 `高位拥挤` 算作昨日强票，因为高位拥挤已经包含赔率下降和兑现风险，应单独观察其风险迁移。

昨日强票今日表现统计：

- `count`：昨日强票数量
- `matchedCount`：今日仍在热榜池中的数量
- `retainedTop100Count`：今日仍在热榜前100中的数量
- `avgChange`：今日仍在热榜池中的平均涨幅
- `positiveRate`：今日仍在热榜池中的正收益率
- `weakeningRate`：转弱率，包含掉出热榜池、今日跌幅较大、今日状态变成 `资金背离 / 转弱预警`

该指标用于回答：

```text
昨天被资金和注意力确认过的票，今天是否继续被市场承接？
```

如果昨日强票正收益率高、转弱率低，说明热榜情绪具备持续性；如果昨日强票大量掉榜或转弱，即使当前热榜池数量扩张，也要警惕质量恶化。

## Stage Evidence Rules

阶段判断采用证据组合，不使用固定权重总分，也不允许单一风险字段直接决定阶段。

核心修正：

```text
风险压力不是退潮本身。
情绪阶段回答“现在处于哪个交易周期”，风险等级回答“这个周期里能不能追、要不要降仓”。
风险压力只有被弱盘面或弱成交承接确认后，才构成退潮。
```

热榜情绪先计算 5 组证据，并拆成两类：

```text
阶段主证据 = 盘面强度 + 成交承接 + 机会扩散
风险修正证据 = 风险压力 + 持续性
```

阶段主证据决定 `冰点 / 启动 / 发酵 / 高潮 / 退潮` 的主方向；风险修正证据决定 `riskLevel` 和风险提示。  
这可以避免“前100上涨 60%、TRIN 0.64、强资+点火仍在扩散”的盘面，仅因为风险压力高或昨日强票失败就被直接打成 `退潮`。

最终输出应表达为：

```text
阶段 + 风险等级
```

例如：

```text
发酵 + 高风险
高潮 + 中风险
启动 + 中风险
退潮 + 高风险
```

### Evidence Groups

热榜情绪计算 5 组证据：

1. 盘面强度 `tapeStrength`
   - 回答：热榜是不是还在涨，涨的是前排还是全局？
   - 输入：
     - 前20上涨比例
     - 前50上涨比例
     - 前100上涨比例
     - 前100平均涨幅
     - 高涨幅数量
     - 近涨停数量
   - 判定：
     - `strong`：前20 >= 65%，前50 >= 55%，前100 >= 55%。
     - `firm`：前20 >= 60%，前100 >= 48%。
     - `weak`：前100 <= 42%，或前20、前50同时偏弱。
     - 其余为 `mixed`。

2. 成交承接 `moneyAcceptance`
   - 回答：上涨有没有成交额支持？
   - 输入：
     - 热榜 TRIN
     - 上涨成交额
     - 下跌成交额
   - 判定：
     - `strong`：`hotTrin < 1`。
     - `weak`：`hotTrin > 1.15`。
     - `neutral`：其余有效值。
     - `unknown`：样本不足。

3. 机会扩散 `opportunityExpansion`
   - 回答：可处理机会是不是在扩散？
   - 输入：
     - `主升确认 + 点火观察 + 强资确认` 占比
     - `强资确认` 占比
     - 有效机会占比较昨日变化
     - 新入前100数量
     - 新入强资数量
   - 判定：
     - `broad`：有效机会 >= 18%，且强资确认 >= 8%。
     - `improving`：有效机会较昨日提升 >= 4%，或新入前100 >= 25。
     - `scarce`：有效机会 < 8%。
     - 其余为 `normal`。

4. 风险压力 `riskPressure`
   - 回答：拥挤、背离、转弱是否在扩散？
   - 输入：
     - `资金背离 + 转弱预警` 占比
     - `高位拥挤` 占比
     - 风险占比较昨日变化
     - 拥挤占比较昨日变化
     - 昨日高位拥挤今日转弱/背离数量
   - 判定：
     - `severe`：风险压力 >= 35%。
     - `high`：风险压力 >= 20%，或风险占比较昨日提升 >= 4%。
     - `crowded`：高位拥挤 >= 18%，或拥挤占比较昨日提升 >= 4%。
     - 其余为 `low`。
   - 注意：
     - `high/severe` 只是风险证据，不直接等于 `退潮`。
     - 如果盘面强度、成交承接、机会扩散仍强，风险压力应解释为当前阶段的风险等级，而不是直接覆盖阶段。
     - 高风险可以出现在 `启动 / 发酵 / 高潮` 中，面板需要显式展示为 `阶段 + 高风险`。

5. 持续性 `continuity`
   - 回答：昨日强票今天有没有继续被承接？
   - 输入：
     - 昨日强资确认留榜率
     - 昨日强票今日正收益率
     - 昨日强票今日转弱率
     - 前100留榜率
   - 判定：
     - `strong`：昨日强票正收益率 >= 60%，或昨日强资确认留榜率 >= 60%。
     - `weak`：昨日强票转弱率 >= 45%，或昨日强资确认留榜率 <= 25%。
     - `normal`：其余。
   - 注意：
     - `continuity = weak` 表示昨日强票承接不佳，是风险修正证据。
     - 只有当持续性转弱同时被盘面走弱或成交承接走弱确认时，才覆盖为 `退潮`。
     - 如果今日盘面强度和成交承接仍强，持续性转弱应提高 `riskLevel`，而不是直接改变阶段主方向。

### Risk Level Resolution

风险等级独立于阶段计算：

```text
低风险：风险压力 low，持续性 normal/strong。
中风险：风险压力 crowded/high，或持续性 weak。
高风险：风险压力 severe，或风险压力 high 且持续性 weak。
```

风险等级用于解释同一阶段中的交易质量：

- `发酵 + 低/中风险`：扩散健康，适合按主线节奏观察。
- `发酵 + 高风险`：扩散仍在，但分歧和兑现压力高，只能按精选和仓位控制处理。
- `高潮 + 中/高风险`：强度足够，但追击赔率明显下降。
- `启动 + 高风险`：新方向出现，但承接分化严重，确认要求更高。

### Stage Resolution

阶段判定顺序：

```text
1. 退潮弱确认
2. 高潮
3. 发酵
4. 启动
5. 冰点
```

阶段判定只使用阶段主证据作为核心，风险修正证据只在 `退潮弱确认` 和 `riskLevel` 中生效。

#### 退潮

`退潮` 必须满足“风险压力 + 弱盘面/弱承接确认”，不能只靠风险占比或昨日强票失败触发。

满足以下任一组合：

- 风险压力为 `high/severe`，且盘面强度为 `weak`。
- 风险压力为 `high/severe`，且成交承接为 `weak`。
- 风险压力为 `severe`，持续性为 `weak`，且前100上涨比例 < 52%。
- 风险压力为 `severe`，热榜池收缩，且机会扩散为 `scarce/normal`，同时成交承接不强。
- 热榜池收缩，机会扩散 `scarce`，且前100上涨比例 < 50%。

解释：

```text
风险已经被价格、成交或持续性确认，交易从机会优先切换为防守优先。
```

反例：

```text
前20/前50/前100上涨结构仍强，TRIN < 1，上涨成交承接占优，即使风险压力高，也不能直接判退潮。
这类盘面应落在 发酵/高潮 + 高风险。
```

#### 高潮

`高潮` 不是无风险，而是强度足够高，同时追击赔率下降。

满足以下任一组合：

- 盘面强度 `strong`，成交承接不弱，且近涨停数量明显增加。
- 盘面强度 `strong`，成交承接 `strong`，有效机会扩散已经达到 `broad`，且高位拥挤显著。
- 近涨停数量较多，高位拥挤明显，且强资/点火仍保持扩散。
- 高涨幅数量和高换手数量同时放大，说明热榜进入高热交易区。

但 `高潮` 必须排除以下情况：

- 机会扩散不充分，仅靠高位拥挤和风险压力不能判高潮。
- 强度集中在极少数前排，前50/前100扩散不足时，更接近 `启动` 或 `发酵 + 高风险`。

解释：

```text
热榜仍强，但交易进入高热区域，适合持仓管理，不适合情绪追击。
```

#### 发酵

`发酵` 强调健康扩散，而不是高位冲刺。

满足：

- 机会扩散为 `broad`；或有效机会 >= 12%、强资确认 >= 8%，且成交承接为 `strong`。
- 盘面强度至少为 `firm`。
- 成交承接不弱。

解释：

```text
热榜机会从前排向中段扩散，成交承接仍在，是进攻阶段。
如果风险压力或昨日强票表现不佳，则展示为 发酵 + 高风险，而不是直接改成退潮。
```

#### 启动

`启动` 强调改善开始出现，但尚未全面扩散。

满足：

- 热榜池扩张，或机会扩散 `improving`，或新入前100明显增加。
- 前100上涨比例 >= 42%。
- 成交承接不弱。

解释：

```text
热榜开始出现新方向和资金尝试，但持续性仍需后续快照和次日验证。
如果风险压力偏高，则展示为 启动 + 中/高风险。
```

#### 冰点

无法满足以上阶段，且表现出弱机会、弱承接或弱扩散时，归为 `冰点`。

典型组合：

- 机会扩散 `scarce`。
- 盘面强度 `weak`。
- 热榜池收缩。
- 昨日强票持续性弱。

解释：

```text
热榜缺少可持续承接，等待新方向或风险释放完成。
```

- 新增 `src/services/hotlist/HotListSentimentAnalyzer.ts`
  - 输入当前 stocks、昨日 daily snapshot、前日 daily snapshot。
  - 复用 `getRankTrendDisplayStatus()` 生成状态分布。
  - 复用 `src/types/emotion.ts` 的阶段配置和阶段摘要。
  - 输出 `HotListSentimentResult`。

- 新增测试：
  - 强扩散但高拥挤 -> `高潮`
  - 强资确认增加、背离低 -> `发酵`
  - 新入/点火增加、风险下降 -> `启动`
  - 背离/转弱增加、昨日强票失败 -> `退潮`
  - 热榜收缩、强资少 -> `冰点`
  - 前20、前50、前100分层统计正确输出
  - 昨日强票今日平均涨幅、正收益率、转弱率正确输出

- UI 第一版只展示：
  - 阶段
  - 结论摘要
  - 前20 / 前50 / 前100 分层结构

  - 昨日强票今日表现：平均涨幅、正收益率、转弱率
  - 热榜 TRIN
