# 热榜情绪分析器方案

## Summary

新增一个独立的 `HotListSentimentAnalyzer`，作为 `DragonBreathAnalyzer` 的补充，不替代它。  
当前已统一情绪周期标准，热榜情绪和龙息情绪都以 `src/types/emotion.ts` 为唯一阶段入口。
定位：

```text
DragonBreathAnalyzer = 全市场情绪宽度
HotListSentimentAnalyzer = 热榜池交易情绪
RankTrend 状态 = 个股处理类型
```

三者观察对象不同，但情绪阶段语言一致：

```text
冰点 / 启动 / 发酵 / 高潮 / 退潮
```

热榜情绪不再用拍脑袋权重打总分，而采用“市场宽度经典指标 + 热榜状态结构 + 三日对比”的规则型阶段判断。

参考依据：
- TRIN/Arms Index 用“上涨/下跌家数”和“上涨/下跌成交量”判断资金是否流向上涨股票，公式为 `(Adv/Dec)/(AdvVol/DecVol)`，低于 1 偏强，高于 1 偏弱。参考 StockCharts: https://chartschool.stockcharts.com/table-of-contents/market-indicators/arms-index-trin
- Zweig Breadth Thrust 用 `上涨家数 / (上涨家数 + 下跌家数)` 的 10 日 EMA 判断广度推升，经典阈值是从 40% 以下推到 61.5% 以上。参考 TrendSpider: https://trendspider.com/learning-center/zweig-breadth-thrust/
- New High/New Low 属于宽度尾部指标，用于判断极端强弱扩散。参考 SDK Trading: https://sdk-trading.com/en/trading-knowledge/indicators/breadth/new-highs-new-lows/

本项目不照搬美股 10 日参数，第一版按 A 股热榜池做三日对比。

## Key Changes

- 情绪阶段统一固定为 5 类：
  - `冰点`
  - `启动`
  - `发酵`
  - `高潮`
  - `退潮`

- 阶段定义统一由 `src/types/emotion.ts` 提供：
  - `DragonBreathAnalyzer` 不再维护旧阶段。
  - `HotListSentimentAnalyzer` 不再维护本地阶段配置。
  - 不保留 `低迷期 / 震荡期 / 平稳期 / 活跃期` 旧阶段兼容。

- 新增三日对比口径：
  - `T`：当前热榜池
  - `T-1`：昨日日级快照
  - `T-2`：前日日级快照
  - 重点看热榜池数量、前100留榜率、状态迁移、资金承接变化、昨日强票今日表现。

- 不采用固定权重总分作为核心判断。
  - 输出可以有 `confidence`，但阶段来自规则证据。
  - 规则优先级：风险退潮 > 高潮拥挤 > 发酵 > 启动 > 冰点。
  - 每个阶段输出命中的证据列表，而不是只给一个分数。
  - 龙息侧的 `overall`、情绪指数、因子分只作为温度和证据展示，不再作为唯一阶段判定来源。

## Core Metrics

第一版计算这些指标：

```ts
interface HotListSentimentResult {
  stage: '冰点' | '启动' | '发酵' | '高潮' | '退潮'
  confidence: number
  summary: string
  metrics: HotListSentimentMetrics
  signals: string[]
  warnings: string[]
}
```

核心指标分组：

1. 热榜宽度
   - 当前热榜池数量
   - 前100上涨/下跌家数
   - 前100上涨比例
   - 热榜池数量相对昨日、前日变化

2. 热榜 TRIN
   - `hotTrin = (上涨家数 / 下跌家数) / (上涨成交额 / 下跌成交额)`
   - `hotTrin < 1`：上涨股票获得更多成交额承接
   - `hotTrin > 1`：上涨家数存在，但成交额承接不足

3. 状态结构
   - `主升确认 / 点火观察 / 强资确认 / 新入观察 / 高位拥挤 / 资金背离 / 转弱预警 / 样本不足` 数量与占比
   - 前20、前50、前100分别统计
   - `强资确认 + 点火观察` 代表有效机会扩散
   - `资金背离 + 转弱预警` 代表风险压力
   - `高位拥挤` 代表热度强但追击赔率下降

4. 三日持续性
   - 今日前100中昨日仍在榜数量
   - 今日前100中前日仍在榜数量
   - 昨日强资确认今日留榜率
   - 昨日高位拥挤今日转弱/背离比例
   - 今日新入前100数量
   - 今日新入且强资确认数量

5. 龙头/涨停补充
   - 涨停数、连板数、炸板数，如果现有字段可取则纳入第一版，否则第二版。
   - 昨日涨停今日平均涨幅、正收益比例、转弱比例。
   - 这些指标只作为热榜情绪补充，不覆盖 RankTrend 状态。

## Stage Rules

阶段判断采用规则证据，不做拍脑袋权重。

- `冰点`
  - 热榜池数量连续收缩，或前100上涨比例明显低。
  - `强资确认 + 点火观察` 很少。
  - `资金背离 + 转弱预警` 占比高。
  - 昨日强票留榜率低。

- `启动`
  - 热榜池数量较昨日扩张。
  - 前100上涨比例改善。
  - `新入观察 / 点火观察 / 强资确认` 增加。
  - `资金背离 / 转弱预警` 下降。
  - `hotTrin < 1` 优先确认启动质量。

- `发酵`
  - `强资确认` 明显增加。
  - 前50资金净流入和超大单承接较好。
  - 昨日强票今日留榜率较高。
  - 题材集中度适中，有主线但未严重拥挤。

- `高潮`
  - 前20、前50大量涨停或高涨幅。
  - `高位拥挤` 明显增加，但 `资金背离 / 转弱预警` 尚未失控。
  - 成交额和换手率显著放大。
  - 适合解释为“强但不宜追”。

- `退潮`
  - `资金背离 + 转弱预警` 快速上升。
  - 昨日强资确认、高位拥挤票今日大量转弱。
  - 前100上涨比例下降，`hotTrin > 1`。
  - 热榜池数量收缩或扩张但质量恶化。

## Implementation Plan

第一版：

- 新增 `src/services/hotlist/HotListSentimentAnalyzer.ts`
  - 输入当前 stocks、昨日 daily snapshot、前日 daily snapshot。
  - 复用 `getRankTrendDisplayStatus()` 生成状态分布。
  - 复用 `src/types/emotion.ts` 的阶段配置和阶段摘要。
  - 输出 `HotListSentimentResult`。

- 新增测试：
  - 强扩散但高拥挤 -> `高潮`
  - 强资确认增加、背离低 -> `发酵`
  - 新入/点火增加、风险下降 -> `启动`
  - 背离/转弱增加、昨日强票失败 -> `退潮`
  - 热榜收缩、强资少 -> `冰点`

- UI 第一版只展示：
  - 阶段
  - 结论摘要
  - 前100状态分布
  - 三日对比：热榜池数量、前100留榜率、强资确认、拥挤、背离、转弱
  - 热榜 TRIN

第二版：

- 接入龙息已有的涨停、连板、炸板、昨日涨停今日表现。
- 接入题材集中度：
  - 主线题材占比
  - 前100题材扩散数量
  - 题材 HHI 或 Top3 集中度
- 做阶段变化趋势图：
  - T-2 -> T-1 -> T
  - 状态迁移矩阵
  - 昨日强票今日表现列表

## Assumptions

- 日级快照可以取到前两日热榜池数据。
- `DragonBreathAnalyzer` 和 `HotListSentimentAnalyzer` 已统一五阶段语言。
- 第一版不使用固定加权总分决定阶段。
- 如果涨停、连板、炸板字段在当前数据层不稳定，先放第二版。
- 阶段解释优先服务交易理解，不作为自动买卖信号。
