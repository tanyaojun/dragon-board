# 独立热榜情绪面板——设计提案（Step 2，待用户确认后实施）

- 日期：2026-09-24
- 前置：`01-口径梳理.md`（后端热榜池全部展示口径）
- 视觉基线：`SectorDetail.vue` 一类项目详情面板——**主题 CSS 变量**（`--bg-primary/--bg-header/--bg-secondary/--color-highlight` 等，随应用亮暗主题）、Teleport 浮层、`panel-header + tabs-left + panel-content` 结构；**不继承** DragonBreathPanel 的写死金融暗色渐变风格

## 1. 定位与边界

- 新面板 `HotlistEmotionPanel.vue`（建议 `src/components/panels/`），与 DragonBreathPanel **完全脱钩**：独立浮层组件、独立数据加载（直接复用 `hotlistSentimentApi.ts` 两个薄 client）、独立样式（主题变量）。
- 只展示热榜池口径（01 文档 §1-§9）；ThemeTrend 共振解释、marketData 顶部行情、龙息因子等一律不进。
- DragonBreathPanel 的「热榜情绪」页签在新面板验证 OK 后删除（其入口按钮改为打开新面板）。

## 3. 交互与状态

- 数据加载：挂载即拉 `series(3)` + `slots`，沿用现有降级语义（缺失日逐日标注、slots degraded 提示、旧文档 `--` 占位）；轮询/刷新按钮手动触发（不自动轮询，与旧面板一致）。
- 页签记忆：`view` ref 默认 `overview`；面板关闭即销毁。
- 入口：DragonBreathPanel 顶部工具区按钮「热榜情绪」改为打开新面板（Teleport 浮层，Escape/✕ 关闭）。

## 4. 风格规范（对齐 SectorDetail）

- 容器：`Teleport to body` + `position: fixed` 浮层、主题变量背景、圆角/边框同 `--border-color`。
- 字体：全局默认字体栈，数字等宽处用现有 `--font-mono`（如项目已有变量，否则跟随现状）。
- 颜色：全部走主题变量；涨/跌/警示用项目通用红绿/橙（同 SectorDetail 的 rgba 色块模式），**不引入** DragonBreath 的紫色渐变与发光标题。
- 五态词配色沿用全局阶段色（如已有 `stage-*` 全局类则复用，否则面板内定义主题变量版）。
