- **单位裁决**：16/16 股尾条 `zt_tur` 与池封单差 ≤19 元（封单时点漂移），无任何 ×100/×10000
  形态。`tur` 与 `zt_tur` 同单位由 rate 公式互证（下）；`buy/sell_tur` 为同消息 uint64 金额族
  + 与池 main_net 量级一致（若 ×100/×10000 则 buy−sell 达百亿/千亿级、远超成交额，排除）。
- **time 裁决**：全样本 3-4 位（如 941=09:41、1500=15:00），0 条越出交易时段、0 条落午休
  空洞（1131-1259 无值）、items 时序单调；首条时间与池 `zt_time` 封板时刻对齐——一字板
  （002076/002160/002209，09:25 集合竞价封）首条=09:30，其余首条=封板后首个整分。
- **rate 裁决**：`rate = tur / zt_tur × 100` 在 2905/2905 条可判 items 上精确成立（容差
  0.02 或 1e-4 相对），含极端样本 001282 首条 tur=66044910 / zt=22116 → rate=298629.53%
  （数值不可能巧合）。rate 是派生比率且**已是百分数尺度**，透出不换算。
- **buy/sell 语义**：16/16 股全 items 单调不减（逐分钟值不可能 16/16 单调）→ 累计口径；
  尾条 = 当日累计封板大单买/卖额。`buy−sell` 与池 main_net 同数量级但非精确相等（000678
  甚至符号相反）——main_net 是全天全价位主力净额，buy/sell 是封板大单口径，窗口不同属预期。

### 自洽校验

- 尾条 zt_tur ≈ 池封单（16/16，差 ≤19 元 = 采集/池快照时点漂移）✓
- rate = tur/zt×100（2905/2905）✓
- buy/sell 单调（16/16）；buy−sell 与 main_net 量级一致 ✓

### 口径注（消费纪律）

1. **raw sum 聚合禁止消费**：items 内 `zt_tur` 是「该分钟封单额」级值、`buy/sell_tur` 是
   「当日累计」，sum 无意义（如 000026 zt-sum=225.7亿 ≠ 封单 5195万）。采集层 raw sum 字段
   仅审计保留（历史日档向后兼容），展示/消费一律取**尾条最新态**：新日档用采集侧派生
   `zt_tur_yuan/buy_tur_yuan/sell_tur_yuan`（协议层 `bdo_aggregate_last` 单一出口）；
   历史日档无派生字段时叙事回退 items 尾条 raw ÷ `BDO_TUR_DIVISOR`（同一常量源）。
2. **tur 业务语义待 App 同屏复核**：tur 是逐分钟级值、与封单同单位，且作为 rate 分子
   （tur/zt×100）；具体含义（封单大单额/封单相关大单指标）未与 App 页面逐列核对，不渲染
   不判读（落库备审计）。
3. **time_text 已派生落库**（"HH:MM"），raw=0（proto3 缺省与缺位不可分）→ None 不伪造。
4. 001339 智微智能仅 11 条：封板分钟数少（盘中反复开板）属正常形态，非丢帧。
5. 2030 的 2014 式同屏核对未做（App 详情页封板大单列名未逐列核对）；本裁决以
   「池封单精确互证 + 帧内自洽」为准，App 同屏核对列为后续加强项。

## 二、2030 阴性记录（未钉死，等下一交易日被动复验）

2026-11-11 收盘日档 abn_items 16 只（全部当日异动事件）：

- `price` 非零 **0/16**、`next_day_price` 非零 **0/16**、`next_day_zf` 可读 **0/16**；
- `date` 集合 = {2026-11-11}（=日档日期）；11/16 只昨日（11-10）不在涨停池（当日新异动股）。

判读：

1. **date = 异动日**：当日事件推送只带 stockId+date；「次日字段全缺位」与之自洽（当日事件
   无次日数据）。若 date 是次日语义，price（异动日收盘价）应已落值——实测全缺位，排除。
2. **zf 比率/百分比与 price 族缩放无法裁决**：无一个非空对照样本。旧叙事把 raw next_day_zf
   直接按百分数渲染（`+X.XX%`）——若上游是比率即伪精度，故本轮**异动提醒行整行暂停渲染**
   （fail-visible，raw 仍随 abn_items 落库；AMMO 2026-11-11b）。
3. **K3 探针帧不可复用**：午前探针矩阵日志（`.tmp_review/kpl_probe_K3_20261111.log`）的
   S 帧为会话加密载荷，探针进程密钥态已失，离线不可解密（已确认放弃该路径）。

### 复验路径（被动，不新开火）

- detail 订阅在生产持续运行（`KPL_STOCK_DETAIL_SUBS=1`），下一交易日日档自然新增样本。
- 复验脚本模式（只读日档）：拉当日 `abn_items`，筛 `price/next_day_price/next_day_zf`
  任一非空样本 → ① `(next_day_price − price)/price` vs `next_day_zf` 判比率（×100）或
  百分比（原样）；② price 候选除数 {1, 100, 10000} 对照池 quotas price + 合理带 1~500 元；
  ③ date 语义复证（历史异动事件的 date 应早于日档日期）。
- 裁决门槛同本轮：≥3 只非空 items 且全样本一致 → 钉死 `ABN_PRICE_DIVISOR`/zf 口径标志 +
  解析器追加 `price_yuan/next_day_price_yuan/next_day_zf_pct` 派生字段 + 异动提醒行按钉死
  口径恢复渲染（同轮同步 docs/测试，§1.2-5）；仍无样本 → 继续阴性等待。
- 若复验发现推送只回当日事件（next* 永远缺位）→ 该口径在 socket 通道永久阴性，记 docs
  （App 侧应由 HTTP 历史源承载，届时另行立项）。
