# 东财 push2 主力资金数据源:风控调研与节流参数定稿

> 2026-09-30。题材主力资金(theme_fund)切换东财 `eastmoney_main` 后盘中数据缺失的
> 复盘与社区实战调研结论。调参前必读,不要凭直觉改频率参数。

## 背景

题材主力资金(约 5500 只 A 股)默认源为东财 push2 `ulist.np` 批量接口
(`backend/market_proxy/eastmoney_fund_provider.py`)。东财 push2 系有 IP 级风控,
本文件记录社区/一手实测的风控机制与本项目定稿参数。

## 社区实测风控阈值(a-stock-data 项目,10.4k 星,SKILL「东财风控阈值(社区实测, 2026-05)」)

| 行为 | 触发封禁的阈值 | 风险 |
|------|---------------|------|
| 每秒请求数 | > 5 次/秒 | 高 |
| 单 IP 并发连接 | >= 10 | 高 |
| 1 分钟请求总数 | >= 200 次 | 中高 |
| 5 分钟请求总数 | >= 300 次 | 触发封禁 |
| User-Agent | 空 UA / 无浏览器特征 | 中 |

一手封禁案例(该项目 issue #36,2026-06-30):10 线程并发、1 小时 45000+ 请求 →
push2/push2his 全系列 `RemoteDisconnected`,**IP 级封禁持续 20+ 小时**。
社区安全线:串行 + 1s 间隔 + 随机抖动(QPS <= 2),批量任务进一步调大间隔。

其他一手经验:

- **防封铁律**(a-stock-data「数据源优先级 & 东财防封」):
  1. 串行,不并发;
  2. 每次间隔 >= 1s + 随机抖动,批量调大到 1.5~2s;
  3. **复用 HTTP 会话(Keep-Alive),不要每次新建连接**(连接重建频率本身是风控指纹);
  4. 带正常 UA + Referer;
  5. 批量循环不 sleep 是被封头号元凶。
- **不同子域不同 WAF**:`datacenter-web` 被封不影响 `push2`,反之亦然。
- **部分大陆住宅 IP 被东财间歇风控**(HTTP 000/空响应),非代码 Bug——盘中偶发断连
  有东财侧成分,应对是长冷却等解封,不是加密重试。
- akshare `stock_individual_fund_flow_rank`(push2 clist 100 条/页 x 53 页)无间隔连发
  会触发 WAF `RemoteDisconnected`——历史已验证,本项目禁用该路径。

## 本项目教训(2026-09-30 盘中事故)

- 第一版参数 300 只/批 x 18 批 x 1.5s 间隔(复用 keep-alive 连接):盘中约 4 批后被
  push2 断连,调度器 300s 冷却到期即重试、反复触发风控,全天只零星攒到 3301/约 5500 行
  (题材分析器资金缺失 40%),IP 进入临时黑名单(50 只单请求也被断)。
- 教训:**东财语境下压力 ∝ 请求次数,与每批大小几乎无关**。分批是 URL 长度上限
  (约 8KB ≈ 800 只)逼出来的,不是减压手段;减压靠批间距与轮间隔。
- 短冷却(300s)到期重试会反复刺激 WAF,恶化封禁。

## 定稿参数(全部 env 可调)

| 参数 | 值 | 论证 |
|------|-----|------|
| 批大小 | 800 只/请求 | URL ≈ 6.9KB 贴近 nginx 8KB 上限;全市场 7 批,请求数最少 |
| 批间距 | 60s + 15% 随机抖动 | 任意 1 分钟窗口最多 1 个请求(阈值的 0.5%);抖动防精确节拍指纹 |
| 轮间隔 | 1800s(30 分钟) | 轮内约 6 分钟完成、其余静默;交易时段约 10 轮/天 ≈ 70 请求 |
| 请求节奏 | 串行 + Keep-Alive 复用连接 | 社区铁律 1/3;UA + Referer 请求级注入 |
| 断连冷却 | 1800s | 断连即已被风控,半小时内不再碰;封禁可达 20+ 小时,靠长冷却自然等解封 |
| 时段门控 | 盘中 9:30-11:30/13:00-15:00 + 收盘后一轮 | 复用 MarketFundScheduler intraday/after_close 逻辑，夜间/周末零请求（仅进程启动预热/缓存缺失冷启动例外一轮） |
| 中止策略 | 429/403/5xx/断连立即中止剩余批次 | truncated_by 结构化上报,部分成功照常保存(fail-visible) |

数据时效:30 分钟级。题材聚合是估算参考口径(行情主页权威资金列走 THS L2,180s 校准,不受影响)。
