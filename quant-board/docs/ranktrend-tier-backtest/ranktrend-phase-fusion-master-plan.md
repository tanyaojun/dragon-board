# 相位研究 × 三轴仓位管理融合总纲（v1 提案，2026-10-04）

> 定位：把散在四条线上的相位资产（EOD 规则分体系 / jev 叙事轨道 / 个股相位分线 / 三轴仓位执行）组装成一个分层融合框架，并给出升级路线。
> 性质：**提案**。不推翻任何现行口径与晋升门，只做组装、接驳与升级排程；所有裁决点显式标注，等用户逐项点头。
> 事实来源：本文档 §8 附录汇总三路调研锚点（file:line）；与现行文档冲突时以现行文档为准，发现冲突应回改本文。

## 1. 一页结论

**现状一句话**：市场相位有骨无肉（规则分数带在管仓位，jev 轴大多停在对照/披露），个股相位有肉无骨（v0.5 判据冻结但只做展示），三轴仓位有框架无选票（水平×动量×事件全在市场级，买什么票没有相位维度）。

**升级一句话**：把体系从「一套市场分数带管全部」升为三层分工——**市场定时机（三轴：水平×动量×事件）、个股定标的（相位五档过滤）、账本定去留（champion-challenger + C9 独立账本）**。jev 叙事按用户既定裁决（10-01「主线放弃保留打辅助」、10-03「情绪节点出手信号 > jev 模型」）制度化为一类角色：**辅证、哨兵、特定事件源**，永不抢规则分的主定义权。

**提升在哪**：
1. 结构补缺——仓位管理第一次获得「选票轴」（个股相位），补齐"只管买多少、不管买什么"的缺口；执行层研究已证"选票过滤重于时点博弈"（高开回避 12/12 全负，见 §8-D）。
2. 证据合流——市场四带 × 个股五档的分层矩阵回测，把两条相位证据流拧成一张期望表，回答"什么环境下什么相位的票能碰"。
3. 治理收口——多套相位并存的"谁说了算"写成宪章级条款；所有 jev 接口按"已接通/已否定/观察中"三态登记，杜绝重复烧钱试错。

## 3. 结构性缺口诊断（为什么停在研究层面）

1. **市场级单腿**：仓位决策只消费"前一日 EOD 分带"一根输入。jev 五根叙事轴全部在生产，却没有一根以"第二意见/告警/事件源"的身份进入月度监控或面板告警——花了钱生产的信号没进决策管线（哪怕以最被动的形式）。
2. **个股轴缺席**：执行层研究反复证明选票质量 > 时点（高开 12/12 全负、低开过滤 +1.58% vs 池等权 +0.59%、C9 账本胜率 45% 的短板大概率在选票不在时点），但个股相位分线冻结后停在展示，四步断点（§2.2）一步没走。
3. **两套相位互不认识**：市场四带 × 个股五档从没同框算过。低温带里 start 相位（低位放量承接）和 divergence 相位（高位烂板示警）理应天壤之别，现在它们在同一条候选池里被同等对待。
4. **裁决悬空**：三份调研合计 20+ 项待用户裁决散落各文档，没有一张统一的裁决清单和默认走向。

**"谁说了算"宪章条款（新增，建议写入章程）**：
1. 市场相位主定义=规则分（sentiment_2b@60 + 四带）。jev 任何轴不得替代主定义，只有三种合法权力：**(a) 臂内挑战**（经预算与样本外裁决晋升）、**(b) 分歧哨兵**（与规则分判定不一致时告警，永不自动改判）、**(c) 事件源**（断层日/C9 类事件标记）。

## 5. 三个合流点（"如何结合"的具体答案）

### 合流点一：规则分 × jev 哨兵 = 相位判定主辅机制（零 token，即刻可做）
哨兵两档 86% 已在盘后链第 6 步每日产出。合流动作：月度监控新增一条**分歧告警线**——当月哨兵与规则分二档不一致的天数比例、尤其哨兵"判低一档"（它系统性把弱势带读成退潮，与 W4 裁决同向）的天数清单。用途是给规则分装一面后视镜：规则分若连续被哨兵反向提示，触发人工复核而不是自动改判。**改动量：月度监控加一段只读统计 + 面板监控页一行。**

### 合流点二：C9 节点仓 × 个股相位 = 节点选票过滤升级（低 token， F2 后可做）
C9 runbook 现行选票条件=冰点日首板堆积 ∩ 次日低开 <+2%。个股相位是天然的第三过滤：冰点次日买的是"谁的反弹"——**start/低位反包档（承接健康）应当优先，divergence/示警四项档应当回避**。动作：F2 扩全月标签后，把 12 个历史谷日的候选池按个股相位档分层回看，若分离方向支持，第三条件预登记进 runbook，三臂记账（未过滤/低开过滤/低开×相位过滤）。
**成本**：标签已产出后为零（回看存量）；新增的只是 runbook 条款与账本一列。

### 合流点三：市场四带 × 个股五档 = 相位矩阵期望表（核心研究增量）
预登记一个**分层读数**（非交易规则）：全语料期内，每笔涨停股次日/T+3 结果按「前日市场分带 × 当日个股相位档」切格，产出 4×5 期望表+样本量。它一次性回答三个悬而未决的问题：极热带的 climax 是否真有毒（极热档刚修复，样本+1）、低温带的 start 承接是否如判据设计的那样健康（量能语义 v0.5 的主张）、弱势带里是否存在"个股相位可赦免"的格子（若有，C6 禁入条款未来要不要开个股例外——**默认不开**，除非格子样本 ≥30 且多月同向）。
**成本**：F2 扩全月后为零（存量标签+已有情绪分+TDX 结果，纯本地计算）。
