# 除权除息（XD/XR/DR）复权口径统一方案

> ⚠️ **本方案已作废（2026-08-23）**：方案前提（"前端 353.60 = 前复权，与后端 363.60 分裂"）
> 系作者**读图错误**——实际行情源（腾讯接口实测）与后端均返回 **363.60/+1.65%**，前端 UI 也
> 一致显示 363.60，**不存在复权口径分裂**。本方案基于假问题，予以作废，仅供历史对照。
> 601869 四维档位 S→D 的真实机制见 `ranktrend-quantity-price-investigation.md`（另行排查）。

> 状态：2026-08-23 方案（**已作废，未落地**；实测验证完成但前提错误）
> 触发案例（已作废描述）：601869「XD长飞光」非交易日量价/四维档位分裂（量价 82→49、档位 S→D、前端 353.60 vs 后端 363.60）
> 归档位置：`quant-board/docs/ranktrend-tier-backtest/`

## 0. 结论先行

**根因**：601869 于 2026-08-21 除权除息（纯现金分红），前端行情源展示**前复权**口径（353.60），
采集/分析链路存**不复权**口径（363.60）——两个复权口径分裂，导致除权股的价格/涨幅/量比/
量价分/四维档位全程对不上。**方案：对除权股在采集与算法层统一采用前复权口径**。

## 1. 问题现象（601869 实证）

| 口径 | 最新价 | 涨幅 | 量比 | 量价分 | 四维档 |
|---|---|---|---|---|---|
| 前端实时（前复权） | 353.60 | +1.05% | 0.86 | 82→49 | S→D |
| 分析库（load_frames，不复权） | 363.60 | +1.65% | 0.76 | 44~72 | C/D |

同一非交易日读取，量价/档位不一致；用户此前疑问"非交易日档位为何变"即源于此。

## 2. 已确认事实（mootdx 实测校验）

- **mootdx `Quotes.factory(market='std').xdxr(symbol)` 提供完整除权因子**，16 列：
  `year/month/day/category/name/fenhong/peigujia/songzhuangu/peigu/suogu/panqianliutong/
  panhouliutong/qianzongguben/houzongguben/fenshu/xingquanjia`；
- **601869 = 纯现金分红除息**：2026-08-21 除息 `fenhong=2.95` 元/10股、`songzhuangu=0`（无送转）、
  `peigu=0`（无配股）；历年共 9 次除息、每10股累计 31.04 元；
- **后端"当日涨跌幅"已用除息参考价**：后端帧 8-21 涨跌幅 +1.6466%，基准=363.60/(1+0.016466)
  =357.705=除息参考价（8-20 收 358.00 − 0.295）——`chg` 字段本身已按除息调整；
- **前端 353.60 为前复权口径**（用户确认）：标准前复权以最新交易日为锚（8-21 收 363.60），
  故 353.60 表明前端数据源采用**非"最新为锚"**的前复权算法（或对除息日当天也做下调），
  具体锚点算法待前端数据源确认。

## 3. 根因定位

1. **复权口径不一致**：前端前复权 vs 后端不复权 → 同一股票两个价格基线；
2. **量价/涨幅/量比对除权高度敏感**：`change`（chg）、`volumeRatio`（量比基准=前 N 日均量）、
   `amount`（成交额）、量价分（`compute_volume_price_score`）都含价格/量基线类输入，
   除权不统一会放大档位漂移（尤其 `XD` 当天）；
3. **非交易日漂移**：周末前端重新读取时若数据源/复权锚点切换，档位随之跳变（前端时序 +
   复权口径双重影响，均见 §2/§4）。

## 4. 复权方案设计

### 4.1 复权因子计算（采集层）
- 用 mootdx `xdxr` 的 `fenhong`（每股派息）/`songzhuangu`（每股送转）/`peigujia`/`peigu`（配股），
  按 `category=1`（除权除息）事件逐次累计，生成每股复权因子序列；
- **前复权**（以最新交易日为锚，历史价向下调）：
  ```
  factor_i = Π_{j 在 i 之后除息} [ (P_{j-1} - fenhong_j/10 - peigu_j*peigujia_j) / (P_{j-1} * (1 + songzhuangu_j/10)) ]
  前复权价_i = 原价_i × factor_i
  ```
  其中 fenhong/10 = 每股派息，songzhuangu/10 = 每股送转，P_{j-1} = 除息前收；
- **锚点**：以最新交易日为锚（前复权最新价=原价）；若前端数据源用非"最新为锚"，需按其
  实际锚点对齐（待确认）。

### 4.2 应用链路（采集/算法层）
| 层 | 改动 |
|---|---|
| 采集（python-bridge / market_proxy） | 拉取并缓存各股复权因子序列；上报 `isAdjusted`/`adjustFactor` |
| 快照入库 | 除权股历史 `price/change/amount/volumeRatio` 按前复权因子归一 |
| 算法（`compute_volume_price_score`/`engine`） | 量价/涨幅/量比在复权口径下计算；`XD` 标记事件化 |
| 展示（前端） | 统一读复权口径，标注复权方式/时间戳 |

### 4.3 范围边界
- 本次仅**纯现金分红**（`songzhuangu=0,peigu=0`）优先覆盖；送转/配股股后续按公式扩展；
- 全量历史复权 vs 仅除权窗口复权——默认**全量前复权**（保证历史连续可比），成本：replay 需预载
  复权因子。

## 5. 风险与纪律（重要）

- **结构性算法改动**：前复权会改变除权股历史价格 → 改变 `change/volumeRatio/amount` →
  量价分 → synergy 档位 → **影响 golden**；
- **必须走 `ranktrend-signal-research` skill 纪律**（2026-09-16 合并原 four-dim-algorithm-research）：
  - 8 月冻结（`assert_not_frozen`），参数/因子决策禁用 8 月；
  - 固定三窗样本外复核（decision/oos1/oos2，8 月 FINAL 08-01~08-14 冻结），7 月股灾样本外排除；
  - golden 不漂移：新增复权参数默认=原不复权行为（可控开关），复权未启用前 golden 不变；
  - 结论不写回默认值，除非用户决策；
- **数据质量**：部分历史帧缺 `amount`（早期 29% 覆盖），前复权对 `amount` 的归一需 fail-visible；
- **兼容**：新增 `adjustMode`（`none`/`qfq`/`hfq`）开关，默认 `none`（不改现状），验证通过后
  再考虑切换。

## 6. 验收标准

- 601869 前后端口径在复权后一致（最新价/涨幅/量比/量价分对齐）；
- golden 回归全绿（默认 `adjustMode=none` 不改现状）；
- 除权股与非除权股的量价分在复权前后变化有解释；
- 样本外（rolling walk-forward）synergy saEx 不因复权劣化。
