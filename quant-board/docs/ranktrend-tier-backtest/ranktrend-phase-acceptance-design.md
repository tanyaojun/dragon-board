## 1. 背景与动机（用户裁决，2026-09-30）

四项驱动力（用户澄清问答确认，全选）：

1. **验收口径漂移**：原始北极星是交易层 wrxpf≥0.78（能不能赚钱），两批月度复跑在 saEx 判定卡上打转，主验收未被正面攻坚——全窗 0.78 实际永远不可达（差相位天生拖后腿），这是口径本身的病。
2. **增量优化收益递减**：阶段 0-27 + 两批复跑以"保持/挂起/OBSERVE"为主，参数空间挖得差不多，算力应转向更大杠杆。
3. **实盘反馈导向**：实盘体感"情绪好时热榜动量才有效"（用户确认），市场状态/情绪相位可能是最大杠杆，旧体系只把它当披露项。
4. **流程太重**：判定卡/锚代际/观察池/台账/月度批次三件同步的维护成本高于其信息产出。

**被否决的替代方案**：纯里程碑制（无月度监控——默认栈上线后无人监护，弃）；最小实验先行（统计效力不足以立正式计划，其精神并入 M1 首步）。

**被否决的附属想法**：引入 jev 第三方 AI 裁决回测结论——用户裁决作废（理由：jev 只擅长结构化选择题，出题质量锁死答案质量上限，出题本身又是沉没成本，难回收）。

## 3. 验收北极星：分相位双线

```text
好相位（进攻职责）：wrxpf ≥ 0.78 且好相位累计笔数 ≥ 60、maxDD ≤ 10%
差相位（防守职责）：不设 wrxpf 线；验收 = 差相位净暴露可证实地优于满仓穿越
                  （空仓/降仓后该相位段回撤与净损优于默认栈满仓，二者至少其一）
相位数量：初始 2-3 档（进攻/中性/防守），M1 定义后冻结一个季度再评估
时间走廊：连续 3 个月度监控周期，好相位读数达线（允许单月噪声）
```

- 0.78 线不降反挪——只挪到它该在的地方（好相位）。
- 差相位考核"躲得掉"，与实盘体感直接对齐；中性相位（若存在）用防守线宽松版（回撤线 + 不大亏）。
- 计划成功判据：北极星走廊达成，**或 M1 给出有据的否定结论**（实盘体感未被数据支持也是正式产出）——两者都算完成使命。

## 5. 计划主体（M1-M3 + 极简月度监控）

### M1 相位定义（研究，约 2-4 周）

- **候选信号**（全部已在生产，无新采集）：regime 四桶（引擎内生）、情绪 route B 连续评分（hotlist_sentiment，113 日覆盖，首选主力）、涨停证据 limitSummary（连板高度/炸板率）、ThemeTrend 拥挤度分位（因子已落库默认关，读取即可）。
- **首步 = 最小实验**：regime 四桶 + 情绪连续分两套现成信号，对历史全窗 54 笔交易 + 信号读数做相位切片，验证"好相位赚钱、差相位亏钱"。
- **质量检验三关**：划分稳定性（相位翻转率）、滞后性（切换滞后收益拐点多少帧、能否实盘可用）、区分度（好差相位 forward return 差距显著性）。
- **出口判据**：存在 ≥2 档划分满足——区分度成立（好相位 h1/h8 forward return 高于差相位：信号层 Mann-Whitney p<0.05 或均值差 ≥2%，且方向在 ≥2 个独立月份一致）且滞后可接受（相位切换滞后收益拐点 ≤3 交易日，实盘可跟随）；**所有候选不成立 = 头等重要结论**（实盘体感未被数据支持），回头重议不硬造。

### M2 分相位验收框架（约 1-2 周）

- 分相位读数 harness：相位标签 join 交易/信号读数，按相位切片出 wrxpf/笔数/回撤/暴露度（复用 `evaluate_gate` / `track1_lifecycle_gate_trade` 底座，切片维度从时间窗换相位）。
- **相位-收益地图**：gen7 默认栈历史全窗分相位基线，后续一切适配的对照物。
- 北极星读数机械化（好相位线 + 差相位防守线自动产出）；月度监控脚本定型。

### M3 相位适配（开放式迭代，一次一候选）

从简到繁：① 差相位降仓/空仓开关 → ② 好相位入场放宽/加码 → ③ 卖点按相位重审（吸收卖点课题；tp×be 市场状态依赖六次复现即相位依赖直接证据）→ ④ O8 双强以"过热相位"视角收尾。每候选对照相位-收益地图，过线才提请用户落默认。

### 极简月度监控（取代月度批次机器）

- 每月数据落库后一次，约 15-20 分钟单脚本：baseline 四窗 saEx（引擎健康/锚复现）+ 分相位北极星读数 + 三参监督线（S+A 触发率、insufficient 占比）。
- 产出 JSON + 短说明落 `data/reports/phase-monitor/`（本地易失不进 git），人工看；无 trial、无判定卡、无三件同步；读数异常才升级人工分析。

### 纪律保留/废除

- **保留**：串行单进程、交易时段不排批、golden 锁基线、参数化不漂移、fail-visible、一次一候选落默认、优化结果永不自动写回默认。
- **废除**：判定卡五条件自动收口（工具在、不再唯一）、观察池状态机、锚代际推进仪式（只在落新默认时动）、L1 复核登记、月度批次三件同步。
- **新增**：相位定义变更 = 标签全量重打 + 地图重算（轻量版代际纪律）。

## 7. 风险与诚实边界

1. **相位可能不存在**——实盘体感可能是幸存者记忆；M1 失败分支为正式结论，不硬造。
2. **相位过拟合**——多候选×多检验天然高估区分度；缓解：滞后性硬关 + 定义季度冻结 + 定义后月度新数据持续验证（天然留出样本）。
3. **样本薄**——历史 54 笔切片后每相位 20-40 笔；区分度主证据用信号层百万级样本，交易层只做方向确认，10 月起新数据积累。
4. **情绪评分历史覆盖 113 日**（约 4 月底起）短于全窗——标签覆盖范围披露，早期月份用 regime/涨停证据补。
5. **兑现节奏**——防守线预期先于进攻线兑现；走廊需数月，中间不达线≠失败，只看趋势。
6. **资源纪律不变**——串行、交易时段不排批、Mongo 只读分析不占 8000 队列。
