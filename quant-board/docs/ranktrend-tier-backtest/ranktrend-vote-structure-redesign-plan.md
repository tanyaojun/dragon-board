# RankTrend 四投票信号结构重设计计划（2026-10-07 立项）

**命题**：四投票维（res/rank/vp/cs）的参数面已到实证峰（L1 台账 §1-§19 全史+四信号轮五案全不晋升），真实空白在**结构级**——票位错配（重复票/睡觉票/错票）与原料缺位（价格序列缺席）。本计划把预研结论转为分波次立项，每案独立走「预登记合同 → 判定线冻结 → trial → Track 1 → 用户裁决」流程。

**纪律继承**（全文适用，各案不再重复）：
- golden 锁基线；参数化默认=原值零行为；一次一候选；判定线跑前冻结跑后不调（T2 vr125 判例：差一点也不开绿灯）；
- B0 锚=G1 代际 **0.1450/0.0983/0.1172**（population=09-12 帧截止口径，与锚同源；T2 runner 已实现逐位自证，各案复用）；
- 判定卡继承：C1（decision saEx rel ≥+3%）∧ C2（oos2 同向正；oos1 照登）∧ C3（passHard 不降）+ Track 1 wrxpf rel ≥0 终判（涉 B/C/D 迁移或入场面必带）+ 市况分桶（strong vs retreat 预注册对比对，两桶反号→挂起）；
- 模型投喂（语料审定/合同起草）由**用户亲自执行**，AI 只备料；本地 replay 零成本步骤不受限。

**现状底座**（`reasoning-corpus-voting-signals.md` §11-§12.3 + `ranktrend-l1-param-ledger.md` §19）：七维票位实态 = res/rank/cs 0.75 + vp 1.0（E 硬短路）+ pm/dv 0.0（关闭，实证 −32%/−25%）+ lc 环境门（不投票）；synergy S 档 127 帧全靠 cs 正票守门；D1 报告 `data/reports/voting-signals-d1.json`。

- **候选（单变量，一次一候选，≤3 档）**：

### W2-1 隔夜延续特征（T1 反杀直接长出的新票位）

- **命题**：跨日分量方向后验优于日内（cs_delta +0.035 vs −0.0005 等）——「昨日末帧→今日首帧跳空方向」本身是未消费信号。形态三选（由审定定）：①第 8 加性维（跳空方向×幅度分位）；②cs 维的 delta 语义扩展（隔夜 delta 与日内 delta 分开计票）；③确认门形态（跳空作 res/rank buy 的放大器非独立票——吸取 pm/dv「独立票失败、门有效」教训）。
- **既有证据**：D1 trigger×h8 矩阵（四窗一致）；风险=10 月行情单一代际、需逐月验稳定（§5-6）。
- **市况假设**：强情绪期隔夜延续（信号）、退潮期隔夜断裂（噪声）——分桶预注册，反向即挂起。

### W2-2 价格确认门泛化（res/rank 接通用价格门）

- **命题**：价格「独立票」死（pm/dv）但「门」活（vp E 短路 −32% wrxpf 保护、jump 确认门 80.42% 降级后 saEx +18.1%）——把「排名说涨，价格认不认」从 Jump 专属泛化。双模型 L3 独立收敛方向。
- **形态候选**：rank buy 档需当帧 change≥θ（或 price_changes 3 帧方向确认）才保 S/A，否则降 B；res 同构。θ 由分位化找自然分界（§5-6）。
- **关键前置**：与 dv/priceMomentum 观察维做冗余面测定（生命周期轮 P2 的教训：同族原料必须先测重叠率）；与 W1-2 的 rank 稀疏诊断联动（门加在 15% 的方向票上，剂量面先弄清）。
- **执行记录（2026-10-08，审定回执落实）**：**前置四窗 4/4 强同向过线 → 立项合同备料完成** `vote-w22-price-gate-preregistration.md`。审定形态裁定=降档确认门（收缩面）、W2-2 优先于 W2-1；前置靶人群 h8：rank buy∧S/A 帧 change<0 组 −0.0665 vs ≥0 组 +0.0006（差 −0.0671，预声明线 −0.01 的 6-10 倍，四窗全负；res 侧同构全负），触发面 20.8%；臂=单参三态 `tierConfirmPriceGateMode` off/rank/rank_res（θ=0 单帧降档门）；判定卡=审定骨架全款（触发率披露+retreat n<50 降级+oos1 止损带+Track1 双窗）；冗余面（dv/pm 共线率）=trial 前置补跑；接线待 P5 收官。语料 §14.3、台账 §24。
- **执行记录二（W2-1 同批挂起，2026-10-08）**：市况分桶先验过线（四桶 CD−SDa 全正，挂起条款不触发）但靶人群分解无靶——res 侧断裂 16,050 帧 brk−cont≈0、rank 侧断裂四窗合计 43 帧微样本反向；「跨日 cs_delta 有信息」（T1）≠「跨日帧内断裂符号有判别力」（实测零），前置省掉注定零效应的 trial。语料 §14.2 登记（含不覆盖姿势）。
