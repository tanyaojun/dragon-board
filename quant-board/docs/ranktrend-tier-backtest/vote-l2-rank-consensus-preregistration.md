## 一、前置诊断考题（立项前的最后一个证据洞）

W1-2 只测了「差一票帧占比高」，未测「差一票帧放进来有没有增益」——占比高≠含正信息。
共识面任何放开形态（单票门/弱票/B− 档）都以「差一票帧 h8 后验不差于 C 档其余」为前提，
该前提必须先测（诊断扩展：`diagnose_voting_signals_exposure.py` W1-2.1 增补，三 h8 cell，
population=ln≥2 ∧ rank C ∧ 有 +8 前视；产物 `data/reports/voting-signals-w12r-consensus-h8.json`）。

## 二、预声明判定线（冻结于跑数前，2026-10-07 深夜，跑后未调）

## 四、结论与覆盖面

- **rank 共识面/阈值面 L2 行为步不立项**（预声明线内机械判定）：共识面放开方向的前提
  （差一票帧含正信息）被证伪；分数轴方向无诊断支持（0.5%）+OOS 反向旧账。无行为 trial、
  无 config 改动、零接线零行为。
- **本阴性覆盖的姿势**：以「放行差一票帧」为前提的全部形态（decisionMinAgreement 降级/单票门/
  差一票弱票/C→B− 档）；以「buy_count≥2 分数不够帧」为前提的分数轴松动。
- **本阴性不覆盖的姿势**（防阴性当终局判决）：①反向命题——「差一票」作为**负向**信号
  （rank C 档内 dbuy1 帧加负票/降级，excess −0.0106 四窗同向为线索）：新票位=结构级改动，
  超出本轮 L2 scope，登记为语料观察线索，未来须独立预登记（与 cs C 档固定负票 −0.375 的
  语义重叠面须先测）；②五分量信号本体重设计（缺位分量的原料面，如 direction 判据重定义）
  ——属 W2 语料审定范围非参数/阈值面；③新代际数据（若 10 月后行情换代，四窗读数可复验）。

## 五、结构解释（与其他证据同族）

单票动量（direction 或 acceleration 单独说 buy）是弱/负向信号，与 §10 五权重实证（0.90 权重压
交叉事件、连续动量贬权至 0.10）方向一致——2026-09-13 的权重实证与本次 h8 后验互为印证：
**共识门槛 ≥2 票实质是「要求至少两个独立动量源确认」，这一设计在 h8 后验上是有效的**。
fallback 覆盖 36.5%、ln=1 100% C 档等短序列结构与此相容（短序列动量质量差，弃权正确）。
