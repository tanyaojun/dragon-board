## 0. 结论先行

1. **口径级空白（方案 A 的立项理由）**：23.8（整维归零话语权）与 23.9（维度票权扫描、
   combo_three_quarter 落默认）的全部结论——res 话语权最重、vp 是"权重已调准的独立票"、
   rank 参与率仅 17%、cs 净票流系统性偏负——**全部建立在 saEx 口径上**。阶段 24.4 刚
   实证 saEx 会放假阳（e1a 排序面 +33.4% / 交易层 wrxpf −32%），且 Track 1 首战即拦截
   一个 saEx PASS_CANDIDATE。维度话语权从未过交易复核：**23.9.1 落默认（当前生产基线）
   的交易层有效性从未被验证**。
2. **参数族空白（方案 B 的立项理由）**：`tierSynergyCsStrengths [1.0, 0.5, −0.5, −1.0]`
   （cs A/B/C/D 档位强度）是 23.9 硬编码参数化清点中登记"结构参数未扫描"的权重类参数
   族中唯一有结构性线索指向的：23.8 实测 cs C 档 62.5% 帧持续投 −0.5（净票流系统性
   下压 v 基线，"synergy D 档 42.2% 偏多的直接来源之一"），但 −0.5 这个值本身从未被
   数据检验。res/rank/vp 的票权已在 23.9 扫过（0.75/0.75/1.0 落默认），cs 的票权也扫过
   （×0.75 落默认）——**票的"个数权重"调准了，票的"力度标定"没扫过**。
3. **预期管理（立项前必读）**：方案 A 是复核性实验，最可能结局是**双向的**——
   ① 若各维归零在交易层同向受损，23.9.1 默认获得交易层背书（认知闭环）；② 若某维
   归零在交易层改善（e1a 式翻转），则该维票权进入重审，产出减权候选（走 Track 2 卡 +
   Track 1 复核后才谈落默认）。方案 B 扫描在 23.9 的经验下（vp 窄峰、三轴 ×0.75 峰）
   最可能结局是**现值即峰、OBSERVE 存档**；C 档强度松绑（→0）有明确的触发率回灌风险
   （§3.3 预登记）。
4. **vp 信号参数再审视（方案 C 的立项理由，2026-09-14 用户命题）**：23.9"vp 票权
   1.0 已调准"的判定有两个未检验前提——① 阶段 9 的量价参数结论（钝感/冗余/显著）
   测于旧基线（syn saEx 0.0651 时代），此后三次落默认（G2 cs 第 5 维投票、22.8
   五权重 p2_aggressive、23.9.1 三轴票权 ×0.75）把基线推到 0.1044，旧结论在新合成
   结构下的交互项未验证；② 23.9 硬编码参数化的量价阶梯 25 字段（config.py:166-190）
   从未扫描，其中 `fundScore*`（对倒判定公式系数）与 `directionThresholds`（涨跌
   分段边界）位于"档位决定面"（阶段 9 洞察：档位由 quadrant+fund 决定）——正是
   阶段 9 证实有油水的两个因子（fund/over）的**公式侧**。方案 C 三层设计：已扫参数
   新基线复核（含观察池最高优先 fund10+over2 的方向复验）→ 未扫面家族分组 →
   活跃参数两轮扫描 + vp 票权敏感性联动。
5. **共振缺票结构（方案 D 的立项理由，2026-09-14 用户命题）**：共振维经阶段 7

### 1.1 维度票流结构（23.8 层 1，decision 窗）

### 1.2 cs 档位强度的算术事实（方案 B 剂量-后果映射的输入）

当前票权下（res/rank/cs 0.75、vp 1.0）：cs 各档实际票值 = 强度 × 0.75 =
A **+0.75** / B **+0.375** / C **−0.375** / D **−0.75**；阶梯 S≥3.0 / A≥2.0 / B≥1.0 /
D≤−1.0（config `tierSynergyVoteStrong/Weak/Reverse` 2.0/1.0/−1.0，与维度权重无关）；
max v = 3.75。C 档 −0.375 意味着：v_raw ∈ [1.625, 2.0) 的帧因 C 票压线落在 B 而非 A——
C 档松绑（→0）将使这批帧越线，**触发率回灌风险与阶段 24 §5.3.1 同构**，预登记于 §3.3。

### 2.2 实现差异预登记（审计关注点，先自首）

**config 路径 no_vp ≠ 23.8 monkeypatch no_vp**：23.8 的 no_vp 用 wrapper 把 vp tier/dir
置 None，**同时移除了 vp E→D 出货硬降规则**（vp_tier=None ≠ "E" 不触发短路）；config
路径 `tierSynergyVolumePriceVote=0` 只归零票权，**E→D 硬短路保留**（阶段 24 已验证
hard 为峰的结构规则，volume_price.py 明文"不随权重归零"）。两者差异 = E→D 短路存废，
如实标注并在报告并列（如需完全复刻 23.8 口径可加 `volumePriceGateMode=off` 联合臂，
列为可选 trial）。

### 2.3 预登记解读规则（判定在本方案内完成，不另立项；审计 M1/M2/m2 修订版）

- **归因边界（审计 M1）**：no_* 臂的反事实是"该维无票"，读数只能证明**票权 > 0**，
  不能证明 0.75 这个具体值正确——23.9 实证 ×0.5 减权仍三窗全正、归零才崩溃，
  "归零恶化"与"0.75 优于 1.0"可同时成立。0.75 vs 1.0 的裁决**只能**来自 w1_old 臂；
- 某维归零在 decision 窗 wrxpf **下降**且 OOS 至少一窗同向（各窗均过 §2.1 样本量门槛）
  → 判"该维不可归零（票权>0 的交易层证据）"，**不构成对 0.75 现值的背书**；
- 某维归零在 decision 窗 wrxpf **上升**且 OOS 至少一窗同向（e1a 式翻转）→ 该维票权
  进入重审：产出"减权候选"（如 ×0.5/×0.625），须补 Track 2 saEx 判定卡 + Track 1
  复核双过才可提案落默认；重审触发同样受 §2.1 交易数门槛约束——阶段 24.4 先例：
  oos2 +64% 仅 22 笔，裁定"不足以推翻主窗"；
- `w1_old` 若在交易层显著优于 baseline（decision +5% 以上且 OOS 不同向受损）→
  23.9.1 的落默认依据动摇，触发"票权组合交易层复议"（同上双过流程）+ 按 §9 回退
  路径执行；反之 23.9.1 获得"0.75 vs 1.0 的交易层直验证据"，但 **L1 §12 补记动作
  挂起至 9 月复验后**（审计 m2：23.9 减权档 oos2 passHard 边缘失效是 23.9.1 挂起的
  第一观察项，复验前不补记"复核通过"），补记时注明证据窗口范围与 §7 窗口消费折扣；
- 本方案内**只判读、不落默认**；任何落默认走既有 golden 变更流程。

## 3. 方案 B：cs 档位强度表两轮扫描

### 3.1 参数与范围

- 目标参数：`tierSynergyCsStrengths`（list[4]，A/B/C/D；当前 [1.0, 0.5, −0.5, −1.0]）；
- **list patch 语义**（阶段 23 口径三决策 ③）：from_patch 对 list 整体替换、无归一化，
  每个 trial 必须显式写全 [A,B,C,D] 四值；
- **共享映射声明**：`_CS_STRENGTH` 同表供 cs/pm/dv 三维使用（volume_price.py:391-393
  定义 / 421-428 消费）；pm/dv 票权默认 0（关闭），强度表扫描在当前默认下**只影响
  cs 维**，无混杂；若未来 pm/dv 启用，本扫描结论需在其启用实验中重验；
- **线性等价边界（审计 B2）**：cs 票 = 强度 × 票权（volume_price.py:422），强度表
  **整表均匀缩放 ×s ≡ `tierSynergyCrossSectionVote` ×s**（v 上线性等价）——cs 票权
  已在 23.9 扫过（×0.5/×1.5/×2 全档有读数），故本扫描的信息增量**只来自档位间相对
  结构（非均匀缩放）**；单档位轴（尤其 csC）的效应与 23.9 cs 票权扫描在 C 票帧上
  方向耦合（csC 松绑 ≈ 对 C 票帧的局部票权归零），判读需注明该耦合——§3.2 "不与
  票权叠加"的隔离仅对组合 trial 成立，单轴解读不豁免；
- 顺带扫描边界：不动 res/rank/vp 票权（23.9 已扫）、不动阶梯阈值 2.0/1.0/−1.0
  （阶段 23 钝感结论 + 24 阶梯为门控骨架）。

### 3.2 trial 表（第一轮粗扫 14 + baseline，第二轮按证据精扫）

| 轴 | 档位（显式 list patch） | 结构动机 |
|---|---|---|

| csB | 0.25 / **0.5** / 0.75 | B 档弱买票；B 票 +0.375 对 B 线 1.0 的贡献占比 |
| csC | 0（中性化）/ −0.25 / **−0.5** / −0.75 | **核心轴**：C 档负票松绑/加压（23.8 线索指向） |
| csD | −0.5 / **−1.0** / −1.5 | D 档强负票；与 vp E→D、lc 降档的负票生态位重叠度检验 |

- 粗扫判读同两轮制：三窗全正轴进精扫（左右邻档加密 + 剂量单调性），跨窗矛盾轴判
  OBSERVE；
- **效应量预期（审计 B4）**：单档位强度变化的 v 效应 ~0.19/票（如 csC −0.5→−0.25），
