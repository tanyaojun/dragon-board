## 3. 首期读数解读（三条）

1. **方向与直觉相反**：低情绪相位（defense）的交易收益（wrxpf 0.97、sum +33.8%）显著好于高情绪相位（offense，wrxpf 0.36、sum −12.1%）——与 M1 交易切片一致（54 笔薄样本），且权益段同向（defense 段 +12.81% vs offense 段 +9.28%，回撤也更浅）。**在 tp×be 卖点已落默认的现状下，"情绪热"相位反而是这段历史的亏损集中区**——与"情绪好时热榜动量有效"的实盘体感相反，可能的原因：① 高情绪期入场拥挤、追高成本高；② tp×be 卖点对高波动相位的行为差异；③ 4-6 月数据杂乱期（52 合成帧）大多落 offense 桶拉低读数。M3 适配立项前必须先在月度监控里看该方向是否跨期稳定。
2. **offense 未过好相位线**：wrxpf 0.355（线 0.78）、35 笔（线 60）双双未达；maxDD 项过（−4.87% ≤ 10%）。defense 过防守线且是双项过（回撤更浅 + 净损更优）。
3. **单期读数 ≠ 验收**：北极星验收走月度走廊（连续 3 期达线）；本期是历史回溯基线，非验收期。
