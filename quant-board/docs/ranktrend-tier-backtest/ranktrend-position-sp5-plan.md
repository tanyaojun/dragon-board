## 3. 方法论红线与教训（SP5 必读）

1. **读数错配警示（本轮最重要洞察）**：T-jev2 用 H1（下槽收益）测拥挤得"无分离"——**不等于拥挤轴无信号**。用户假设"拥挤=高位风险→减仓"是**回撤端**假设，正确读数是风险类：后续 N 槽最大不利偏移（MAE）、持有期回撤、池内高标回落幅度。SP5 证据门必须**按轴配读数**：温度轴用收益类（H1/持有收益），拥挤轴用回撤类。用错读数会错杀真信号。
2. **2D 前车之鉴**：温度×拥挤组合阶梯先验不成立，单轴证据先行，组合后置且需独立证据门。
3. **加仓否定先例**：温度"加仓进攻"端必须先证明"高温优于中温"（不只是"高温优于低温"），否则先做防守向（低温减仓，即已预登记的 jev_band_v1 思路的日级版）。
4. **Simpson 教训**：跨月混合分位会翻转方向（前日日温全窗负 vs 逐月 5/6 正）——日级研究**必须逐月分析** + 固定标定窗阈值（冻结，禁按月重标定）。
5. **阈值禁抄四带**（用户裁决）：LLM 分数标定未知，一律样本分位数自标定 + 冻结。
6. **预算与晋升**：挑战者 ≤2（现占 exit_v1+jev_seq_v1；队列 jev_band_v1/rebal_v1/slot_v1）；晋升=章程 §6（≥2 样本外月同向 + ≥30 笔 + 回撤改善 + 用户终审）；in-sample 证据只立候选不翻默认。
7. **fail-visible / 冻结 / 不入信号引擎**：全程沿用 §13 消费纪律。

## 4. SP5 研究问题定义（三问）

- **Q-温度（机会轴）**：日级温度（前日 as-of）能否划出"进攻带"——带内入场/持有收益显著优于带外？锚定点=温度带界（分位数冻结）；判定点=带界穿越 + 确认机制（是否需要连续 N 日滞后确认，对照 stage_confirm 思想，防单日噪声）。
- **Q-拥挤（风险轴）**：日级拥挤（前日或当日最新已采槽 as-of）能否划出"防守带"——带内**回撤类读数**（MAE/持有期最大回撤/高标回落）显著恶化？判定点=拥挤带界触发**减仓/出场**（天然走 exit 端，参照 exit_v1 per_band 载体先例），而非入场端。
- **Q-两轴关系**：温度与拥挤是否正交（槽级仅 0.387 相关）？能否构成"温度定进攻档位 + 拥挤定防守闸门"的**分工双轴**（而非 2D 交叉矩阵——后者已被否定）？分工双轴=两个独立单轴开关的组合使用，不建交叉带。

**T1 标定**（产物 `data/reports/phase-monitor/jev-day-axis-calibration.json`）：
- 输入：113 日 eod `scores.day_temperature/day_crowding`（04-15→09-30 全覆盖）+ 1070 槽 scores + 规则分 EOD（`load_eod_scores`）。
- 输出：两轴全窗+逐月分布（n/mean/median/p25/p50/p75/min/max）；**全窗四分位冻结阈值**（沿用 jev_band_v1 先例：全窗标定、禁按月重标）；逐月落带占比矩阵（单月独占某带 = 漂移警示）；Spearman 相关矩阵——日温↔日拥挤（**两轴独立性主判据**）、日温↔前日规则分、日拥挤↔前日规则分、日温↔同日槽温均值、日拥挤↔同日槽拥挤均值。
- 验收：两轴独立性结论（|ρ|<0.5 可分工；≥0.7 高相关 → SP5 增量论证必须落在时点/形态而非信息源）。

**T2 证据门——按轴配读数**（产物 `data/reports/phase-monitor/jev-day-axis-evidence.json`）：
- 帧级前向读数（同日窗口；池收益 = 共享代码均值、共享 ≥5；高标子池 ≥3；高标 = 帧内 rank 前 10%）：
  - **H1** = 下一帧池收益（**温度轴主读数**，复用 T-jev2 框架）；
  - **fwdWorst** = 当日后续任意帧最差池收益（**拥挤轴主读数**）；
  - 敏感性：fwdEnd（当日末帧）、fwdWorstTop（高标子池 fwdWorst）、同槽拥挤 × fwdWorst（读数错配修正重测）。
- 预测子与分带：前日 eod 日温/日拥挤（前日映射 = frames 自身交易日序列）；分带 = **全窗冻结四分位**（禁抄规则四带；禁按月重标）。
- **主假设方向（预登记）**：温度 Q4 H1 均值 > Q1（用户假设：热→强）；拥挤 Q4 fwdWorst 均值 < Q1（高拥挤 → 当日更深的池内不利偏移）。
- **门**：≥2 个月同向且月内 Mann-Whitney p<0.05；全窗显著性只作参考（Simpson 纪律）；反向显著 → **REVERSE** 只登记观察不立载体（参照 C2 前日 day_stage 处置）；其余 **FAIL** = 诚实收口。
- 日级聚合稳健性（防同日前日值 ~9 帧聚类伪影）：113 日「前日带 × 当日整日池收益（首帧→末帧）/ 当日自首帧起最不利偏移 / 次日首帧缺口」。
- 交易层对照（次要证据）：t6 正式基线 54 笔（`t6-runs-formal/1-summary.json`，bt_cd0ba11b698e4ebd）回联 frames——entrySnapshotId 起至 exitTradingDate 池内可观测最差价 → MAE = 最差价/entryPrice − 1；票掉出池 = 右截断如实计数；按前日日拥挤带对照（n=54 只作支持性读数）。
- fail-visible 排除计数：早于首个 eod 日的 frames（无前日分数）、尾帧/单帧日（无前向窗口）、共享代码不足、高标共享不足——全部入产物。

**T3（证据达标才启动）**：锚定点 = 冻结分位带界；确认机制 = 滞后 N 日确认设计（对照 stage_confirm 防单日噪声）；温度轴 → 入场端因子（**防守起步**：低温减仓 = jev_band_v1 思路日级版；加仓端仅当 T2 证明「Q4 > Q2 中温」而非仅 Q4 > Q1——T0 加仓否定先例）；拥挤轴 → 出场/减仓端（phaseExitCoupling 通道，参照 exit_v1 per_band 载体先例）。载体命名（如 jev_day_temp_band / jev_day_crowd_exit）与参数表在 T3 预登记时定。

## 6. 风险登记

- **信息共享风险**：槽温↔规则分 0.717——日级温度与规则分相关性待 T1 实测；若日温也高相关，SP5 的增量论证必须落在"时点/形态"而非"信息源"。
- **拥挤轴可能真无信号**：若 T2 回撤类读数仍无分离 → 诚实收口，拥挤降级为纯披露字段。
- **加仓端否定先例**：温度"加仓"端证据不足时绝不硬上（T0 教训）。
- **LLM 非确定性**：日级分数随文档冻结；前向积累的新文档与旧标定窗可能漂移——月度漂移抽检程序沿用 SP4 T5。
- **多重比较**：两轴×多阈值×多读数的选择效应——预登记唯一主读数 + 其余为敏感性，走廊样本外才是裁决。
