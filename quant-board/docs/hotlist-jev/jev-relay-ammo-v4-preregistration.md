## 1. 背景与根因（10-16 实证，全部可复现）

### 1.1 停牌在「三日晋级链」内被误判为断板（正确性缺陷）

2026-10-16 用户报「停牌股链内误判」后核对：`e702725a` 修的是**真连板回溯链**
（`jiuyan_streak_map`/`jiuyan_consecutive_streaks`，design §9.1「停牌不算断板、跳过续算」）。
实时验证 `jiuyan_streak_map(db,'2026-10-16')['600825'] == 11` ✓（14 天 11 板，跳过
10-13/14/15 三个停牌日）。**但 `three_day_chain_line` 与 `relay_flow_line` 未同步**：
该次提交对链函数只改了「N天M板」渲染、回封判定、家数口径对账，**未加停牌分辨**。

当前代码实时输出（非历史存档）：

| 日期 | 链段原文 | 事实 |
|---|---|---|
| 10-13 | 「新华传媒 9天9板→昨日10天10板**今日断板**」 | 10-13 上交所**停牌** |
| 10-14 | 「新华传媒 10天10板→**次日即断**」 | 10-13/14/15 **停牌** |
| 10-13 `relay_flow_line` | 「断板 **36 只**…TDX 覆盖 **35/36**」 | 未覆盖的 1 只=停牌的 600825，被计入断板家数 |
| 10-13 `relay_flow_line` | 「昨日池今日晋级率 25.0%」 | 分母含停牌股，既未晋级也未断板却被计入 |

污染面：`relay_momentum`（10-13/10-14 weakening 由假断板信号支撑）、`relay_phase`（同级输入）、
晋级率分母与边际对比。10-16 当日链段**未误判**（窗口 10-14/15/16 整落停牌缺口，龙头从
tops 消失）——那是 omission 不是 correction，见 §1.3。

### 1.2 分层晋级把 5 板以上合并，高位层分化不可见

`relay_flow_line` 分层口径为 `layers.setdefault(min(s, 5), …)`，5/6/10/11 板混入同一
「5板」层。10-16 输出「**5板→0%(0/2)**」——两层样本实为 5 板（002343/002696），当日
11 连板龙头若在列也无法区分。11 连板时代，**高位层（5→6→…）的晋级/断板分化正是
`relay_phase.divergence` 判据「晋级率较昨日/参照明显回落」的核心证据**，现被合并掩盖。

### 1.3 高位股多日轨迹缺位

10-16 三日链只点名 D-2 池 top3 的 3 日命运；市场真实结构是「1 只 11 连板妖股 + 首板洪水」
（梯队 57/3/3、首板占比 90%）。龙头 14 天 11 板的逐日路径只出现在段 4 龙头档案的
单只板序行，**第 2-5 高位股无多日证据**；且链窗口落进停牌缺口时，龙头在链段完全不可见。

### 1.4 排除项复核（§1.2.6 先查原料与题目）

用户命题「相位改 5 日/10 日链」的评估结论（同日完成，本文固化）：

- **10-16 判 `divergence`（指数 30.0）的钱效证据独立且扎实**：晋级率 13.2%、断板 33 只
  中位 -5.11%、大面 16、收盘跌停 6、隔日溢价 -3.71%、炸板率 45.4%（100 分位）。
  加长链**不会翻转**该日判定——感知上的「接力情绪好」（涨停 59 家、最高 11 板）
  恰是判据明令禁止单独据以打分的两项。
- **10 日逐股链数据算术不成立**：103 天诊断实测日晋级率 16.7~22.3%，按 20%/步，
  D-9→D0 存活率 ≈ 0.05%，链率恒为 0，第 4 步以后分母仅 0-3 只股=纯噪声；
  且更长链更滑向「家数/高度轨迹」，会把已超带的 ρ=0.895 继续推高（重复建设）。
- **5 日链可行但不推荐**：缺失日脆弱性上升（THS 炸板池 16 散布缺失日，5 日链命中
  ≥1 日概率≈53%→口径混用）、维修成本大于收益；其信息价值可由 §3 的三项以更低风险覆盖。
- 结论：**相位主锚结构不动**（三日链 + 近 10 日聚合轨迹 + 今日炸板面），
  以「补高层证据 + 修停牌 + 加有帽多日轨迹」替代「改链长」。

## 2. 改动清单（实现不得偏离）

### 2.1 改动一：三日链 / 晋级断板停牌分辨（正确性修复）

- **文件**：`quant-board/backend/operations/jev_relay_index.py`
- **函数**：`three_day_chain_line`（fate 循环、存活集合 `s1`/`s0`、边际对比）、
  `relay_flow_line`（`promoted`/`broken`/`rate`/分层）
- **单一事实源约束（硬）**：停牌决策表**必须**抽为公共 helper 供两处共用，禁双实现：
  - 建议落点 `quant-board/backend/operations/jev_label_jiuyan.py`：
    `day_status_of(db, code, date, bars=None, adj=None) -> "sealed" | "broken" | "suspended" | "unknown"`
  - 判定表（与 `jiuyan_consecutive_streaks` 现有决策表逐条一致，`e702725a` 已固化的两条边界继承）：
    | 当日封板集合（`_sealed_codes`） | TDX 日线 | 触发名单（`_touch_codes`） | 判定 |
    |---|---|---|---|
    | 含 code | — | — | `sealed` |
    | 不含 code（池可用） | 无棒 | 不含 code | `suspended`（停牌跳过） |
    | 不含 code（池可用） | 无棒 | 含 code | `unknown`（TDX 数据洞，非停牌） |
    | 不含 code（池可用） | 有棒 | — | `broken`（断板） |
    | 池缺失（None） | 无棒 | 不含 code | `suspended` |
    | 池缺失（None） | 有棒且收在涨停价 | — | `sealed`（日线补证） |
    | 池缺失（None） | 有棒未收涨停 | — | `broken` |
    | 池缺失（None） | 无棒 | 含 code | `unknown` |
  - `jiuyan_consecutive_streaks` 同步改为消费该 helper（行为等价，`test_jev_streak_map.py` 470 行必须全绿）
- **口径变更（停牌跳过续算，与 `e702725a` 用户裁决同源）**：
  - 存活集合：`suspended` 股**既不计晋级也不计断板**（从两集合剔除），文案披露
    「（含停牌跳过 N 只：名称）」；
  - 断板家数：`broken` 剔除 `suspended`，文案改「断板 X 只（另停牌跳过 Y 只）」；
  - 晋级率分母：`池基 − suspended`（决策点 D2），算式与 `relay_flow_line` 同源同式，
    **两行数字必须继续一致**（现约束不可破）；
  - `unknown`（数据洞/北交所 920xxx 不覆盖）：**不让步为停牌**，落不可算并披露，
    该股不参与任何比率（宁缺毋猜）。
- **fate 文案新增分支**（与现有三分支并列，顺序：连板中 → 昨日断板今日回封 →
  **昨日停牌今日回封** → 昨日断板/停牌今日断板 → 次日即断；每支按当日实际状态取词）：
  - 例：「新华传媒 9天9板→10-13 **停牌跳过**（复牌后 11 板，见段4）」
  - 判据零改（叙事给的事实变真，档位枚举与判据句不动）。

### 2.3 改动三：新增段 2c「高位股多日轨迹」（有帽新段）

- **文件**：`jev_relay_index.py`，新函数
  `high_position_trajectory_lines(db, date, dataset_id=..., top=5, n=10) -> list[str]`
- **入参口径**：今日触板池中 `jiuyan_streak_map` 真连板 **≥4** 的个股，按 streak 降序、
  封板时间升序取 **top 5**；无 streak≥4 → 单行「高位股轨迹：无（今日最高 X 板）」。
- **逐日状态**：以 `trading_dates_before(db, date, n-1) + [date]` 为轴（近 10 个交易日），
  每股每日状态取 §2.1 的 `day_status_of`：
  - `sealed` → `●`；`broken` → `○`；`suspended` → 停牌（按日区间合写，不逐日重复）；
    `unknown` → `?`（披露不可验日）
- **渲染（省 token，仿板序行）**：每股一行，例：
  `600825 新华传媒（当前连板11）：近10日 ●●●●●●●●●● · 10-13/14/15 停牌跳过 · 区间 14天11板（一字板）`

- **fail-visible**：TDX 日线整体不可用 → 单行「高位股轨迹：TDX 日线不可用（fail-visible）」；
  入池股 <1 → 按上条；`unknown` 日如实标 `?`。
- **位置**：`build_relay_narrative` 中插在段 2b（题材演化）之后、段 3（题材梯队表）之前。
- **判据联动（决策点 D3）**：`relay_phase` / `relay_index` instructions 各增一句

  并列参照，**不得单独据其打分**」；`relay_momentum` 不动（其锚仍是三日链 + 炸板面）。

## 5. 预算与执行

- **回放窗口**（决策点 D4）：候选 A = 10-16 往前 15 个交易日（2026-09-22..10-16，含
  10-13/14/15 停牌段与复牌日）；候选 B = 往前 20 个交易日。
- **预算**：15 次 × ~6.5K tokens ≈ 10 万 tokens；20 次 ≈ 13 万 tokens（官方直连，$ 量级 <0.01）。
- **执行方式**：单进程顺序执行
  `.\.venv\Scripts\python.exe -m backend.operations.jev_relay_index --relay-day <日> --force`
  （v4 重放需 `--force` 覆盖 v3 文档；执行前逐日清单与预算再次确认）。

  **不自动重试**，如实落 degraded 并披露（2026-10-07 纪律）。
- 密钥走 `.env.local`（`JEV_TYPESAFE_KEY`/`JEV_CF_TOKEN`），不落新存储。
- 存储合同不变：`hotlist_jev_relay_index`，`_id={date}:RELAY`，`questionSetVersion="v4"`，replace_one 幂等。

## 7. 验收标准（全部可测，缺一不可）

1. **停牌零误判**：任一「停牌日跨链」的股票，fate/断板家数/晋级率分母均不得记断板
   （600825 fixture 测试锁定，见 §8）。
2. **数字自洽**：段 2a/段 2c/段 1（最高板、梯队）/段 4（龙头档案）的「最高板/连板数」
   两两一致，不得重现审计 #2/#3 的自相矛盾族。
3. **`insufficient_evidence` 率不升**：回放窗口内 vs v3 同期，比例不得上升。
4. **ρ(relay_index, day_temperature) 不升**：v3 现 0.895 已超 [0.5,0.85] 带，
   v4 不得继续推高（>0.90 判失败，回溯判据权重）。
5. **分布不离散**：phase 至少 3 档出现，或与 v3 分布形状同构（不复现 15 日样本塌陷）。
6. **全窗 status=ok**：15/15（或 20/20）落档；证据缺失日按设计降级披露，不算失败。
