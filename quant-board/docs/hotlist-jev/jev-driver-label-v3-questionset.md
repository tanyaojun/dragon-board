## 二 考题（每题：为什么这么问 / 选项为什么这么组织 / 锚什么证据）

### Q1 driver_type（七选一）——建议保留，去留由你裁决

- **为什么还问**：①v1/v2/v3 三代对比需要同题锚（否则"v3 变化"无法归因于弹药还是题目）；②它在热榜**非涨停**人群有已验证的筛选信号（真催化 8.0% vs 无催化 1.0%，p=0.0102），标签库对"挑明日可能板的股"仍有用；③同一题在富弹药下的改判幅度本身就是弹药质量的度量（v1→v2 改判 63%）。
- **代价**：约占总 token 1/3。若你裁决"已板人群内不要类别轴"，可砍掉省成本，三代对比降级为 v1×v2 两代。
- **选项为什么这么组织**：七类沿用阶段3 冻结口径（ma_restructure/order_earnings/product_event/ma…/policy/industry_cycle/capital_flow/concept_stretch），与 v1/v2 逐字可比；保留 v3.1 的「催化所指业务若已是主业不应判蹭概念」例外条款与「无新催化→资金接力」兜底。**文案原文不动**（动一个字就破坏同题锚）。
- **锚的证据**：弹药 1（解析催化行）+ 弹药 2（涨停时间）。

### Q2 catalyst_depth（六选一）——保留（本轨道唯一三验真信号）

- **为什么问**：催化落点深度（质量轴）是同一批标签里唯一统计显著的轴：concept_assembly 唯一负桶三验成立；60+ 强带 Kruskal p=0.0255（组装股 0% 续板/−3.18%）。这直接服务"强势日回避纯组装股"的复盘辅助。
- **选项为什么这么组织**：五实质桶（核心主业/放量承接/早期承接/股权关联/概念组装）+ 信息不足逃生口；判据锚可数证据（动词七级：研发<送样<验证<认证<小批量<量产<规模出货；证据分级 T1-T3：网传传闻不得支撑放量层；core 防偏/early 防吸护栏）。**文案原文不动**（v3.1 定稿判据）。
- **锚的证据**：弹药 1（解析中的收入占比/订单/参股行）。

### Q3 catalyst_freshness（四选一）——保留（机械轴，便宜）

- **为什么问**：新旧催化与续板有观察价值（9 月全量 continuing 74% 符合缩量市）；判据纯日期锚（距今 ≤2 交易日=新），几乎零歧义；每只 token 增量最小。
- **选项**：fresh_catalyst / continuing / none / unclear——四态 MECE；锚弹药 1 中的日期证据 + 叙事头日期。

### Q4（新增·供你裁决去留与文案）买盘逻辑四选一——「位置>类别」的直接检验

- **题目草案**：「该股今日涨停的最主要买盘逻辑是哪一类？只依据所给信息判断，不预测后市。」
- **选项与组织依据**（按"买盘驱动源"划分，MECE）：
  - `independent_catalyst` 自身独立催化：今日涨停主要由该公司自身的公告/订单/事件驱动（解析有对应具体事件行）；
  - `sector_follow` 板块联动跟随：同板块多股今日齐动，该股为跟随位（锚弹药 5：板块今日涨停家数多 + 该股封板时间偏后）；
  - `high_board_relay` 高位卡位/情绪接力：无明确新催化，靠连板高度与情绪地位接续（锚弹药 4：连板梯队 ≥3 板/高位 + 解析无新事件行）；
  - `pure_sentiment` 纯情绪修复：无板块协同、无高度、无新事件（缩量市超跌反弹形态）。
- **为什么加**：游资定价的第一变量是位置（龙头/跟风/卡位），不是催化分类学——这是根因分析的直接推论；而"板块联动 vs 独立"需要跨股+跨文本判读，结构化数据给不全，只有模型能答。
- **风险预登记**：c/d 判据部分依赖叙事详略（贫料环境可能误判）；处置=试点后人工抽验 5 只（判例层核对），不设硬门。

### Q5（新增·用户指令）当日相位强弱分线题——四选一

- **题目草案**：「仅依据所给盘面事实（涨停家数、炸板率、连板梯队、板块效应及各自近 20 日分位），判断当日市场情绪相位落在哪一档？只依据所给信息判断。」
- **选项与组织依据**：`cold_lt40` 冷带（40 分线以下）/ `weak_40_60` 弱势带（40-60）/ `strong_ge60` 强势带（60 分线以上）/ `insufficient` 证据不足——三档**直接对齐用户裁决的三带框架**（C7 阶梯 10-40/40-60/60+），与规则分 40/60 两线同口径，产出可逐日对照。
- **为什么值得问（模型才有增量）**：规则分是历史分位温度计（§原料一致性排查结论），模型独立读盘面结构判相位 = **第二条独立管线**——分歧日即情绪轨道 W2 哨兵的候选信号（对照/哨兵正是 jev 辅助线定位）。
- **防锚定污染（关键设计）**：叙事里**不出现规则分与相位带结论**（弹药 6 修订原因）——喂了答案再问=复读，零信息。模型只拿分位化原始事实。
- **锚的证据**：弹药 6 全部（机械可数）；预登记机械校验=三天规则分 24.4/42.8/65.9，正确档应为 冷/弱/强（3/3 为判据自洽基线）；同日 186 只判定应一致，分裂=判据不稳信号（本身即读数）。
- **「当帧」边界**：本次判**当日（15:00 收盘帧）**；日内逐帧版属情绪轨道既有序列题，不混入打标轨道。

### 不考的（及理由）

- 温度/拥挤/置信：情绪轨道的事，口径分离不混入打标轨道。
- 封板质量/连板高度/板块家数：**结构化直供，不烧模型**（能用数据回答的不问模型）。
