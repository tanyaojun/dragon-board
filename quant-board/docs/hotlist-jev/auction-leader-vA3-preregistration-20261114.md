## 2. 题目条款

### 2.1 改 Q1 `auctionLeaderSealToday`（封板题）

- 新增判据分支（引用叙事供给行）：
  ① **一字板分支**（P2/Q1 修复）：bid 行 09:25 匹配价 ≈ 限价 且 竞价成交/换手为真零
  → 「硬一字」读法：一字板封板概率评估不得引用「竞价成交弱」作负证据（零值=无对手盘，
  非抛压）；试盘行全匹配 09:25 且试盘顶死（≥95% 限价）为佐证锚；
  ② **试盘三档判据**：试盘行 end_time 三档（全匹配 / 不可撤窗 / 可撤窗撤单）与
  试盘涨幅档作为封板读法的证据锚；**「可撤窗撤单」不得单独作负证据**（基率 18%），
  须与试盘涨幅符号/强度、资金姿态合读；
  ③ 试盘负涨幅（end 时点跌破昨收）可作为显著负证据（4% 档）。
- 缺席降级：试盘行缺席（榜外/采集失败）→ 对应判据自动失效，回到 vA2 口径，不悬空。

### 2.2 增 Q4 `trialSettlementPattern`（试盘结算形态题，个股级新增）

题面要点（**判据只给观测框架与合读规则，禁嵌 §1 基数率**——题面随每次投喂重复
注入，嵌率会反复烧 token 且形成锚定偏差；校准数只进本文档与评估层）：
- 档位：`hard_oneword`（全匹配 09:25+顶死）/ `no_cancel_settle`（不可撤窗定型）/
  `cancel_weak`（可撤窗撤单+试盘负涨幅）/ `cancel_neutral`（撤单+0–50%）/
  `cancel_strong`（撤单+≥50% 限价）——五档均为 09:25 可观测事实，不问结局；
- 判据引用：试盘行（end_time/试盘涨幅/首开/最终/首加）+ bid 行（09:25 匹配价）+
  结构行（连板）；资金姿态（维持/撤减）作为合读证据引用，不单列档位（备选方案 B：
  拆两题 `trialSettlementPattern` + `trialMoneyPosture`，token 成本↑，待裁决）；
- 期望答案分布按 §1 梯度设计（评估层对照，不进题面）。

- Q2 硬度题 × 方向解耦：负面硬事实（澄清公告等）→ 硬度降档而非方向翻转；

## 4. 边界与语义纪律

1. 试盘榜 = max_amount 降序 cap 100：小额试盘出榜 → 试盘行缺席（降级路径覆盖）；
2. first_amount/first_add/max_amount/last_amount 业务语义仍待 App 同屏核对；
   校准用「最终 vs 首开」比值关系不依赖精确语义（等比自洽），题面不写语义解释；
3. jj_percent 是 end_time 时点快照（勘察 §4 已双样本自证），题面引用须带时点措辞；
4. ST/20cm/30cm 限价口径按代码分档，评估层统一（§1 口径）。
