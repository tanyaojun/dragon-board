## 二、新题设计（唯一新增题，事件驱动判答）

### 2.1 题目 `leader_rebound_popularity`（新龙人气成色）

- **type**：choice；
- **判答条件（程序门）**：仅当日命中弱转强事件（`leaderRebound` 或
  `benchmarkAdvance`，事件股=当日分轨空间龙一，裁决 5 口径）的叙事行判答；
  非事件日叙事**不含本题**（零额外调用，见 §四预算）；
- **题面要点（草案，落地前用户过目）**：仅依据所给证据（人气证据链行、板块结构、
  题材深度/延续题在同批叙事中的判答、空间锚行），判断该弱转强反包的**人气聚合
  成色**——是完成「新龙确立」（人气聚合、梯队跟随），还是「单日反抽」（仅存量
  情绪脉冲、无跟随）。硬规则：
  ①空间锚行必须先对齐（历史同结构反包再走≥1板率），偏离须点名锚行数字+锚外新证据；
  ②人气证据链行是本题专属判据源（见 §三），判档须点名链行具体事实；
  ③跨题一致性：同叙事延续题判 ending 时默认不得判 dragon_confirm，除非给锚外新证据；
  ④关键证据缺失（事件股无窗内序列、板块结构不可考）判 insufficient，不得硬填。

### 2.2 判档词表（B2 待裁决）

| 档               | 语义                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- |
| `dragon_confirm` | 新龙确立：反包+板内跟随（当日板内上板家数≥2）或题材延续题 strong_extend 同判，人气聚合 |
| `one_day_pop`    | 单日反抽：封板但无板内跟随、无题材新催化，人气未聚                                     |
| `insufficient`   | 证据不足：窗内序列缺失+板块结构不可考（窄口径，沿用 v13 收紧哲学）                     |
