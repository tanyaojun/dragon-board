# map_stage 方向语义家族 B+C 预登记（2026-10-08，用户裁决「然后再进行B+C」；判定线冻结于回放前）

## 0. 一句话

EOD 档位的方向判别从「末步差分 slope」升级为「日内路径 dd + slope」组合，并消除 ≥60 段方向盲区
与 60 边界跳变——修复两类残余误判：①尾盘反抽日（全天跌、末步 +1 → slope>0 误判启动）
②高位回落日（62 分从 75 峰跌落仍判发酵）。

## 1. 冻结判定线（先冻结再回放）

```
map_stage(score, slope=None, path=None)
  path 仅 EOD 传入：{"dd": drawdownFromHigh}（EOD 分 − 当日日内峰分）；盘中槽恒 None（行为零变化）

  score >= 75        → 高潮（不动）
  score >= 60        → 退潮 if (dd ≤ −8 或 slope < −10) else 发酵      ← C：≥60 段接方向
  40 ≤ score < 60    → 退潮 if (dd ≤ −8 或 slope < 0) else 启动        ← B：中段 dd 补充 slope
  score < 40, slope<0 → 退潮（不动）
  score < 40, 其余    → 冰点（不动）
```

- **dd ≤ −8**：日内自高点回落 ≥8 分=回落中（EOD 收盘对日内峰的距离，非末步噪声）；
- **≥60 段用 slope < −10**（强负才翻，浅回落 −3/−5 保持发酵——档位水平仍高，方向只在急跌时接管）；
- **中段保持 slope < 0**（A 方案已上线，dd 是补充不是替换——dd 修尾盘反抽，slope 修浅路径日）；
- **bounce 不入映射**：锚案例 09-24（dd −9.1 / slope −2.3 / bounce +26）用户盘感=退潮日——dd 优先级
  已由锚案例裁决，bounce 无独立锚案例支撑，不引入（V 型深反弹日的 dd 优先归属披露于回放）；
- dd 缺失（旧文档/无 pathDiag/score 缺）→ 退化为现行规则（fail-visible：缺失不发明方向）；
- 阈值 −8/−10 为冻结设计值；灵敏度变体（dd −6/−10、强 slope −8/−15）**仅披露不选线**。

## 2. 语义边界

- path 仅 EOD：盘中槽保持末步差分（响应性 + 变更面最小，EOD 是决策消费面：regime/门控/相位全读 EOD）；
- 与 jev 的关系：不引入 jev 输出（jev 仍是独立观察轨，哨兵分歧只告警不改判）；
- 60 边界跳变消除：59.9/−20 → 退潮（中段 slope），60/−20 → 退潮（≥60 强 slope）——两侧一致。
