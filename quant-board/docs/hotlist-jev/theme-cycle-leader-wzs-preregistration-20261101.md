## 一、方法论锚与两层关系

第3课四阶段：**主升浪 → 转弱势 → 弱转强 → 终结者**。各阶段使命：

| 阶段 | 使命 | 可数锚（本草案判据的原料） |
|---|---|---|
| 主升浪 | 龙头角逐，「翻倍的龙头出现才证明题材有赚钱效应」 | 空间龙一 gain10、真连板高度、家数分位 |
| 转弱势（真金的考验） | 盯住谁能**稳住在相对高位不崩塌** | 人气股池逆势表现（窗内逐日涨跌/触板） |
| 弱转强 | **新龙再崛起**，只有两种形式：①人气股反包 ②连板的标杆，**没有第三条路** | 形式①/②事件（§四） |
| 终结者 | 再无新龙崛起 + 无资金回流 → 个股慢慢退出自选 | 观察窗满无事件 + 冰点/家数萎缩 |

**两层关系**：第5课弱转强=板块效应层（指数翻红/核心股大涨/家数，wzs 节点已落地）；
第3课弱转强=**龙头个体层**（新龙是谁、以哪种形式崛起）。节点判档（wzs）只能答
「板块出现弱转强迹象」，答不了「新龙是谁」——本草案补龙头层，两层联立见 §五。

## 二、用户裁决（2026-11-01，本预登记基石，共八条）

1. **人气股逆势观察窗扩至 3 个交易日**（暂定）。理由（用户原话）：「3 日内不反包
   人气散了，龙头就会被抢」。断板日 D0 起 T+1..T+3 为有效观察窗，窗满未反包 →
   退出观察（人气散，视为真金落寞）。
2. **标杆晋级门槛 = 真连板 3 日（streak≥3）**。真连板≥3 的股为「连板的标杆」。
3. **周期状态机做显式**（非推导投影），且**弱转强要能做到日内**（盘中识别，
   不止收盘确认）。
4. **（Q1）盯盘池同步 3 日窗**：V4-G 盯盘票池窗由 T+1 改为 3 日窗 + 窗位/逆势表现
   披露（取代同日早间 T+1 收紧裁决，见 §三；height≥2 与未跌停条件保留不变）。
5. **（Q2）新龙归属暂只认 10 日空间龙一**：形式①/②事件股 = 当日 v12 分轨空间
   龙一（main/growth 各自 gain10 最高者，单源不另造）；非龙一的反包/晋级只披露
   为跟风/统计口径，不构成新龙再崛起。
6. **（Q3）回封又炸允许多次尝试，完成态=收盘封板**：盘中触板可多次均计尝试；
   收盘回封（THS 池确认）即反包成立，此前盘中炸板不影响；「炸板后不回封」
   =当日尝试失败，余窗继续。盘中疑似永不计入完成态。
7. **（Q4）终结阈值 N=1，冰点即终结**：观察窗满后首个 ice 节点日即终结；
   collapse 不触发终结（板块停留转弱态）。
8. **（Q5）断板日跌停不入观察池**（沿用 v12 未跌停条件），确认。

## 四、龙头弱转强两形式判定（核心判据草案）

记号：D0=断板日；k=T−D0∈{1,2,3}=窗位；height=真连板高度（当日 streak 与近 3 日
最近封板日高度取大，v12 单源）；THS 池=盘后封板确认。

### 4.1 观察池（人气股逆势观察母体，逐板块）

入池条件（全部可数，逐日重算）：
- 近 3 个交易日内（D0∈[T−3, T−1]）**曾封板后断板**，且 height≥2（断板日历史高度）；
- 断板日**未跌停**（沿用 v12 未跌停条件；跌停断板=真金已崩，不入池、fail-visible 披露）；
- 昨日空间龙一无论封否**恒在池**（它在主升浪使命内，断板即开窗）。

池行披露（fail-visible）：code/name/轨别/D0/窗位 k/断板日高度/窗内逐日涨跌幅与
是否触板（逆势表现=「稳住高位」的观察证据，v1 只披露不进硬判据）。

### 4.2 形式①：人气股反包（完成态）

- **判定**：观察池内个股当日收盘封板（THS 池确认，裁决 6：收盘回封即成立，
  此前盘中炸板不影响；盘中触板=尝试，可多次）→ 事件
  `leaderRebound(board, code, date, k, height)`；**新龙=该股且该股=当日分轨空间
  龙一**（裁决 5）；非龙一回封 → 披露为跟风反包（统计口径），不构成新龙再崛起。
- **盘中版**：实时报价触达涨停价 → `intradayReboundTouch`（尝试/疑似态，显式标注
  「触板未确认」；封死确认依赖盘后池，L1 盘口 bid1@涨停价仅作疑似 proxy，
  数据边界见 §六）。疑似态**永不计入完成态**（裁决 6）。

### 4.3 形式②：标杆晋级

- **判定**：昨日 streak≥3 的池内股（=「连板的标杆」，裁决 2）当日收盘封板且
  streak+1，**且该股=当日分轨空间龙一**（裁决 5）→ 事件
  `benchmarkAdvance(board, code, date, streak)`，新龙=该股。
- 标杆非龙一（gain10 未居首）→ 晋级披露为跟风/统计口径，不构成新龙再崛起。
- 全场无 streak≥3 股或标杆均非龙一 → 形式②当日不成立，如实出「无标杆/标杆非龙一」
  注记，不伪 0。
- 盘中版：标杆股盘中触板/疑似封板 → 日内提示（同 4.2 盘中机制）。

### 4.4 龙头弱转强成立（两形式合流）

当日命中 ①∪② ≥1（事件股=当日空间龙一）→ **龙头层弱转强成立**，新龙=事件股；
两形式同时命中时双事件并列披露。

## 五、显式周期状态机（裁决 3）

状态词表（每板块一个当前态，逐日+日内可迁移）：
`主升 mainrise / 转弱 weakening / 弱转强 wzs / 终结 terminal`。

| 迁移 | 触发（全部可数） |
|---|---|
| →主升 | 节点∈{brewing, fermenting, mainline}，或空间龙一续板晋级/创高度新高 |
| →转弱 | 空间龙一断板（leaderState=broken，**开启 3 日观察窗**），或节点∈{weakening, collapse} |
| →弱转强 | §4.4 事件命中（新龙再崛起=本阶段使命完成） |
| →终结 | 观察窗满（窗内无 ①②事件）且当日节点=**ice**（裁决 7：N=1 冰点即终结；collapse 不触发终结，板块停留转弱态） |

- **可重放**：状态机输入=节点序列+龙头事件流，确定性、零 token、全历史可回填
  回测；每次迁移落痕（from/to/触发证据/日期），迁移无证据不得发生（fail-visible）。
- **日内迁移**：转弱→弱转强允许日内触发（盘中触板/标杆疑似晋级即可标「弱转强
  （盘中疑似）」），收盘按 THS 池复核；疑似未确认 → 态保留+显式回退痕迹。
- 与节点判档的关系：状态机**消费**节点不重复定义节点；同一证据两层各有语义词
  （wzs 节点=板块迹象，弱转强状态=新龙已现），分歧时并列披露不互相覆盖。

## 六、日内判定与数据边界（裁决 3 的诚实边界）

- 事件源：KPL socket 实时报价（3006，现成）判触板；pulse 实时红盘（板块层，现成）
  作背景；**真 L2 封单/逐笔未完成**（§4.3 TDX 红线），封死确认只能盘后 THS 池。
- 盘中三态显式区分：`未触板 / 触板未封（或炸板）/ 疑似封死（盘口 proxy）`，
  全部带「疑似」标注；不把疑似封死渲染成确认，不把触板渲染成反包成立。
- 数据不可考（报价断流/池缺失）：日内列显式「不可考」，不伪 0、不静默（AGENTS §4.0）。
