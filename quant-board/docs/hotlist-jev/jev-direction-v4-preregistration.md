## 四、计分口径（冻结不变）+ 裁决对比表（第一交付物）

- 判读时点=盘中 11:00 槽帧落盘即判读；验证=**隔日涨幅**（T+1 最后一槽 change；掉榜股不计分）；
- buy 对=隔日涨 / sell 对=隔日跌 / **hold 遇 \|隔日\|≥5% 算错**；insufficient 不计分；
- 置信校准：高置信组正确率应显著高于低置信组，否则置信视为无效；
- **裁决对比表（每日自动产出，先于任何判据迭代）**：jev 线 vs 规则线（synergy 档位查表 S/A/B→buy、C→hold、D/E→sell，确定性可复现）同股同场（join 键=code+tradingDate），同一把尺子算两线正确率、混淆矩阵、一致率；分带（冷/弱/强/高峰）分层披露。v3 教训：自比「永远 hold」七轮空转——本线只与规则线比。

## 五、判据草案（v4，单题集 A 形态不变；**改门须用户点头**）

`direction` choice 四档（buy/sell/hold/insufficient），confidence 0-1。

**instructions 读法锚（每条锚 §三具体块/字段）**：

1. **序列**（块1）：**历史深度 ≥5 交易日才可作主证据**；seenDays<5（含 FIRST-SEEN）走位置+板序+板型路径并降置信，不得引用不存在的序列历史（铁律 3）。多日同向才成趋势（看 directions 列，不看相邻槽噪声）；against-trend jump 日（jumpIdxs 非空）否决当前方向；连续下跌 ≥3 日是退潮证据；choppy 往返降置信。
2. **位置+板序**（块2）：连板轨迹上升且位置低（距 20 日最高 >20% 或窗口低点距今 ≤8 日）= 启动/扩散位；连板高度停滞或下降且高位（距最高 <10% 或低点距今 ≥15 日）= 拥挤位；板序断板（末位由 ● 转 ○）加深回撤 = 反转位。
3. **量价+板型**（块3）：价涨+量比 1-2.5 = 确认；量比 >2.5 的上涨 = 派发嫌疑（非确认）；净占比 >+20% = 对倒/洗盘嫌疑，**不是看多**；净占比 ≤-10% = 派发；价跌+放量 = 最强 sell 证据；**一字板（首封=末封=09:25 且封单大）是真实但不可交易信号，永不作为 buy 证据**；烂板/反复开板/放巨量滞涨 = 分歧示警。
4. **市场 as-of**（块4/5）：市场处于摆动锚峰值附近且炸板率/大面走高 = 退潮基调（个股证据门槛抬高、sell 权重放大）；处于谷值附近且炸板收敛 = 出清末段（不追 sell）；市场事实缺失按缺失处理，不用情绪分替代。
5. **环境门（buy 前提，双门 AND）**：门1 位置=块2 判启动/扩散位（连板轨迹上升+非高位；拥挤/反转位禁 buy）；门2 情绪相位带=块8 固定分线查表，**仅 strong 带放行**（peak≥75 拥挤拦 / cold<40 拦 / weak 40-60 拦， blocked 带的看多读数降为 hold）。
6. **insufficient 仅限数据不可用**（块7 质量自标或关键块缺失）；证据冲突=hold，不是 insufficient。

**criteria（每条可数）**：
- `buy`：序列多日上行且跑赢池中位（块1 vs 块8）；位置=启动/扩散（块2）；量价确认且净占比正常（块3）；双门全过（块2 位置门+块8 strong 带）。
- `sell`：多日下行/连跌 ≥3 日，或高位+板型分歧（烂板/反复开板/放巨量滞涨），或价跌+放量/净占比 ≤-10%，或断板+深回撤的反转位。
- `hold`：证据混合或幅度太弱，或 buy 门失败但无 sell 证据。
- `insufficient`：仅数据不可用；永不因证据冲突。

## 六、pilot 门判据（可量化，先冻结再开火）

- **窗口**：连续 10 个交易日（须含 ≥1 个退潮日+≥1 个震荡日；情绪带四带至少各出现一次，不足则顺延）；
- **人口（2026-10-13 用户裁决：全热榜池）**：判读帧全部在榜股，**v3 三条件排除（主力非空/当日≥4槽/前三日连续）取消**——那是「序列为主证据」判据的影子，会把新面孔（最强 ignition 候选）系统性挡在 buy 判读外。10-12 实测全池 234（其中 firstSeen 22/序列弱 81，降级自标不排除）；每日落档全池数+firstSeen/序列弱分层计数；
- **开火前验收**：黑名单机验（15 字段）+人工抽 3 日叙事通读+摆动锚/时点口径抽 1 日对账；
- **通过条件（四条止损线全不触+一条增量线）**：
  1. insufficient 输出率 ≤10%；
  2. 高置信（≥0.9）占比 ≥30%；
  3. hold 占比 ≤70%（v3 为 83%，在线外）；
  4. **增量线：jev vs 规则线正确率差 ≥5pct 且二项检验 p<0.10**（10 日窗口累计 ~1200 配对例）；
  5. 置信分组单调（高置信组正确率 > 低置信组，§四校准要求）。
- **人工抽验**：每周 ≥10 例（翻转例+高置信 sell/buy 优先），归因顺序固定 ①原料→②题目→③协议解析→④方案；
- **成本**：叙事 ~2.1-2.5k 字符/例（10-12 全池 234 例实测 median 2252）≈ 0.8-1.2k tokens input/例 × ~230 例/日 ≈ **0.2-0.3M tokens/日**（v3 的 1/3）；10 日 pilot ≈ 2-3M tokens；开火前预算确认；
- **回退**：questionSetVersion="v4"+AMMO_VERSION 戳+git（f79e3a70 为原料层锚）；停链即零成本；判据迭代仍须「拟合日之外验日」协议，小样本调参禁入判据（buy v2 教训）。

## 七、止损线（用户裁决：jevu 仍犹豫=立即止损，此路不通）

pilot 内触发**任意一条**即停线、不迭代、不调参、承认此路不通：

1. insufficient 输出率 >10%（jevu 自述原料不够）；
2. 高置信（≥0.9）占比 <30%（判据形同虚设）；
3. hold 占比 >70%（缩回无脑 hold）；
4. **jev vs 规则线正确率差 <5pct 且 p>0.10**（终极线：无增量即无存在价值）。

第 4 条不满足时前三条免谈。止损动作=停链+归档（台账/DB 导出 data/backups/）+一行结论入库，不做「再试一版」。
