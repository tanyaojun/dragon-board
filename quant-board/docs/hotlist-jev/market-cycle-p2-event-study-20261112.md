  入场后市场情绪常仍惯性下探，不是即时反转确认。这与第4课「弱转强=唯一最佳时机」的**左侧潜伏**

## 三、与大盘 wzs（relayIndex 口径）一致率 / 分歧清单

- 本状态机 wzs 入场 **7 日**；大盘 wzs 命中（`reference.marketWzs.hit`）**20 日**；**同日重合仅 1 日（10-23）**。
- **一致率极低是设计内**：两者锚点/判据根本不同——
  - 本状态机 wzs = **高位龙一命运**（断板后企稳/反包，E4 宽容）；
  - 大盘 wzs = **relayIndex 跳升**（T-1≤40 → T≥50 且 Δ≥+10）。
  一个看高位股是否被宽容，一个看情绪指数是否跃迁，**测的是轮回的不同侧面**（裁决 1A 并列参照，
  无预设权威，正是要把分歧摆给用户对照）。

## 四、结论与用户盘感终审引导

1. **突破（E1）= 确认性右侧信号**：次日情绪平均上行、波段起点；但天花板约 2 日后崩塌，宜快进快出。
2. **wzs（E4）= 左侧潜伏窗口**：次日情绪常仍下探，价值在「开始关注」而非「立即入场」；等突破确认。
3. **与大盘 wzs 低一致**：两锚测不同侧面，分歧清单是终审重点——请用户对照 2026 窗口案例裁决
   「高位宽容」与「指数跃迁」哪个更贴近其盘感的「弱转强」，或二者分层使用。
4. **压缩 0 / ice 0**：本窗无「3板归零」极恐慌日，ice 态未触发（如实，不硬凑）。
5. **暖机 20 天**（05-06→06-02）事件/状态不作可靠转折证据；终审以 06-03 起成熟窗为准。

## 五、局限

- 次日溢价用 ΔrelayIndex（市场级），未算信号日锚股个股次日收益（二期可补，需命运链逐日取数）。
- 样本量小（成熟突破 7 / wzs 入场 7），统计意义有限，**盘感终审优先于统计显著性**。
- 除权日 relayIndex/涨跌幅失真（既有 fail-visible），事件研究未逐日剔除除权日（二期精修）。
