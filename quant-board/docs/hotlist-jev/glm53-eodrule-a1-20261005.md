# 二、§4 六问归因与判读框架

归因顺序固定：①原料/数据供给 → ②判据与题目设计 → ③协议与解析层 → 最后方案重设计。以下逐问给「怎么判」。

## Q1 09-24 分歧日 —— 归因决策树

```

  ├─ 用户「退潮日」指什么？枚举可检验子命题：
```

## Q2 +2.44 系统性上移 / re-anchor —— 判据问题（锚定未随分布重定义），先排除数据层

- **①数据层**：+2.44 是 T5 重算迁移矩阵的确定性算术结果（T6 剔除 skipped 后 +2.37/76 天，不改变结论），非采集误差——数据层无罪。
- **②判据层判读框架**：
  1. 先问「上移是修正还是漂移」：拆 EOD 差值桶的成分（T6 §3：+≤5 桶 24 天、+≤8 桶 21 天、+>8 桶 9 天、−侧合计 23 天）。若上调主要来自「旧兜底退潮→新冰点/启动」（−6→−8/0，差值 −2/+6），且这些天的独立环境对照（jev 温度轴）不显示环境差 → 上移是旧级联低估的修正，re-anchor 无必要；若来自「启动→发酵/高潮」（+5/+8）的日子后验不撑 → 才有重标定理由。
  2. 再问「re-anchor 50 与重标定 REGIME_STAGE_ADJUST 是否同一自由度」：五值相对基准的偏移才是净效应，只挪基准=整体平移，同时移动 strong/normal/weak/retreat（70/50/30）跨线天数——**该 state 迁移矩阵 T6 未给，未知，必须先补（方向二产出）**。

## Q4 40/60 边界与 U 形 —— 判据问题（边界实证依据未复检），且互证可能跨体系

- **判读框架**：
  1. **体系对齐检验（第一步，最易被跳过）**：U 形是「生态宽度分位三档」的次日涨停均值（70.1/54.9/69.7），40/60 是「8 维合成 score」边界——先验证同一槽在两套分箱的秩一致性；若秩一致性低，「互证」不成立，U 形不能作 40/60 的证据使用。

  3. 自然分界 vs 40/60 的偏差方向逐月稳定性——参照 U 形先例标准（8+9 月稳定复现），至少 2 个月方向一致；
