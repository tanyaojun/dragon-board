## §一 P1-1 除权日 prev_close 失真修正（板序假阴根治）

### 病灶（已登记边缘 → 本轮根治）

- 登记处：`jev_driver_ammo.py:232`、`jev_label_jiuyan.py:496`「除权日 prev_close 失真属已知边缘」。
- 影响面：`sequence_line_from_bars`（板序 ●○ 判定用 `close[t-1]×(1+涨幅线)` 做阈值——除权日
  真实昨收=交易所除权参考价，TDX 原始棒的前收未除权 → 假阴漏板）；`position_line_from_bars`
  （20 日窗口最高/最低/涨幅未复权 → 除权像崩盘，距高点/窗口涨幅失真）；`board_shape_line_from_bars`
  （当日触板阈值用 `_prev_close_of_date`=`bars[-2].close` → 除权日全盘型误判）。
- 发生率：任一 10 日窗口内含除权事件的个股（分红送转季更高）。

### 方案（akshare 后复权链式因子，零判据改动）

- 因子源：mootdx/pytdx 无 xdxr 接口（实测 `.venv` 无 `get_xdxr_info`）；akshare 1.18.81
  已是项目依赖（market_proxy 在用），`stock_zh_a_hist(adjust="hfq")` 取后复权收盘。
- 核心公式（两路推导收敛，测试锚定）：**修正昨收(t) = raw(t) × hfq(t-1) / hfq(t)**，
  其中 raw(t)=TDX 当日收盘、hfq=akshare 后复权收盘。非事件日 hfq 比=raw 比 → 恒等回退
  `raw(t-1)`；现金红利/送转事件日自动给出除权参考价。
- 可信带防线：每条链校验 `|修正昨收/raw(t-1) − 1| ≤ 涨幅线 + 5pp`，超界（数据源错位/
  停牌重组）该链接回退 raw 并计数；异常链接 >0 时叙事行如实注记「除权修正部分回退」。
- IO 边界：akshare 取数放 runner 壳（`_hfq_closes`，按 code 进程内缓存 + 锁 + 0.15s 节流，
  失败返回 None=整股回退未修正口径 fail-visible，不炸 run）；ammo 只收 `hfq_closes` 字典
  纯计算。wiring 在壳内（`stock_position_line`/`limitup_sequence_line`/`_prev_close_of_date`），
  所有消费方（打标 pilot/zhaban 板序/relay 龙头档案）自动受益，调用点零改动。
- **精度声明**：hfq 值源为两位小数，因子比相对误差 ~1e-4 → 修正昨收误差 ~0.1 分；
  涨停价四舍五入临界股（真实收盘距阈值 <0.5 分）仍有翻转残余，预登记接受并披露。
- **代际**：`AMMO_VERSION 2026-10-05a → 2026-10-11a`（新文档盖新戳，旧文档缺新戳=旧代
  fail-visible）；**不整月重跑**（沿批次B 用户裁决先例：旧文档留档不回写，未来新打标自然用新代）。
- 成本：零 jev 调用；akshare 免费接口 ~150 股/日 ×1 次，进程内缓存。
- 验证门：①纯函数测试（现金红利+送转合成用例逐分锚定）；②生产抽验——挑 2-3 只近期除权股
  （10 月除权除息）板序行逐位人工复核 vs 行情软件复权图；③既有 hotlist 测试全绿。

### 回退

纯函数参数化：`hfq_closes=None` 即完整回退现行为；删壳内 wiring 一处即回原状。git 回退。

### §一附录：因子源三级实测定案（2026-10-11 实施当日，同日修订）

原方案「akshare 后复权链式因子」经实测定案为**百度除权除息日程 × 交易所公式**（更优：
精确参考价、每股零网络、每日 1 次调用替代每股 1 次）。三级实测证据链：

1. **东财源被墙**：`stock_zh_a_hist`（push2his.eastmoney.com）SSL EOF（重试 2 次同败）——
   本机网络环境限制，非接口消亡（阴性结论按日复测纪律）。
2. **腾讯 hfq 不可用**：`stock_zh_a_hist_tx(adjust="hfq")` 非纯事件链（无事件日恒等校验
   20/22 错，每日漂移~1%）——口径不符弃用；其 qfq 恒等 22/22 对，但每股 15-43s 延迟不可接受。
3. **定案**：`news_trade_notify_dividend_baidu(date)` 按日除权清单（分红/送股/转增三要素，
   **每10股口径**——603337 XD杰克科 实证：分红 3.00 元 → 参考价 34.70 = 35.00−0.30 ✓）×
   交易所公式 `参考价 = round((前收 − 每股分红)/(1 + 每股送转), 2)`。9 月试点窗口逐日覆盖
   实证（27/32/11 行）；603337 真实冒烟：事件命中+板序行带「除权修正已应用」注记。
   配股事件无配股价字段→该股回退原口径（fail-visible）；送转口径假设=每10股（与分红同表
   同约定，事件稀少，抽验门覆盖）。
4. **【2026-10-11 双线 review 补遗】可信带防线落地**：§一原设计的逐链接可信带在方案切换时
   曾被裁撤，review P1-3 指出配股混合事件会算出越界参考价（错数据比无数据更糟）→ 已补实现：
   `_adj_prev_series` 逐链接校验「当日真实涨跌幅 close/参考价 ≤ 涨幅板+5pp」，越界（配股混合/
   源错位）该链回退原口径；纯送转不受影响（真实涨停日恰在带内）。同批落地：失败负缓存
   300s 退避（防逐链接重试风暴）、百度改版列漂移校验（按失败处理不静默当无事件）、
   参考价 ≤0 守卫、conftest 全局 akshare 离线 stub（测试禁网延伸红线）。
