**2. 归因分析 – 9/16 边界判例最可能的失误层**  
| 可能层 | 说明 | 判据依据 |
|--------|------|----------|
| **① 原料** | 9/16 判例中「家数」远低于 p80（30 < 72），但「连板高度」刚好触及 p80（6 = p80），导致判据在「家数或高度」的“或”逻辑上产生歧义。原料中缺少对「单轴」与「双轴」的明确区分，使得模型在边界上产生不稳定判定。 | 证据显示仅有单一轴（高度）满足阈值，而另一轴（家数）明显不满足，导致判例落在「边界模糊」区。 |
| ② 判据 | 判据文本使用「家数或高度触及 p80」的宽松“或”逻辑，未限定「显著」或「双轴」要求，导致边界案例容易出现“仅一轴满足”即被判为「拥挤解除」。 | 判据原文未对「显著」程度给出量化阈值（如超出 p80 的幅度），缺乏对「单轴满足」的排除规则。 |
| ③ 协议/解析层 | 解析层对「或」的布尔实现是标准的逻辑或，未加入额外的置信度加权或冲突检测，导致判例直接通过。 | 协议层未对「家数」与「高度」的权重进行校准，未捕获单轴满足的潜在误判。 |

**最可能的根因**：**① 原料**（缺少对「单轴显著超 p80」或「双轴联合」的量化锚点），因为即使判据文字已写「或」，若没有对应的、可度量的原料支持「显著」概念，模型只能依据现有的单轴数据做出决定，导致边界判例出现。

**3. 优化方案（≤2 条）**

### 方案 1 – 收紧「家数或高度」判据为「两轴联合」  
- **判据文案 diff**  
  ```
  - 当日涨停家数或连板高度触及参照高位（≥p80） → 判为拥挤解除  
  + 当日涨停家数 **且** 连板高度均触及参照高位（≥p80） → 判为拥挤解除
  ```
- **锚定的可数证据清单**  
  1. 当日涨停家数（每日统计）  
  2. 连板最高高度（每日最高连板层数）  
  3. 对应的 p80 分位阈值（历史 20 日滚动分位）  
  4. 早帧拥挤状态标记（是否满足 crowding_score ≥阈值）  
  5. 收盘帧回落幅度（涨停数/最高板相对高位的回落比例）  

- **Pilot 设计**  
  - **窗口**：2024‑09‑01 ~ 2024‑09‑30（完整月）  
  - **数值化门判据**：  
    - `family_count >= p80_threshold` **且** `peak_height >= p80_threshold` → 通过；  
    - 任一未达标 → 进入「补原料」路径。  
  - **抽样**：随机抽取 200 只股票，确保行业分布均衡。  

- **预期失败模式**  
  1. **稀缺原料**：部分股票缺少连板高度记录 → 触发「补原料」流程。  
  2. **阈值过高**：导致大幅降低「拥挤解除」案例数，可能出现业务覆盖率下降。  

- **成本估算**  
  - 计算 token 消耗约 9 万 tokens（完整月 200 只股票的每日指标计算与对比）。  
  - 额外存储与查询成本约 0.12 USD（按现行云服务计费）。  

- **回退方式**  
  - 若业务覆盖率下降 > 5% 或模型召回显著下降，回滚到原「或」判据（保持原始阈值），并在 `config/rules.json` 中保留版本标签 `v2.5_original`。  

- **对 9/08 判例的影响评估**  
  - 9/08 案例的「家数」≥p80 且「连板高度」≥p80，满足「两轴联合」条件，仍判为「拥挤解除」 → **不受影响**。  
  - 若仅满足单轴（如仅家数或仅高度），将被划为「未解除」 → 进一步收紧判据的方向正确。

### 方案 2 – 引入「显著超 p80」阈值（单轴）并加入置信度加权  
- **判据文案 diff**  
  ```
  - 当日涨停家数或连板高度触及参照高位（≥p80） → 判为拥挤解除  
  + 当日涨停家数或连板高度 **显著超** 参照高位（≥p80 + Δ），且置信度 ≥ 0.75 → 判为拥挤解除
  ```
  （Δ 取 10% 绝对值或固定 5 家/5 层，视行业波动而定）  

- **锚定的可数证据清单**  
  1. 当日涨停家数与对应的 p80、p90 分位阈值  
  2. 连板最高高度与对应的 p80、p90 分位阈值  
  3. 置信度评分（基于模型输出的概率）  
  4. 早帧拥挤状态标记  
  5. 当日/收盘帧回落幅度  

- **Pilot 设计**  
  - **窗口**：2024‑10‑01 ~ 2024‑10‑15（两周）  
  - **门判据**：`value >= p80 + Δ` 且 `confidence >= 0.75` → 通过；否则进入「补原料」或「保留原判」路径。  
  - **抽样**：覆盖 150 只高波动股票（日均涨跌幅 > 5%），确保极端情况被捕获。  

- **预期失败模式**  
  1. **置信度波动**：模型在低流动性股票上置信度偏低，导致大量「未通过」 → 需要调低置信度阈值或补充流动性原料。  
  2. **Δ 设定不当**：若 Δ 过大，导致几乎无案例通过；若过小，收紧效果不明显。  

- **成本估算**  
  - Token 消耗约 7.5 万 tokens（两周窗口、150 只股票）。  
  - 计算资源额外 0.08 USD。  

- **回退方式**  
  - 若置信度阈值导致通过率 < 10%，回退至原「≥p80」阈值并记录 `v2.5_delta_original`。  

- **对 9/08 判例的影响评估**  
  - 9/08 案例的家数 71 ≈ p80（72）略低，连板高度 7 > p80 + Δ（若 Δ=5% 则阈值约 75），置信度 0.71 < 0.75 → **将不再判为「拥挤解除」**，从而体现收紧的实际效果。

**4. S1 / S2 终判决策树（四种组合）**  

| S1 状态 | S2 状态 | 路径 (归层/处理) | 量化判定标准 |
|---------|---------|------------------|--------------|
| **FAIL**（方差 < 12） | **显著**（S2 ≥ 显著阈值） | 1️⃣ **补原料再测** → 重新收集 3 天内的涨停/炸板原料，方差满足 ≥ 12 再进入下一层。 | - 方差 ≥ 12 重新通过；<br>- S2 ≥ 0.8（显著） |
| **FAIL** | **不显著** | 2️⃣ **恢复连续评分** → 降低 S1 方差要求至 10，暂时放宽 S1，进入「连续评分」监控窗口 5 天，观察趋势。 | - 方差 10 ~ 12 视为「弱通过」；<br>- S2 < 0.8 |
| **PASS**（方差 ≥ 12） | **显著** | 3️⃣ **定版归层** → 直接进入最终层级判定（如 `crowd_clearing`、`no_crowding`），无需补原料。 | - 方差 ≥ 12；<br>- S2 ≥ 0.8 |
| **PASS** | **不显著** | 4️⃣ **双轨并存** → 保持当前层级，同时开启「双轨」监测：一轨使用现有判据，另一轨尝试「补原料」或「收紧阈值」的实验分支，待 7 天后择优。 | - 方差 ≥ 12；<br>- S2 < 0.8 → 触发实验分支评估。 |

**量化阈值说明**  
- **S1 方差阈值**：12 为合格标准；10‑12 为「弱通过」可进入恢复路径。  
- **S2 显著阈值**：基于历史分布设定 0.8（对应上位 80% 置信度），可根据实际分布微调 ±0.05。

**5. 证据不足 & 需补原料的关键点（列出具体缺失项）**  
1. **连板高度的完整历史记录**：部分股票缺少每日最高连板层数，导致「高度」锚点缺失。  
2. **涨停家数的行业分位阈值（p80、p90）**：当前仅有全市场阈值，缺少行业细分阈值，影响判据的精准度。  
3. **置信度评分模型输出**：在低流动性股票上未生成置信度，导致「显著超 p80」判据无法评估。  
4. **早帧拥挤状态标记**：缺少对「早帧是否已处于拥挤形态」的统一标记，影响 `crowd_clearing` 的前置条件。  
5. **回落幅度的量化指标**：目前仅有文字描述「明显回落」，缺少具体数值（如回落比例 ≥ 30%）的可计量证据。  

这些点在当前数据集中均为「证据不足」状态，必须在 pilot 阶段通过补充原料（历史行情回溯、行业分位重新计算、模型置信度输出等）予以填补，方能保证新判据的可靠执行。
