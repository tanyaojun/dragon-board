# map_stage 中段方向感知预登记（2026-10-08，用户裁决「选A」；判定线冻结于回放前）

## 0. 一句话

`emotion_score.map_stage` 的 [40,60) 区间由「无条件 → 启动」改为「slope<0 → 退潮，否则 → 启动」，
修复「高位回落日被判启动」的方向性错误（2026-10-08 实证日：score 44.8 / slope −12.7 全天单边下行被判「启动」）。

## 1. 触发案例与归因（§1.2#6 顺序）

- 原料层：排除——emotion_score 与 jev 轨道同源（collect_slot_evidence），原料无差异；
- 判定方对照：jev EOD day_stage=退潮（11:00 起 retreat 连续 6 槽）；旧级联 `resolve_stage`（legacyCascadeStage）=退潮
  （09-30 同判退潮）——规则家族内部一致，唯一异端=新分数映射层；
- 映射层缺陷：40-60 区间 slope 不参与，而 slope（=当日上一有效槽分差，末步方向）正是区分
  「从 66 跌下来的 44.8（退潮）」vs「从 30 爬上来的 44.8（启动）」的唯一可用方向量。

## 2. 冻结判定线（先冻结再回放）

```
score >= 75           → 高潮（不动）
score >= 60           → 发酵（不动）
40 <= score < 60      → slope<0 → 退潮；slope>=0 或 slope=None → 启动   ← 本次唯一变更
score < 40, slope<0   → 退潮（不动）
score < 40, 其余      → 冰点（不动）
```

- slope 语义不变：当日上一有效槽 score 差（末步方向，接线层提供）；
- slope=None（缺数据）保持「启动」，不发明退潮（fail-visible：缺失不伪造方向）；
- slope<0 为冻结线（用户裁决方案 A 原文），**不做阈值调参**；斜率灵敏度分布仅作披露不作选线依据。
