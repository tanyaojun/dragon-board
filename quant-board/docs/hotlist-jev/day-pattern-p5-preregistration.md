## 一、步骤 0 · 机制核对（先决门）

**目的**：验证模型 day_pattern 作答与帧数据轨迹是否脱节（脱节则代理分析失效，且直接构成方案二的触发证据）。

**重构口径（冻结）**：
1. 逐帧数据 = 当日各槽位 doc 的 `evidenceRaw.limit.ztCount`（缺失帧跳过，fail-visible 如实计数，不插值）；
2. 当日参照 p50 = 该 EOD `narrativeRaw` 锚段「涨停数：p20=… / p50=**N** 家」正则解析（as-of 严格早于当日，与模型所见同源）；
3. 强帧 = ztCount ≥ p50；弱帧 = ztCount < p50。

**机械推导规则（八类，优先级冻结——时间形态类优先于水平类）**：
1. 在场帧（有 ztCount 的帧）<2 → insufficient（信息不足，不计入一致率分母，单列）；
2. late_rescue：末两帧均强 **且** 其余在场帧全弱；
3. low_recover：早盘帧（≤10:30）存在且弱 **且** 中后段（11:00–14:00）存在越线帧 **且** 末帧强；
4. rally_fade：13:00 前存在强帧 **且** 末帧弱（且 13:00 后存在弱于早半程峰值的帧）；
5. wide_swing：相邻在场帧强/弱切换 **≥3 次**；
6. steady_strong：在场帧过半强 **且** 末帧强；
7. steady_weak：在场帧过半弱 **且** 末帧弱；
8. narrow_range：其余（全部 <p50 且切换 <3 且不满足 7——即贴参照低位无形态）。

**一致率门**：机械推导档位与模型 day_pattern 答案的一致率 **≥80%**（分母=在场帧 ≥2 的 EOD）→ 允许用重构轨迹做代理分析；**<80%** → 判"模型作答偏离帧数据"，升级为方案二触发证据（§七触发条件②类），代理分析作废。

## 二、主检验 · 条件化次日读数分离

**分组（预登记冻结，不分不拆）**：修复组 = low_recover + late_rescue；强势组 = steady_strong；走弱组 = steady_weak + rally_fade。unclear/insufficient 样本剔除并计数。

**读数口径（冻结）**：
- 次日涨停数Δ = 次日交易日 15:00 帧 ztCount − 当日 15:00 帧 ztCount（`evidenceRaw.limit` 同源）；
- 次日最高连板Δ = 同上 maxBoard 差；
- 次日热榜收益 / dayWorst：与 crowding pilot S2 同源口径（fwdWorst）与 C9 账本池代理（次日池等权 pctChange 均值），执行时如遇缺帧 fail-visible——**9 月首读暂不计算**（行级回算留待正式执行），先读只出两个 Δ。

**方法**：Mann-Whitney U，双侧 α=0.025，Holm 校正（两组间比较族）。**方向预登记**：修复组 ≥ 走弱组（依据 v2.5 尾盘偷袭拆分理由："修复成色待验证"隐含修复日次日不弱于走弱日）；方向反转如实报告不作事后解释（C2 反向指标先例在案）。

## 三、结构检验 · 冗余度（同源偏差显式声明）

pattern 与 stage 来自同一 jev 调用（同源），结构检验只作冗余度参考、不作因果主张：
- pattern × day_stage 列联 Monte Carlo 精确检验（10⁴ 次置换）；
- 条件熵比 r = H(pattern|stage)/H(pattern)（Miller-Madow 修正）；**判读线：r≤0.7 独立信息充分；r≥0.8 近冗余**；
- n<40 只报告不判定。
