# 炸板链「大盘行」历史补数（2026-10-20，用户令「补炸板历史行情」）

> 背景：`jev-driver-label-v32-preregistration.md` §2.3/Z2 登记——炸板打标 67 个交易日、1701 只文档，
> **84.5%（1438/1701）写「大盘：不可考（帧缺失）」**：老 15:00 帧没有 `indices.sh`，
> `broad_market`（大盘拖累）判据在这部分样本上等于没有输入。09-28 起前向 100% 命中，历史不可回放。
> 本轮处置：**零写库、不动历史帧**，读侧补数——帧缺时用上证指数日线重算涨跌幅，行内标实际口径。

## 1. 落地

`backend/operations/jev_zhaban_label.py`：

- 新增 `_sh_index_change_pct(db, date)`（按 (dataset, date) 缓存），回退链：
  1. 15:00 帧 `indices.sh.changePct`（relay/情绪链同源，行尾标「15:00 帧」）；
  2. 本地 vipdoc `vipdoc/sh/lday/sh000001.day` 日线重算（close vs 前收，零外呼，标「本地日线重算」）；
  3. 线上 mootdx `index_bars(symbol="999999")` 日线重算（本地未落当日棒时，标「线上指数日线重算」）；
  4. 全缺 → 维持 `大盘：不可考（15:00 帧与指数日线皆缺，fail-visible）`，不补 0。
- 帧只落 `change` 点位的历史分支保持原语义（`±X.XX 点（涨跌幅缺失，点位口径）`——
  2026-10-16「-19.19% 假暴跌」事故口径，不回退）。

## 2. 实测（只读生产库，零 jev 调用）

| 项 | 结果 |
| --- | --- |
| 大盘行覆盖 | 67/67 打标日 **100% 可算**（60 日本地日线、10-20 由线上兜底——本地 vipdoc 未落当日棒） |
| 抽查值 | 06-10 −0.42%、09-10 −0.43%、10-16 +0.24%、10-20 +0.12%（与帧值 10-20 Δ0.002pp 一致） |
| **口径警告** | 帧值与日线重算**并不等价**：可比的 3 天里 10-16 Δ0.084pp、10-19 Δ0.374pp（10-19 帧隐含前收 3655 与 TDX 3716.28 矛盾，疑似帧侧错值）。因此：绝不把重算值伪装成帧值；**两列不得混用**，重算值只出现在帧缺的日子且行内带口径标注 |
| `dry-run` 验证 | 2026-06-10 华正新材：尾行 `大盘：上证今日 -0.42%（本地日线重算）`（原先「不可考」） |

## 3. 决策与边界

- **历史 1438 只标签不重判**：`broad_market` 只占答案的 0.2%（3/1701），为补一行证据把 1701 只
  全部重烧（≈152 万 tokens，≈$0.16，耗时数小时）不成比例；且重判会换掉非大盘证据下的原判定，
  与「历史文档不回改」惯例冲突。数据侧已 100% 可用，是否重判由用户按需点单（可按日期窗口小批回放）。
- 前向：09-28 起帧值本就 100%，本次改动对其零影响（仍走帧分支，仅新增「（15:00 帧）」标注）。
- 测试：`tests/hotlist/test_jev_zhaban_market_line.py`（12 用例：回退链四态、点位口径防伪造、
  `_pct_of_date` 边界、全缺 fail-visible），全 fake/monkeypatch，禁网。
