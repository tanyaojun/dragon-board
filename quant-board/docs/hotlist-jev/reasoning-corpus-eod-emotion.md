# EOD 情绪规则分 · 推理语料包（2026-10-05 组装）

**用途**：投喂强推理模型（GPT-OSS-120B `@cf/openai/gpt-oss-120b`，reasoning=high），对 **EOD 情绪分计算逻辑**做归因分析与优化方向研讨。
**使用方式**：pi 内 `/model` 选 `workers-ai: @cf/openai/gpt-oss-120b` + `/thinking high`，粘贴 §6 模板；或 Cloudflare Playground。单次成本估算：语料 ≈6-8k input + 2-3k output ≈ **$0.005/次**。
**边界**：本包只做语料预处理，**不改任何生产代码与判据**；任何采纳的改动走正常流程（配置 diff → 用户裁决 → 测试）。

## §2 切换战果（T5/T6 实测，2026-09-30）

**T5 迁移**（1069 槽 + 113 EOD 全量重算，slotErrorTotal=0）：
- 新旧 stage 一致率：槽位 **32.5%**、EOD 31.9%——预期内（切换意义=打破旧分布）
- 最大迁移流：退潮→冰点 **240 槽**（旧"无梯度兜底退潮"被斜率区分开）
- 高潮档从不可达 → **63 槽**（旧发酵 36 + 旧启动 18 + 旧退潮 9）
- 五档新分布：冰点 34.0% / 启动 38.1% / 发酵 12.7% / 高潮 5.9% / 退潮 9.4%

**T6 regime 影响**：
- EOD 层 meanDiff **+2.44**（系统性上移）；单槽极值 +14 / −8
- 类别门控迁移不对称：**放松门 ≈293 槽 vs 收紧门 ≈144 槽**——类别切换效应远超 regime ±2.44 线性分量
- 差值分桶=regime 输入差值分布（stage_adjust 是线性查表，其余四分量不受影响）

## §4 已知分歧与未决问题（推理主目标）

1. **09-24 分歧日（未裁决）**：旧级联判全天退潮；新评分判中段 42-60 启动为主（13:30 单槽 24.6 被 2 槽确认正确吸收）——新评分认为"热榜攻击结构仍在"。与用户"09-24 退潮日"盘感存在分歧，**待用户裁决是否调整映射边界**（透明可调，改边界=配置 diff）。
2. **+2.44 系统性上移**：EOD 层整体上移后，regime 基准 50 是否需要 re-anchor？注意 `regimeStageAdjust` 在优化搜索空间内，覆盖值回测需按其配置重映射。
3. **门控不对称风险面**：放松 293 槽 vs 收紧 144 槽——净放松环境下 D_EXIT_RISK/allow_* 门的行为变化是否需要 replay 量化（T6 已列为后续）。
4. **40/60 边界与 U 形**：40-60 禁入带与"生态宽度中档最差"U 形互证，但 40/60 两个数值边界的原始依据与当前评分分布的匹配度未复检。
5. **市况维度缺位**：量能轴、低开轴均实证市况依赖，但规则评分本身无市况态参数——是否值得引入（以及如何避免过拟合 9 月单一萎缩市况）。
6. **09-29 修复日对照**：新评分全天 61-79 有梯度（含 14:30 冲高 78.6 未确认回落），与"修复向上"叙事方向一致但日内形态与 jev 轨道仍有差异。

## §5 文档未覆盖、需代码佐证的缺口（诚实标注，勿让推理模型臆测）

## §6.3 使用要点

1. **先读代码再开火**：§5 缺口清单里的 `stage_confirm.py`/`slope` 定义/EOD 聚合公式未入语料，涉及这些的提问先让 pi 读文件补齐上下文，否则模型会臆测；
2. **不做正收益拟合**（用户裁决）：验证口径是「结构信号复现 + 门控迁移量化」，不是「调参到回测好看」；
3. **不预测谷、跟随状态**：谷前特征已证伪（T-1 精度 9%），任何「提前识别」方向的建议直接否；
4. **要判读框架不要结论**：问「09-24 类分歧日的归因决策树」，不问「09-24 到底该判什么」；
5. **产出处理**：模型的边界调整建议 = 配置 diff 提案，必须经 replay/回测验证 + 用户裁决才落产；模型输出本身不构成改动授权。
