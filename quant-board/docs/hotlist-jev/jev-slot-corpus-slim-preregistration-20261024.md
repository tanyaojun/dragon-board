## 2. 三刀方案（一轮一变量，顺序执行，任一刀不过门即停在该刀）

### 第一刀：恒真降级位降噪（确定性冗余，无语义损失）

- 改法：`collect_slot_evidence` 的「热度字段未采集」降级位保留计算（evidenceRaw 质量位
  不动，fail-visible 不减），**渲染层** `build_slot_jev_state` 改为仅当日首帧（无 priors 时）
  披露；后续帧的质量段省略该条（上游恢复即自动回到逐帧披露——恒真条件以代码判断为准，
  非硬编码日期）。日级链 `_aggregate_day_quality` 已按种类聚合计数，不受影响。
- 预期收益：每篇 ≈-20 字（全日 ≈-200 字 ≈-250 tok），小但零风险——该信息在同日其余
  帧的质量段与日级聚合中仍可见。

### 第二刀：已走帧压缩行字段瘦身（判据外语境证据删减）

- 候选删减组（`format_evidence_line` 压缩行，非当前帧全量段）：
  1. 热榜 TRIN（含涨跌向成交额后缀，≈25 字/行）；
  2. 主力净额（净额合计+正负家数，≈20 字/行）；
  3. 生命周期五桶（≈25 字/行）；
  4. 强资/风险行级标记（≈12 字/行）。
- 依据：八题判据与【近20日参照】锚均不引用这四组（逐条复核见诊断报告 §3-①）；
  当前帧全量段**保留不动**（Q1 当前帧题仍见全量语境）。
- 预期收益：满帧日 15:00 槽已走帧段 -25~30%，单叙事 -15~25%，日链 input -15~20%。
- 风险：这四组是「纯原始证据零规则输出」设计的一部分（语境证据），删后 stage/temperature
  落点可能漂移——**必须 replay 对照，不过门即回退**。

### 第三刀：已走帧滑窗（是否立项视前两刀结果）

- 早帧压缩行汇总为「峰值行」（峰值涨停/峰值真连板/炸板率区间/量能区间），仅保留最近 K 帧
  全行（K≈4）。收益最大（-30~50%）但行为漂移风险也最大；前两刀验收后若日链 input 已降至
  目标（≤30K tok/日），本刀不立项。
