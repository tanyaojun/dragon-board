## 2. 三刀方案（一轮一变量，顺序执行，任一刀不过门即停在该刀）

### 第一刀：恒真降级位降噪（确定性冗余，无语义损失）

- 改法：`collect_slot_evidence` 的「热度字段未采集」降级位保留计算（evidenceRaw 质量位
  不动，fail-visible 不减），**渲染层** `build_slot_jev_state` 改为仅当日首帧（无 priors 时）
  披露；后续帧的质量段省略该条（上游恢复即自动回到逐帧披露——恒真条件以代码判断为准，
  非硬编码日期）。日级链 `_aggregate_day_quality` 已按种类聚合计数，不受影响。
- 预期收益：每篇 ≈-20 字（全日 ≈-200 字 ≈-250 tok），小但零风险——该信息在同日其余
  帧的质量段与日级聚合中仍可见。

### 第二刀：已走帧压缩行字段瘦身（判据外语境证据删减）

- 候选删减组（`format_evidence_line` 压缩行，非当前帧全量段）：
  1. 热榜 TRIN（含涨跌向成交额后缀，≈25 字/行）；
  2. 主力净额（净额合计+正负家数，≈20 字/行）；
  3. 生命周期五桶（≈25 字/行）；
  4. 强资/风险行级标记（≈12 字/行）。
- 依据：八题判据与【近20日参照】锚均不引用这四组（逐条复核见诊断报告 §3-①）；
  当前帧全量段**保留不动**（Q1 当前帧题仍见全量语境）。
- 预期收益：满帧日 15:00 槽已走帧段 -25~30%，单叙事 -15~25%，日链 input -15~20%。
- 风险：这四组是「纯原始证据零规则输出」设计的一部分（语境证据），删后 stage/temperature
  落点可能漂移——**必须 replay 对照，不过门即回退**。

### 第三刀：已走帧滑窗（是否立项视前两刀结果）

- 早帧压缩行汇总为「峰值行」（峰值涨停/峰值真连板/炸板率区间/量能区间），仅保留最近 K 帧
  全行（K≈4）。收益最大（-30~50%）但行为漂移风险也最大；前两刀验收后若日链 input 已降至
  目标（≤30K tok/日），本刀不立项。

### 6.4 噪声地板控制实验（2026-10-24，用户裁决「选A」）

- **执行**：同一叙事（存档 evidenceRaw 重建）**零语义改动**原样重放 10-23 十槽，
  逐字节保真断言全过；typesafe 通道 10 次全 ok。
- **实耗**：input 42,013 tok / output 2,097 tok。归档 `data/backups/slim-noise-20261024.jsonl`。
- **读数**：
  | 口径 | 读数 |
  |---|---|
  | 全判位一致率（与第一刀同门） | **38/40 = 95.0%** |
  | 掷硬币判位（基线 top2 差<0.1 或置信<0.45） | 8 个，其中一致 6 |
  | **剔掷硬币后一致率** | **32/32 = 100.0%** |
  | temperature 最大 \|Δ\| | 3.6 分 |
- **结论**：
  1. **噪声地板实测 95%**——第一刀的 87.5% 与零改动基线（95%）都各有单次抽样方差，
     但分歧质量**完全落在掷硬币带**：两轮重放（零改动 + 第一刀）在非掷硬币判位上
     **双双 32/32 = 100% 一致**。即：**在可判位上，第一刀与零改动不可区分**。
  2. 原 90% 一致率门**确认不可用**（对零改动重放也只有 95% 余量）。
- **改门提案（待用户点头）**：对照验收门改为——
  **主判据：剔掷硬币判位（基线 top2 概率差 <0.1 或基线 confidence <0.45）后档位一致率
  = 100%；辅判据：temperature 全部 \|Δ\|≤5（噪声地板实测 3.6，留门 5）。**
  逐判位掷硬币标记以**基线文档的 probabilities/confidence** 判定（重放前即可算，
  无前视）。
- **第一刀在新门下的回看**：非掷硬币判位零分歧 → 新门下应为 PASS；但收益仍是最小
  （全日 ≈-250 tok），是否回收落生产由用户单独裁决（回收=重落渲染改动+槽级代际戳+重启）。
- **解锁**：新门落地后，第二刀（压缩行四组瘦身，预期日链 input -15~20%）可开对照
  （≈4.2 万 input tok/轮，开火另报备）。
