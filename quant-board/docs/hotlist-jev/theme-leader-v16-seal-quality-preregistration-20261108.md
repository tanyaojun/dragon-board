## 1. 问题登记

**现象**：续板题判据一直写着「封板质量」「封板质量异常」，空间题写着「封板质量显著占优」，
但叙事里 **没有任何可量化的封板质量数字** —— 只有结构行（首封时间/连板高度）与板内炸板面
（触板未封家数）。模型只能凭「封板早」这一条定性判断，无法区分「封单占流通 8% 且峰值未撤」
与「封单占流通 0.7% 且峰值已撤 60%」这两种完全不同的封板状态。

**原料其实早在库里（零新采集）**：`kpl_daban_pool.items` 自 2026-11-07 起按 2103 具名字段
+ quotas×28 全量落库，含 `zt_tur`（封单）、`max_zt_tur`（最大封单）、`real_float`（实际流通）、
`real_turnover`（实际换手）、`main_net`（主力净额）、`amount`（成交额）、`pool_state`
（sealed/broken）。2026-11-06 实测 33 只成员：

- 封单/实际流通比 0.22% ~ 8.72%（跨 40 倍，区分度充足）；
- 闽发铝业 5 连板 2.20 亿封单、主力净额 −0.59 亿（封住但资金流出，正是需要模型看见的形态）；
- `*ST亿晶` 5 连板封单/实际流通仅 0.71%（ST 连板语义不同，数字直接可读）。

**结论**：缺的是「把已落库字段送进叙事」+「让判据显式引用它」，不是新数据源。

## 2. 改动

### P1 语料行：`seal_quality_line`（个股级，排板内炸板面行后、基线前）

```
封板质量（KPL 涨停池 14:35 采集帧，非收盘帧）：主板龙一 红太阳：封单 0.77亿=实际流通 1.7%；
峰值封单 4.08亿（现为峰值 19%）；实际换手 14.3%；主力净额 +1.48亿=成交额 +24.9%
```

- 插入位置理由：板面事实（结构/梯队/炸板面）之后给「这只股自己」的量级；与随后基线行/空间锚
  相邻，便于判据「对锚 + 判据句点名封板质量」的引用链闭合。
- 板块级叙事（深度/延续）**不加**：基因/封板质量都是单股画像，「龙头分歧」仍由炸板面与结构行
  承载；实测不足再另起换代。

### C1 判据：续板题规则⑦ + 空间题规则⑥（题面原文见 `QUESTIONS_THEME_LEADER`）

- 续板题⑦：封板质量行 = 本行封板质量的**唯一可量化判据源**；偏离最细同桶一档以上须点名该行
  至少一项数字；该行不可考/单位待校验时禁调档、禁补 0；规则⑤（未封板断板反包）不适用。
- 空间题⑥：封板质量行可作为**锚外新证据**一类；偏离空间锚且引用封板质量时须点名具体数字；
  行不可考时禁据此调档。
- `criteria` 各档文案**一字不动**：档位语义仍由 instructions 硬规则约束，避免「改档位阈值」
  与「补数据行」两类变更混在一次换代里（v15 教训：桶校准与原料补行分开登记）。

## 3. 口径与单位自证（本轮最需要注意的坑）

`DABAN_QUOTA_NAMES` 只把 quotas[14]/[18] 命名为「封单」「最大封单」，**未与 App 逐列对照**，
即无法静态断言单位是元还是手。处置：

1. **元假设带校验（评审修订，双假设方案废弃）**：`r = zt_tur / real_float` 落 `[0.05%, 50%]`
   → 按元口径出行。废弃理由：元比率 r1 与手比率 r2=r1×100×price 在低价股区间可**同时落带**
   （数学上不可分）——单选手假设会输出放大 100×价 的伪封单额，单选元假设会把手真值低估
   100×价 倍，两向都是会被题面⑦消费的错数字。App 封单列以亿展示、quotas 数值元惯例
   （涨停委买额/实际流通实测=元）均指向元，故元假设先行。
2. **越界就退化**：元假设越界 → 只原样透出数值 + 「单位待校验」，**不出任何占比与峰值比**；
   缺实际流通 → 「单位待校验（缺实际流通无法自证）」。复核若证明单位=手，
   `_seal_unit()` 改返回 `("yuan", 100.0 * price)` 一处即可，行文与下游零改动。
3. **盘中实弹复核**（下个交易日，1 发）：同一时刻取 `GetStockPanKou`（凭据走
   `mapping_refresh.KPL_APP_BASE_PARAMS`，间隔 ≥2s），比对：
   - `封单额` vs `weituo.b1 价×量`（容差 ±15%，差异来自帧时点与撤单）；
   - `real_float` vs `actualcirculation_value`（±2%）；
   - `main_net` 符号与 `amount` 量级一致。
4. 复核不通过 → 把 `_seal_unit()` 的返回值固定为 `unknown`（一行改动），行退化为原样透出，
   **不重算历史、不猜换算**。

**其他口径**：

- `pool_state="broken"`（曾入池后炸板未回封）→ 标「最后封住帧 HH:MM，其后炸板未回封」，
  防止把 10:20 的封单当收盘值读；
- 采集帧早于 14:57 → 标「非收盘帧」（封单仍在变；2026-11-06 归档帧实测为 14:35）；
- **不消费**：`warn_tag`/`back_zt`/`stock_tag`/`financing_tag`（语义未破译或未定）、
  `zt_buy_amount`（涨停页常空）、`open_time`（收盘帧清空）、竞价四件套（次日信息泄漏风险）；
- **语料降级归因（评审 P1）**：涨停池日档缺失/读口异常/当日池空 → 行出
  「涨停池语料不可考（原因）」，**不**伪装成「不可考（今日不在涨停池）」——后者仅用于
  语料在场且查无此股；`fetch_pool_quality` 返回 `{"items", "degraded"}` 结构化原因；
- **峰值封单带校验（评审 P2）**：峰值占实际流通超出 `(0, 100%]` 物理不可能 → 不出读数。
