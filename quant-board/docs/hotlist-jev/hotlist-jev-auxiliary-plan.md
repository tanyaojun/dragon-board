## W1 复核工作台（分歧仲裁 + 退潮异议 + 边界复核，一个入口）

**目标**：把 jev 变成规则情绪评分的人工复核辅助面——你逐项看证据、点选裁决、落库归档，产出直接喂 W4 映射修订。

**复核项三类（v1 范围）**：
- **A 类·分歧仲裁**：登记的 4 个全槽分歧日（09-08/09-14/09-17/09-23）全部槽 ≈40 项——台账预登记的复核范围（规则"启动"40.6-59.7 vs jev 93% 判"退潮"的方向盲争议）；
- **B 类·退潮段异议**：规则档位 ∈{退潮,冰点} 而 jev sequence_stage ∈{start,ferment,climax} 的槽（防守端第二意见；retreat 段一致率 96% → 预计稀少）；
- **C 类·边界日**：EOD 分数距 40/60 边界 ≤3 分的交易日（连续分主定义的边界抖动暴露；日级 v1，槽级边界后置）。

**每项字段**：id（date|slot|type）、date/slot/type、规则侧（score/slope/rawStage）、jev 侧（sequence_stage/confidence/temperature）、narrativeRaw 首段（≤200 字）、次日池结果（历史项，帧池收益）、ruling（status=pending|rule_right|jev_right|ambiguous + note + ruledAt）。

**实现**：
- 后端 `backend/operations/jev_review_list.py`：只读聚合生成 → Mongo `phase_monitor` kind=review_items（_id=review_items:<date>:<slot>:<type>，幂等 upsert，已有人工裁决不被覆盖）；
- 路由 `hotlist_jev_routes.py` 增 `GET /api/hotlist-jev/review-list`（按日聚合返回）+ `POST /api/hotlist-jev/review-ruling`（写 ruling；同前缀无需动 proxy 白名单）；
- 前端：jev 第 7 页签新增"复核工作台"卡——分日折叠、项展开证据、四个裁决按钮（规则对/jev 对/模糊/跳过）+ 备注框，POST 落库；进度行（未决/已决计数）。

**验收**：pytest 专项绿（分类逻辑/幂等不覆盖裁决/ruling 校验）；vue-tsc 0 错误；浏览器验收用户本人做。

## W2 分歧哨兵（规则分链路数据质量监控，月度）

`backend/operations/jev_divergence_monitor.py`：月度一致率（五档/两档攻防/退潮段）+ 与基线和上月环比 + 告警规则（**五档一致率环比 |Δ|>15pp 或两档 |Δ|>10pp → 告警行**；机理=规则分上游数据代际/源故障会先表现为与 jev 独立管线的分歧率跳变，先例 emotionValue 205/1071 缺失）。产物入 phase_monitor kind=divergence，挂每月复检程序。基线（2026-09）：五档 27.2% / 两档 65.8% / 退潮段 96%。

## W3 N15 涨停驱动分类扩窗（阶段3 首个 PASS 级信号的存量验证）

- **暂缓解除后执行、再经用户终止（2026-10-01）**：启动后实测速率 ~10.8 条/分 → 全程需 ~37 小时，用户裁决"时间太长，立即终止"；**终止时落库 954 条 ok（覆盖 05-18 起 3 个交易日），已花成本 ≈$0.05**；
- **重启前置条件（若将来再做）**：脚本现状无 skip-existing（裸重跑会全量重打重花钱），需先加 `--skip-existing` 幂等跳过 + workers 提速（原 2），并把窗口/时长预估如实重报用户批准；
- **范围收窄重启（2026-10-01 用户指令"N15 达标，先跑 9 月份的未有的，不要全量跑"）**：`--skip-existing` 已实现（跳过当日已有 ok 标签、degraded 重试、断点可续）；本次窗口 **仅 2026-09-01→09-30**（21 交易日 / 4,525 股次 / 估算 ≈$0.23），5 月既有 954 条不动；后台运行中；
- **达标口径注记**：9 月单月跑完产出的是**参考读数**（Kruskal 分组+排序方向 vs 首验）；预登记的扩窗达标判据（全窗 p<0.05 且排序一致 → PASS_CANDIDATE）仍需完整窗口，是否继续补 8 月/其余月份由用户届时裁决；
- **9 月参考读数（2026-10-02 实测，4,525 ok / 0 退化 / 有次日匹配 3,239）**：
  - **排序方向 5/5 完全复现首验**：ma_restructure 17.2% > order_earnings 12.5% ≈ concept_stretch 12.5% > product_event 4.1% > capital_flow 2.8%（首验 21.3 > 14.3 > 11.6 > 4.1 > 1.8；两两方向 9/10，唯一"反转"是 order_earnings 与 concept_stretch 打平的 tie 伪影）——**驱动分类的排序信息在独立月稳健**；
  - **但 Kruskal p=0.5042 不显著**（极差 14.4pct 贴线）——首验 p=0.0007 未在 9 月子窗复现；机理候选：9 月缩量市组内方差压缩 + concept_stretch(n=1372)/product_event(n=1020) 两大组稀释；连板/首板分层：首板 13.0% vs 连板 7.8%（首板承接更好）；
  - 混杂警示沿用：ma_restructure 高连板率或含一字板买不进的幸存者偏差；掉出次日池的 ~1,200 条按缺失处理（与首验同口径）。
  - 决策材料：全量补 5-8 月 ≈19,000 股次 ≈$0.95 / 按当前实测速度 ~3.5h；补齐后方可用预登记判据正式裁决 PASS_CANDIDATE 或诚实收口。
- **用户裁决：不跑全量，课题挂起（2026-10-02）**——9 月读数归档即止；定论=**驱动分类排序方向在独立月稳健复现（5/5），但单月统计不显著（缩量市组间差被压缩），全窗显著性检验不执行**。将来若重启：`--skip-existing` 已备，`--start 2026-05-18 --end 2026-08-31 --skip-existing` 直接续跑（已打 5,479 条不重复计费），判据沿用预登记。本课题总成本累计 ≈$0.28（首验 $0.05×2 + 9 月 $0.23 量级）。
- 原始规格：扩窗 05-18→09-30（05-06~05-17 无 reason 数据缩窗），92 交易日 / 24,479 股次，理论成本 ≈$1.26。

## W4 五档映射方向维修订（裁决归档，用户裁决**暂不修映射**，2026-10-01 收口）

缺陷定位：`emotion_score.py:155 map_stage()`——`40≤score<60` 无条件"启动"，斜率仅 <40 段生效（方向盲）。修订候选（例：40-60 且斜率<0 → 退潮）从 W1 裁决归纳 → 预登记冻结 → 版本化实现+golden 锚（无键逐位不变）→ 全量重算 → 对比读数（分歧日修正数/档位分布/jev 一致率/EOD regime 影响）→ 用户盘感复核 → 翻默认裁决。**爆炸半径注记**：五档映射只驱动展示/叙事/regime 标签；四带相位轴用分数本身（40/60 切），不受影响。

**复核裁决归档（2026-10-01，用户 44 项人工裁决完成，数据在 phase_monitor kind=review_items）**：
- 裁决分布：A 分歧仲裁 **4/4 jev 对**、B 退潮段异议 **19/19 jev 对**、C 边界日 21 jev 对 + 1 规则对（09-30 59.1）+ 7 自动一致；44/44 一边倒。
- **三重证据收敛**：用户裁决 × 四带交易解剖（40-60 弱势带逐月皆亏 −2.05%/笔、10-40 冷带 +3.68%/笔）× jev 对照（规则"启动"槽 jev 93% 判退潮）→ 同一结论：**现行 40 分判界错位，启动实质区间在更低分段，40-60 实质是退潮/弱势**。
- 已呈两方案：方案一（40-60 且斜率<0→退潮，幅度不足——A 类 slope<0 仅 3-5/10 槽）vs 方案二（40-60→退潮/27-40→启动，EOD 退潮 17→49、启动 42→31）。唯一反例 59.1（规则对）与 58.7（jev 对）互斥，属边界噪声未迁就。
- **用户裁决：暂不修映射**——裁决数据归档留证，40-60 判别问题继续由 **C6 弱势带（分数轴 40-60 不开新仓）** 在交易层解决，五档语义保持现状；将来若修，本节证据链（裁决+双方案影响面）可直接续用。

**原料一致性排查（2026-10-01，用户指令"排查规则文档和 jev 模型的输入原料是否一致、差在哪里、找分歧原因"）**：
- **原料层真同源**：两边消费同一聚合器 `collect_slot_evidence`（jev_state.py）——同一帧 limitSummary/指数/总成交额、同一行情行、同一昨日行、同一 lifecycle join；两个服务层取数互为复用（hotlist_sentiment_compute 注释明示"口径同源"）。分歧不来自数据不同。
- **分叉点一·参照系（最大）**：规则分每维做历史分位校准（涨停 30 家→历史 25 分位→25 分），jev 拿绝对数字+五档文字语义，无历史分布参照（temperature 十档锚也是绝对语感）→ 40-60=历史平庸区，规则只能输出"平庸"，分不清"高潮跌落的平庸（退潮）"vs"冰点爬升的平庸（启动）"。
- **分叉点二·结构证据 jev 独有**：焦点个股 top8（题材/涨幅/涨停/生命周期/热度）+ 涨停原因 top5 + 当日逐帧序列——"高位股集体走弱"（退潮核心判据）只有 jev 直接可见；规则分里被稀释成风险行计数/广度变差，滞后且钝。
- **分叉点三·方向信息原料有、映射层丢弃**：jev sequence_stage 天生看当日逐帧序列；规则有 slope 但 map_stage 40-60 段不看（只 <40 用）——44/44 裁决实证的方向盲是映射层问题。
- 次要：规则风险维校准偏宽（riskRowsPct P10=84.7→90 分区分度压缩、高潮压制条款已删）；缺失处理不同（jev 逐项标注 vs 规则缺维归一）；昨日承接已同全池口径。
- **结论**：规则分=历史分位温度计（精确无结构无方向语义），jev=结构+序列判读器（有结构有方向无历史锚）；分歧集中爆发在"中段平庸区+高位走弱结构日"，机理自洽。**原料层无需修改**；将来修映射的最硬方向=给映射补结构/方向维输入，而非换原料。
