# 题材龙头语料去开发语义：桶键中文化 + 题面术语对齐（2026-11-17b）

> 预登记性质：题面一词变更（hash 换代）+ 纯语料渲染改版。用户裁决（2026-11-17，
> 西陇科学 002584 案例续审：「还有开发语义混杂在里面，比如『同桶』」）。
> 前批：`theme-leader-corpus-slim-20261117.md`（2026-11-17a，三档精简，题面 hash 不动）。

## 1. 问题

2026-11-17a 精简后语料仍残留程序内部语义：

- 结构基线/空间锚行直投**分组桶键**：`同桶[streak1|n>=8|early<=10:00]`、
  `按连板高度[1]`、`按板块家数[>=8]`、`按封板时间[early<=10:00]`、`按跟风梯队[3]`、
  `按昨日承接[prev0]`——`streak1`/`early<=10:00`/`prev0` 是程序查键，不是市场语言；
  「同桶」本身是开发术语。
- 梯队形态行 `（领先 持平）` 语义杂糅；非零差 `（领先 +1）` 缺单位。
- 基因行 `溢价5%2次` 数字粘连歧义（溢价5% 与 2次 无分隔）。
- 催化原文 `正文更新 2026-10-20=28 天前` 等号拼接是程序计算风格。
- 解析摘录枚举压缩+句界截断叠加产出 `等。…` 双省略号杂糅。
- 枚举压缩边界 bug：短引导句场景（如「1、试剂包括过硫酸钠、…」，「试剂包括过硫酸钠」
  恰 8 字可成项）编号「1」独立成首项**占用前 3 保留槽**，致实际保留化学名不足 3 个
  （旧输出仅 2 个；长引导句生产路径未触发，测试抓出）。

## 2. 题面消费面核对（改前逐题扫描）

- 续板题① literal 消费「同桶」一词 + 「方括号条件最全」识别机制 + 「按连板高度」桶名；
  **不消费字面桶键**（括号内容通配）。→ 叙事改「同结构[中文条件]」必须题面同步改一词。
- 空间题①「最细出率桶」无「同桶」字面；rebound 题消费空间锚行存在性。→ 无需改。
- 身位题 literal 消费 `Top3`/`领先差`/`真连板` → **保留不动**（域术语，非开发语义）。
- 板块级两题（depth/continuation）不消费结构基线行 → 共享渲染改版零题面影响。
- 程序侧叙事解析器两处（`theme_leader_label._anchor_deviation_audit` /
  `theme_leader_seal_stats._anchor_observation_fields`）正则锁「结构基线：同桶[」前缀
  → 同步改「同结构[」（括号内容通配不受中文化影响）；src 审计标签保持内部术语
  「同桶」（结构化字段，不进叙事）。

## 3. 改动清单

**题面（一词，hash 换代）**：续板题①「最细出率同桶」→「最细出率同结构桶」。
语义零变化（识别机制「方括号条件最全且样本≥8」与回退桶名不变）。
`QUESTION_SET_HASH_THEME_LEADER`：`8c6c94429abd` → **`eb9cfae4139e`**（自动重算）。
QUESTION_SET_VERSION 保持 v17（术语对齐，非语义重写）。

**语料渲染（AMMO 2026-11-17a → 2026-11-17b）**：

1. 桶键中文化单一源（`bucket_cn`/`combo_cn`，结构基线/空间锚共用，禁第二套）：
   - `同桶[streak1|n>=8|early<=10:00]` → `同结构[1连板·板块≥8家·首封≤10:00]`
   - 单维桶值带单位：`[1板]`/`[≥8家]`/`[≤10:00]`/`[3家]`/`[0家]`；
     时间桶 `mid<=13:00`→`10:00后~13:00`（review n1：early 含恰 10:00，「后」消边界歧义）、
     `late>13:00`→`>13:00`；unknown→`不可考`。
   - **原始键不动**：`combo_key`/各 `*_bucket` 分组、落库审计、基线脚本查键单一事实源不变。
2. 梯队：0 差 `（领先 持平）`→`（与次高持平）`；非零差补「板」单位（`领先 +1 板`，
   与身位题「领先差≥1 板」同口径）。
3. 基因：`溢价5%`→`溢价5%以上`（`溢价5%以上2次` 消歧；落库 gene 六字段不动）。
4. 催化新鲜度（digest，板块级催化原文/产业树补充映射两处）：`正文更新 X=N 天前`
   → `正文更新 X，N 天前`（逗号分隔，括号为外层统一边界）。
5. 摘录截断（digest `_clip_excerpt`）：句界尾「。…」→「…」（句号让位省略号，
   删节披露不变；先删尾「。」再剔编号空头，防「N、。」尾 bypass，review n2）；
   枚举压缩 `_ENUM_RUN_RE` 起始位禁「数字、」编号头（lookahead，项内数字不受影响；
   已知边界：纯数字枚举全起始位被禁不再压缩、中段编号头仍入项，语料罕见，备查）。

## 4. 路径边界

- 桶键中文化只改 `baseline_line`/`headroom_anchor_line` 渲染层；龙头/板块级叙事共享
  同函数同批生效（板块两题不消费基线行，零判据影响）；竞价链不消费这两函数。
- 催化新鲜度/摘录截断在 digest 证据块，龙头/板块级/竞价共享——纯措辞，判据零引用
  （题面扫描确认无「天前/正文更新」literal 消费）。梯队/基因措辞同样经共享渲染函数
  （board_ladder_line/zt_gene_line）传播至板块级与竞价链：竞价题面只语义消费
  「领先差≥1 板/Top3」，无「领先 +N」「溢价5%」literal，已验证无害（review 核查项 7）。
- `Top3`/`真连板`/`领先差`/`中位再走`/`均值` 等题面消费域术语保留。
- 封板质量行单龙一前缀维持前批裁决（明确保留项），不在本批范围。

## 6. 可比性

题面 hash 换代 → **跨代不可比**：`8c6c94429abd`（2026-11-17a 及以前 v17）与
`eb9cfae4139e`（2026-11-17b 起）评估必须分段；Brier/验收门槛按代际各自累计。
术语对齐不改判据语义，预期分布漂移极小，但按纪律不做跨代合并结论。

**机制落地（review M1 修复，2026-11-17）**：本批是 v17 live 标答期内首次「hash 换代
而 version 不动」，pilot_eval 原分代键仅 version → 两代会静默合并进同一验收队列，
与本节声明矛盾。已修：`_sample_row` 增带 `questionSetHash`；同 version 含多 hash 时
按 `version@hash` 拆分 `versionMetrics`（单 hash 版本原键不变，输出形状零变化）；
`versionHashes` 审计维度随报告透出；`_v17_groups` 增 hash 过滤，多 hash 日按 hash
拆子报告（`v17GroupsMixedHash`）不出跨代并集。回归：
`test_same_version_multi_hash_generations_not_aggregated` /
`test_v17_groups_split_by_hash_when_mixed`。
