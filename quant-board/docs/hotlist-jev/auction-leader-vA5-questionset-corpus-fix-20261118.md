## 2. 头号修复：板块判答注入死代码（运行层 bug）

**根因**：`_label_one` 把 answers 写进 DB doc 但从不回写 `built["answers"]`；run() 板块标注循环
`sector_answers[board] = b.get("answers") or {}` 恒取 {} → `sector_judgment_line({})` 恒 None →
**首跑全链龙头 doc 板块判定行永远缺席**（sectorJudgmentState 恒 sector_missing）。重跑场景被
DB 预载 + 冻结叙事掩盖（旧测试只锁重跑 state，不锁首跑叙事）。广百案实证：板块 doc 09:29:06 ok
（climax 0.09/weak_extend 0.59），龙头 doc 09:29:10 sector_missing。探针复现：首跑 sector answers
在场（fermenting）而龙头叙事无板块判定行。

**修复**：`_label_one` 返回前 `built["answers"] = answers`（一行）。新增首跑注入回归测试
`test_fresh_run_injects_sector_judgment`（锁叙事含板块判定行，不只锁 state）。身位题规则③/
core 判据「板块判定活跃」/证据清单自此可达（v17 题材链 A2 悬空修复的同款失效，竞价链漏修）。

附带观察（登记）：贫料下板块 depth 判答近均匀（climax conf 0.09）——注入行已带置信披露，
是否给注入加置信门待裁决；本轮不改。
