## 一、方法论要点（第4课原文）

1. 情绪 = 恐慌/兴奋 → 演化为**亏钱效应与赚钱效应的轮回**，即周期。工具 = **市场情绪监控表**（连板梯队 + 高位股命运逐日记录）。
2. 四大可数特征：

| 效应 | 特征 | 原文判定细则 |
|---|---|---|
| 赚钱 | 高位宽容 | 看 2 天：龙头断板后震荡两天不崩塌（数源科技式），或断板后反包（金发拉比式）。本质=最激进的接力资金在不利走势下仍能安然离场 |
| 赚钱 | 空间突破 | 看 1 天：突破上一个连板空间天花板（4 板空间亏钱→有人疯狂买 4 板甚至上 5 板）；一字板突破更容易成功（极恐慌→极兴奋）。稀缺事件（原文 2023 全年约 3 次） |
| 亏钱 | 高位崩塌 | 看 1 天：空间龙头连板后直接按跌停（恒银科技式）；看 2 天：无跌停但连续大跌、无人承接（大湖股份式） |
| 亏钱 | 空间压缩 | 与高位崩塌相伴：3 连板以上归零、天花板下移（原文 2023-06-16 案例） |

3. **唯一最佳时机 = 情绪弱转强**（亏钱→赚钱的转折点）：恐慌缓和（高位被宽容以待）→ 资金尝试空间突破 → 赚钱效应标杆诞生。
4. 空间打开后以情绪龙头为锚做横向（高位人气股）/纵向（题材板块）衍生——与第3课（题材周期，龙头锚）、第5课（板块弱转强，指数+家数锚）的接口。
5. 体系定位：**第4课市场级择时（什么时候做）→ 第3课题材级（做哪个题材）→ 第5课板块级（板块入场点）**。本课题只补市场级转折判定层，不改动第3/5课已实施件。

## 四、事件定义（P1，提案；盘后判定，缺原料→不命中+结构化 reason）

事件主体 = 市场空间龙一（两轨各判，事件带 `track` 字段）。作用域 Q2 已裁决 = A：v1 仅锚作判据，≥4板高位群体命运仅进监控表展示。

### E1 空间突破 `space_breakthrough`

- 判据：今日 maxBoard **>** 近 20 个交易日 maxBoard 最大值（严格大于；持平=未突破）。
- 附带事实：突破股 code/name/track/streak、是否一字板（板型复用封板质量/TDX 板型单源；不可考→注「板型不可验」，不猜）。
- 稀缺性登记：原文约 3 次/年；回填窗 126 天预期 0–3 次，**为 0 如实报告，不硬凑**。

### E2 空间压缩 `space_compress`（v2，2026-11-12 用户改门）

- **v2 判据（现行）**：**连板空间高度持续打不开**——`maxBoard ≤ 4`（突破不到 5 板）**连续 ≥2 个交易日**
  （自第 2 个连续低位日起命中）。常量 `COMPRESS_MAX_BOARD=4` / `COMPRESS_MIN_DAYS=2`；持续段由
  `compress_low_streak` 从天花板序列算（None 断链 fail-visible）。
- **改门记录（2026-11-12，用户裁决）**：v1「今日 ≥3 板家数=0 且昨日 ≥1」（3板以上归零转折）全窗
  0 命中——本窗 maxBoard 最低=3 从未归零，不贴合冰点。用户盘感：**6月=趋势行情（权重趋势涨、
  连板小票接力情绪低）= 天花板卡 3-4 板持续多日 = 冰点/压缩；9月以来空间打开，真连板行情=10月后**。
  故精确为「空间高度持续打不开（≥2日）」regime 口径。试跑验证：6月 06-09→06-16 连续6天卡3-4板精准
  命中、9月短暂压低口袋（09-10→14）正确、10月突破 gain 主导。阈值≤4、9月口袋、ice 直入语义均获用户批准。
- **状态机语义（v2）**：E2 命中**任何态直入 ice**（regime）；E2 解除且无其他事件 → ice 退 loss
  （`space_compress_lift`，不再永久自持）。优先级 E1>E3>E2>E4 不变（崩塌/突破日可覆盖 ice）。
- v1 归档：旧「归零转折」口径废弃（git 历史可溯），检测器/测试随 v2 重写。

### E3 高位崩塌 `high_collapse`（主体 = 昨日市场空间龙一，两轨各判）

- **1日型**：昨日空间龙一今日跌停（`is_limit_down_pct`）。
- **2日型**：昨日空间龙一今日+昨日均大面（≤-5%）且两日均未跌停、均未封板（无承接）。
  - 注：封板日涨幅为正不可能大面，故 2日型主体天然为已断板高位股——与原文「没有跌停但连续大跌」一致。
- 主体哲学 = 「昨日龙一的今日命运」（与 sector_nodes `leaderState` 主语一致）；龙头更替后旧龙命运不入判据（仅展示，Q2 可扩）。
- ≥4 板高位群体跌停/大面家数：描述字段进监控表，v1 不作状态机判据（Q2）。

### E4 高位宽容 `high_tolerance`（主体 = 昨日市场空间龙一中断板状态者）

- **反包型**：锚股最近 3 日内最近状态 = broken（`day_status_of`）且今日 sealed → 即时事件（最强形式，原文金发拉比）。
- **企稳型**：断板日 = day0，其后**连续 2 个交易日**（day1/day2）每日均「未跌停 且 未大面 且 未封板」→ day2 收盘出事件（原文「震荡两天不崩塌」，数源科技/中大力德/华西股份）。
  - 「稳住高位」操作化 = 未跌停 + 未大面（冻结口径，不新增阈值；是否加累计跌幅约束见 Q4）。
  - 窗内再断板 → 以最近断板日重置 day0；窗内封板 → 走反包型。
- 高位宽容本质 = 接力资金不利走势下安然离场，故「未跌停+未大面」即充分（Q4 倾向）。

## 五、状态机（P2，提案）

### 5.1 词表与输入

- 四态：`loss`（亏钱效应）/ `ice`（冰点）/ `wzs`（弱转强窗口）/ `gain`（赚钱效应）。
- **输入 = 事件流 E1–E4 only**。relay_phase / 规则五档 / jev 五档 / 大盘 wzs（relayIndex 口径）= 并列参照，只读快照进 doc 供前端对照，**不进判据**（裁决 1A）。
- 市场周期永续轮回，**无吸收态**（与 theme_cycle terminal 不同）；全态可逆。

### 5.2 迁移表（优先级高→低，取当日最高优先级命中；theme_cycle 同构）

| 优先级 | 条件 | 迁移 | 原文依据 |
|---|---|---|---|
| 1 | E1 突破命中 | 任意态 → gain | 空间突破=赚钱效应标杆诞生（一字板突破=极恐慌→极兴奋，V 型直接确认） |
| 2 | E3 崩塌命中 | 任意态 → loss | 高位崩塌=亏钱效应，赚钱效应消失 |
| 3 | E2 压缩命中（v2） | 任意态 → ice；ice 自持 | 空间高度持续打不开≥2日=冰点 regime（2026-11-12 改门） |
| 4 | E4 宽容命中 | loss/ice → wzs；gain/wzs 自持 | 恐慌缓和=弱转强窗口开启（唯一最佳时机） |
| 5 | 无事件 | loss/gain/wzs 自持；ice → loss（压缩解除） | days-in-state 披露；ice regime 解除退 loss（space_compress_lift） |

- **同日 E3+E1 冲突（旧龙跌停+新股破天花板=龙头更替）：Q5 已裁决 = B，E1 优先判 gain**（空间仍开放=更替非崩塌，第3课龙头更替哲学；旧龙个体命运≠市场亏钱效应）。优先级序冻结为 **E1 > E3 > E2 > E4**。
- wzs 窗口 v1 **不设超时**（Q3）：无突破无崩塌则自持，days-in-state 披露，回填分布出来后再裁决是否加窗。
- 首日默认态：无事件 → loss（保守默认，非判据判定）+ warmup 披露（Q6）。
- 迁移落痕：`transition {from,to,trigger,evidence,date}`（theme_cycle 同构）；事件证据带 track/code/数值。

### 7.1 它为什么从未进入生产链/龙头节点（文档史，2026-11-12 侦查补录）
