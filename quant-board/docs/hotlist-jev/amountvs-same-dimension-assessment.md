# 评估：量能同期（amountVsSame）第八评分维的贡献率与启用影响（2026-10-06）

> 触发：用户问「totalAmount 对帧级情绪分的贡献率？启用第八维后 EOD 均值会不会大变？」
> 方法：纯离线模拟——从 `market_daily_amount` 参考集合（TDX 综指口径 150 日）取逐日 vsSamePct，
> 按校准曲线插值得第八维 sub，注入 113 个 EOD 文档维度均值（`compute_emotion_score` 等权纯函数）。
> 明细：`data/backups/amountvs-same-simulation.json`。零写库、零模型调用。

## 一、贡献率

- **权重**：评分八维等权（`_WEIGHTS` 全 1），启用时贡献权重 **1/8=12.5%**；当前全历史 113 天该维全部 skipped（**实际贡献 0%**）——历史帧无 `indices.totalAmount`（09-30 才接线），vsSamePct 无从计算。
- **sub 值水平**：历史 vsSamePct 分布中位 **−1.0pp**（p10 −13.3 / p90 +13.7，范围 −21.4~+26.0），映射到校准曲线后 sub 中位 **49.2**、均值 50.7——落在 50 中性锚附近。

## 二、若启用：EOD 均值几乎不变，但极端信号被系统性稀释

| 项 | 读数 |
| --- | --- |
| EOD 分数均值变化 | **+0.11 分**（n=113，范围 −4.8~+5.9，\|δ\|≥5 仅 4 天）——均值不会大变 |
| 75 高峰线穿越 | 6 天，**全部「跌出」**（高峰日被压回） |
| 30 深谷线穿越 | 5 天，**全部「收复」**（拉出深谷） |
| 25 深谷线（C9 门）穿越 | 3 天，**全部「收复」** |
| 40 相位线穿越 | 6 天（方向同机制）；60 相位线 0 天 |
| 深谷日（cur<30，n=14） | 均值 24.2 → 27.4（**向 50 拉升 +3.2**） |
| 高峰日（cur≥75，n=11） | 均值 77.7 → 74.7（**压回 −3.0**） |

**机制**：vsSamePct 常态在 0 附近 → sub 常态 ≈49 ≈ 中性锚 → 加入均值 = 把极端读数向 50 回归。而深谷（<25/<30）、高峰（≥75）、C9/C10 全部是「极端读数即信号」的定义——第八维对均值无害，**对尾部信号是单向稀释器**（20 次阈值穿越无一例外指向中位）。

## 三、其他两项否决因素

1. **曲线未校准**：`_CALIB["amountVsSame"]` 注释自证「设计值待积累 ≥20 交易日后校准」（±30pp 才到 25/80 分）。历史 vsSamePct 实测 p90 才 +13.7pp——设计曲线的陡峭段与实际分布错位，直接启用=把设计值当真值。
2. **T+1 预测力增量为零**：EOD 对照实验（本目录 v2 报告）实测量能类候选统一同窗偏相关 C9b −0.047 / C9m +0.05，全部不显著且 Q3-only——第八维不带来分数的预测力增量。

## 四、建议：暂不启用，数据先积累

1. **不启用**：均值收益 +0.11 对不上尾部信号稀释 + 阈值重校准（C9/C10/深谷/高峰账本全部重生成）+ golden 重录 + 7-9 月帧回填的联动成本。
2. **积累替代**：每日用 `market_daily_amount` 参考集合记录 vsSamePct（只记录不评分，成本≈0），20+ 交易日后得到真实分布，再校准 `_CALIB["amountVsSame"]`。
3. **重启条件**：校准后若 sub 分布系统性偏离 50（如缩量季稳定 30-40）且对 T+1 出现可检出的预测增量，届时以「全窗帧回填 + 第八维启用 + 全阈值重校准」单独立项执行。
