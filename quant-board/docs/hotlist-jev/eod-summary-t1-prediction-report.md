## 〇、结论先行（v2 人话版）

1. **EOD 终值保持现任——且被加强**：扩窗+修复后，EOD 对「明日池高开」的预测力从 +0.32 升至 **+0.36 [+0.18,+0.51]**（n=102）；全天均值挑战者仍然全面落败（最强格 +0.22）。两个季度独立成表后结论各自成立（Q2 +0.25 / Q3 +0.42）。
2. **新增市场级对照让边界更清楚**：EOD 分预测的是**热池**的次日开盘结构（高开 +0.36、高开砸占比 +0.28），对**大盘指数**几乎无预测力（指数高开 +0.01、指数收益 −0.05）。它是热钱情绪计，不是大盘温度计。
3. **净收益：所有候选、两个季度都预测不了**（Y5 全窗 +0.12 不显著；Q2 +0.07 / Q3 +0.17）。v1 判断维持。
4. **【撤回】v1 的「C9b 缩量→次日高开砸 +0.40」是 8-9 月小窗伪象**：全窗 +0.08（n=98），Q2 −0.04 / Q3 +0.20，统一同窗偏相关 −0.05。这是本轮用户保留意见换来的最重要修正。
5. **H1（高开低走+缩量+尾盘拉→次日砸）维持「样本不足结案」，且 v1 的检验本身有错**：审查发现 v1 条件②阈值在比率单位下 49/49 永真（等于没检验）；修订 3 重定标后，绝对阈值 1/105 触发、分位数式 0/105 触发——这个完整形态本身就是稀有事件。
6. **市况依赖第五次复现（分季度版）**：EOD↔池收益 Q2 +0.07（无）vs Q3 +0.17（边缘）；同一分层在池高开上是 Q2 +0.25 / Q3 +0.42——「EOD 分的所有预测力都在退潮期更强」跨季度一致。

## 三、H1 专项（修订 3 口径）

- 基线 105 日；条件②重定标后（C9m ≤ −0.05，居中 0 的对昨日半场比值差）：**绝对阈值 1/105 触发（9-14），分位数式 0/105 触发** → 两种读法都「样本不足结案」。
- v1 报告的「9-14 触发」不可信：当时条件② 49/49 永真，等于只检验了①③；9-14 在修正口径下恰好也是真缩量日（C9m ≤ −0.05），但单日不可判。
- 成分拆解（全窗）：尾盘拉升 → 次日池高开 +0.37（稳健）；「缩量」成分 → 高开砸 +0.08~+0.25 且仅 Q3 驱动（不稳健）。**用户的「缩量+尾盘拉→砸」：尾盘拉一半成立（高开），缩量一半存疑（仅退潮期）**。
