## 一、P2 范围（三块）

1. **显式周期状态机**（裁决 3 核心）：每板块一个当前态，词表
   `主升 mainrise / 转弱 weakening / 弱转强 wzs / 终结 terminal`；
   输入=sector_nodes 节点序列 + P1 事件流（`hotlist_jev_leader_wzs`），
   确定性、零 token、全历史可回填；每次迁移落痕（from/to/触发证据/日期），
   无证据不得迁移（fail-visible）。
2. **日内弱转强疑似层**（裁决 3/6）：KPL socket（3006）触板判 + 盘口封死
   proxy，盘中三态显式（`未触板 / 触板未封 / 疑似封死`），疑似永不计完成态；
   盘后 THS 池复核，疑似未确认保留原态+显式回退痕迹。
3. **前端展示**：盯盘清单/连板行情页加「周期状态 + 窗位 + 新龙事件」列；
   状态与节点分歧时并列披露不互相覆盖。

附带（评审遗留）：`build_and_save_leader_wzs` 挂盘后定时步（schedule.py
advisory，照 sector_nodes 先例），消每日手动回填。

状态机判据（预登记 §五原文，不做口径改写）：
- →主升：节点∈{brewing, fermenting, mainline}，或空间龙一续板晋级/创高度新高
- →转弱：空间龙一断板（leaderState=broken，开启 3 日观察窗），或节点∈{weakening, collapse}
- →弱转强：§4.4 事件命中（P1 leaderRebound/benchmarkAdvance，新龙再崛起）
- →终结：观察窗满（窗内无①②事件）且当日节点=ice（裁决 7：N=1 即终结；
  collapse 不触发终结，板块停留转弱态）
