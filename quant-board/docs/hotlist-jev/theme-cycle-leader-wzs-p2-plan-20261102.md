## 一、P2 范围（四块）

1. **显式周期状态机**（裁决 3 核心）：每板块（×轨）一个当前态，词表
   `主升 mainrise / 转弱 weakening / 弱转强 wzs / 终结 terminal`；
   输入=sector_nodes 节点序列 + P1 事件流 + 龙一结构事实，确定性、零 token、
   全历史可回填；每次迁移落痕（from/to/触发证据/日期），无证据不得迁移。
2. **龙头判定与【题材龙头】打标链同源对账**（v2 新增）：状态机的「空间龙一
   断板/续板晋级」事实不再有第三套来源——回填走 `day_leader_rows(space_mode)`
   重算（`rank_board_stocks_seal` v12 复合键，与打标链同源），增量直接消费
   台账 `hotlist_jev_theme_leader_labels` 行内结构事实（唯一键
   `(tradingDate, board, segment)`，v12 §2.2），双轨对账漂移 fail-visible。
3. **日内弱转强疑似层**（裁决 3/6）：KPL socket（3006）触板判 + 盘口封死
   proxy，盘中三态显式（`未触板 / 触板未封 / 疑似封死`），疑似永不计完成态；
   盘后 THS 池复核，疑似未确认保留原态+显式回退痕迹。
4. **前端展示（以【题材龙头】台账为主载体）**：
   - rv-themes 台账表新增「周期状态」列（板块×轨四态徽标）与「新龙事件」
     标记（`leaderRebound` 命中=该行龙一即新龙再崛起，与台账结算列
     `outcomeSealedNextDay` 天然互验：反包完成态=次日续板）；
   - 状态机四态与 jev「题材深度三层」（igniting/fermenting/climax/ebbing，
     v5 题目集）**并列披露不互相覆盖**——结构态=节点+事件确定性事实，
     jev 层=语料叙事判断，同一板块两个语义词各说各话（与预登记 §五
     「wzs 节点 vs 弱转强状态」同原则）；
   - 盯盘清单窗位徽标（P1 已有）不动；rv-nodes 板块节点视图不加列
     （状态机消费节点，不反向污染节点视图）。

附带（评审遗留）：`build_and_save_leader_wzs` 挂盘后定时步（schedule.py
advisory，照 sector_nodes 先例），消每日手动回填。

状态机判据（预登记 §五原文，不做口径改写）：
- →主升：节点∈{brewing, fermenting, mainline}，或空间龙一续板晋级/创高度新高
- →转弱：空间龙一断板（leaderState=broken，开启 3 日观察窗），或节点∈{weakening, collapse}
- →弱转强：§4.4 事件命中（P1 leaderRebound/benchmarkAdvance，新龙再崛起）
- →终结：观察窗满（窗内无①②事件）且当日节点=ice（裁决 7：N=1 即终结；
  collapse 不触发终结，板块停留转弱态）

## 三、与【题材龙头】的整合细节

1. **龙一身份零新增口径**：P1 已同源（`day_leader_rows(space_mode)` 内部
   `rank_board_stocks_seal` 复合键=打标链同款）；P2 状态机继续消费该行，
   不出现第三套排序。
2. **状态机结构事实双轨**：
   - 回填（历史）：重算 `day_leader_rows(space_mode)`（零 token，同 P1 回填范式）；
   - 增量（生产）：直接读台账 `hotlist_jev_theme_leader_labels` 行内结构事实
     （唯一键 (tradingDate, board, segment)，v12 §2.2 不变式）；
   - 对账：重算行 vs 台账行的 code/streak/leaderSealedToday 不一致 → 落
     `cycleReconcileGaps` 披露（不静默、不二选一覆盖）。
3. **事件与台账结算互验**：`leaderRebound`（P1，收盘封板确认）⟺ 台账行
   `outcomeSealedNextDay=true`（同股次日续板）；不一致入对账披露——两条独立
   链互为校验，不合并口径。
4. **前端并列原则**：台账行内「周期状态（结构）」与「深度三层（jev 叙事）」
   各自徽标独立展示，颜色语义互不混用；分歧日不加任何仲裁标记（仲裁属用户
   人眼与 P3 叙事层）。
5. **日内疑似只进盯盘清单**（Q5 待裁决确认）：台账是盘后结算语义，日内疑似态
   不进台账行，避免「疑似」污染结算语义（裁决 6：疑似永不计完成态）。
