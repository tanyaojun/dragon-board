# C9 深谷出手操作规范 v1（2026-10-03 冻结版）

**性质**：实验性信号的小仓试运行规范。C9 晋升门未过（11 样本胜率 45%<67%），本规范是"研究性执行"的纪律框架，不是已验证信号的操作手册。
**证据标注**：✅=两窗以上数据验证；⚠️=单样本/方向线索；📋=个人风控自设（无数据标定）。

## 一、信号识别（每个交易日收盘后，盘后链自动+人工确认）

1. 18:00 盘后链 `deepValley` 步自动写账本（phase_monitor kind=c9）；打开 JEV 叙事→温度计页签人工复核；
2. **出手节点**：EOD 收盘 **<25**（✅ 三日反弹 7/7、均值 +43.2；交易代理 3/4 胜）→ 次日为出手窗；
3. **观察节点**：EOD **25-30**（⚠️ <30 整体 14/15 反弹但交易代理 5/9）→ 只轻仓试探或放弃，有断层佐证（温度计琥珀卡⚡）加分；
4. 频率预期：<25 约 1.2 次/月、<30 约 2.5 次/月——**没出现就是没机会，不找机会**；
5. 不可行项（已证伪，勿尝试）：T-1 特征预测谷（A/B 条件精度 1/16）、模型判段（四轮不过线）。

## 二、次日执行（出手窗当日）

1. **不集合竞价挂单**（高开组的唯一不亏买点在竞价，但机器同抢、好票抢不到=不可执行）；09:35 前只看不动；
2. **候选池**（✅ 双条件）：冰点日**首板堆积**（当日首板股，如 9/4 的 31 家）∩ 次日 **低开/平开（开盘涨幅 <+2%）**——两条都满足才进池；
3. **回避清单**（✅ 12/12 全负）：开盘 **≥+2% 的一律不碰**（机器扫板+冲高回落集合，均值 -5.21%，含高涨期）；跌停/大幅回撤票不碰；
4. **选票质量过滤**（⚠️ 单方向线索）：有 jev 标签时回避 concept_assembly（强势日组装股 0% 续板/-3.18%）；热榜非板层真催化类（重组/订单）优先观察；
5. **时点与分批**（✅ 路径多日上午弱下午拉起）：09:35 后观察，**上午回踩分 2-3 批进**（如 10:00/10:30/11:00 各批）；全天未回踩不满额，**14:30 后不追**（尾盘进均值 -0.41% 最差）；
6. **分数跳档不追**：反弹日常见 EOD 直跳 60+（9/4→9/7 62.4），当日按 C7 阶梯 60+ 三成档走，节点仓不加码。

## 三、持有与退出（✅ 窗口纪律）

1. **持有窗 = 3 个交易日**：EOD 反弹 +18~60 分、池代理正收益全部集中在 3 日内——T+3 收盘**评估兑现**，不自动展期；
2. T+3 评估规则：达到目标兑现；未达但情绪分已回到 40 上方→兑现离场（节点仓逻辑完成）；深亏票按 📋 个人止损线执行（**止损阈值无数据标定，登记待研究**）；
3. **40-60 禁入对节点仓不开例外**：只在 10-40 窗内的票可做节点仓，防节点变追高（C7 裁决不动）。

## 四、仓位框架（与 C7 阶梯的关系）

1. 阶梯档位是节点仓的**上限**：深谷日常在 10-40 带（次日阶梯=满仓档），节点仓总幅度 ≤阶梯档位，**分 2-3 批构建**；
2. 单票/单批幅度 📋 自设（建议单票不超过节点仓的 1/3，池内 3-5 只分散）；
3. 节点仓与 C7 常规仓**分开记账**（C9 账本 vs 脉拍台账），晋升评估互不污染。

## 五、市况门控与降级（✅ 三重市况依赖证据）

1. 市况事实（用户锁定）：7=杀跌、8=冰点震荡、9=弱修复、4-6=高涨——**幅度预期按市况打折**：低开组反弹 退潮期 +2.26% vs 高涨期 +0.64%；
2. **连续失效降级**：出手节点连续 3 次（跨月）未兑现 3 日反弹 → 暂停执行等复检（冻结协议）；
3. **单边阴跌月**（如连续深谷但反弹<10 分连续出现）= 信号失效的实时征兆，第二次失效即触发上一条；
4. 10 月起逐月复验：deepValley 步自动入账 + 月底人工复盘（市况标注 + 两臂对比：未过滤 vs 低开过滤）。

### 5.1 改进候选登记（2026-10-04 用户裁决：先登记意向，F2 数据后定）
