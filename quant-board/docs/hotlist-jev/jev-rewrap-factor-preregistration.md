## 1. 结论先行

| 问题 | 结论 |
| --- | --- |
| 反包因子现在的覆盖面？ | **个股级有、市场级缺位**：①弹药 7 板序行对个股自动打标「断板反包」（final 口径）；②relay 三日链 fate 对「昨日炸板→今日回封」逐股点名（10-16 修复）；③**市场级聚合（家数/比率/分位/盘中口径）全线缺失**——relay_phase 的「弱转强/方向逆转」判据引用了语义但语料没给任何反包锚，属「判据引用 ↔ 语料未供给」空洞（与 v3.2 盘点 §3-③ 同族）。 |
| 反包股值得单列吗？ | **值得**：105 日实测，隔日反包股次日晋级率 **20.1%**，同日首板基准 **15.8%**（+4.3pp）；炸板回封股晋级率 **23.1%** vs 基准 16.6%（+6.5pp）。反包是涨停人口里承接质量显著更高的子群。 |
| 直接把「反包家数」加进指数行不行？ | **不行，裸计数强共线**：corr(反包数, 当日涨停家数)=**0.684**——涨停多的日子反包自然多，裸计数进叙事会被广度吸收、进评分会与 ztCount 维双重计权。必须用**比率口径**（分母归一）。 |
| 那该用什么口径？ | 预研胜出：**反包率 rewrapRate = 昨日断板候选今日反包数 ÷ 昨日断板候选池**（候选池=前 5 交易日在板且昨日未板），中位 5.5%；与**当日 relayIndex corr=0.527**（强于裸计数 0.437），与次日连板晋级率 corr=+0.176。辅口径：**回封率 sealRate = 昨日炸板池今日回封数 ÷ 昨日炸板池**，中位 7.7%（覆盖 86/105 日）。 |
| 能预测次日情绪吗？ | **当日状态刻画强、次日预测力弱且不稳**（rewrapRate vs 次日 relayIndex corr=+0.08；次日涨停Δ率 −0.36，与广度高位混杂）。因此本轮定位：①**先作 relay_phase/relay_momentum 的语料锚**（「方向逆转：昨日弱今日明确修复」目前无原料）；②次日预测力按 §6-R3 单独立研究（分相位条件化），过门才谈入分。 |
| 盘中（12:30）口径可行吗？ | **数据在、历史薄**：`{date}:midday` 真午盘名单自 10-21 才有（10-20 是收盘补写），盘中口径**只能前向采集**，不可历史回测。盘中哨兵建议纯计算展示（零 jev 调用），先积累 15 日样本再裁决是否盘中打分。 |

## 3. 口径定义（单一事实源）

```
断板候选池(D)   = (ZT(D-2) ∪ ZT(D-3) ∪ ZT(D-4) ∪ ZT(D-5)) − ZT(D-1)
                  （近 5 日在板、昨日未板——「昨日应封未封」的观察池）
反包家数 fb(D)  = 断板候选池(D) ∩ ZT(D)
反包率(D)       = |fb(D)| ÷ |断板候选池(D)|            # 主口径，池空 → 不可算（fail-visible）
回封率(D)       = |FAIL(D-1) ∩ ZT(D)| ÷ |FAIL(D-1)|    # 辅口径，昨日炸板池缺失 → 不可算
盘中反包触板数  = 断板候选池(D) ∩ ZM(D)                  # ZM=午盘名单（触板口径，12:06 快照）
盘中反包率(D)   = 盘中反包触板数 ÷ |断板候选池(D)|
分位            = 各率近 20 日序列分位（anchor_lines 同法）
```

边界与陷阱（预研实证，防误读）：

1. **禁用裸计数做跨日比较**（corr 0.684 共线）；叙事行给家数仅供绝对规模感知，跨日比较一律用率。
2. 反包 ≠ 全部弱转强：昨日停牌复牌股会落入候选池（TDX 无棒与断板同形——relay 真连板口径
   同款陷阱），行内标注「候选池含停牌复牌 k 只（不可验）」，不单独剔除但不冒充。
3. 午盘名单口径=**已触板**（非封板）：盘中反包率是「触板口径」，与 EOD 封板口径不可直接比，
   行内/卡片必须带口径徽标。
4. 北交所 920xxx 无 THS 池/日线结构性缺口：按现有 relay 池口径自然落「不可验」，如实注记。
5. 池与名单取数一律复用 relay 现有函数（`_pool_of` / `_ths_pool_items` / ZT 名单读取），
   禁建第二套取数实现（单一事实源）。

## 5. 与情绪指数判据的对接（判据是否改动 = 裁决项）

relay v7.1 三题与反包语义的对账：

| 判据原文（现冻结） | 反包行能供给什么 |
| --- | --- |
| `relay_momentum.reversing`「昨日弱今日明确修复（主要指标跨过昨日水平带）」 | 反包率较昨日/近 20 日分位跳升 = 断板池被资金重新捞起的直接计数 |
| `relay_momentum.accelerating`「炸板面收敛」 | 回封率 = 昨日炸板今日修复的家数比率（现只有当日炸板增减，没有修复视角） |
| `relay_phase.launch`「首板堆积…晋级率尚低但断板亏钱与炸板面可控」 | 断板候选池规模（昨日断板总量）+ 反包率（亏钱是否被承接） |
| `relay_phase.divergence`「高位分歧…炸板面恶化」 | 反包率低位 + 候选池放大 = 断板无人接（恶化）的量化注脚 |

**建议（裁决 1）**：先**纯语料**——反包行进叙事，判据一字不改（`QUESTION_SET_VERSION_RELAY`
维持 v7.1），跑 15 个交易日后按 relay_momentum=weakening→reversing 翻转日的叙事引用情况，
再裁决是否线化判据升 v8（对齐 v3.2 裁决 6A→B 的两步走纪律）。

## 8. 验收门

1. **G1 供给率**：近 20 个交易日重放，反包行非 fail-visible 率 ≥95%（池空/池缺失日如实注记）。
2. **G2 对账零偏差**：反包家数/候选池/回封率与源库逐值核对（独立只读脚本，≥5 日抽样）。
3. **G3 既有语料零漂移**：重放 5 日，relay v7 既有段落（段1~段6）与存档逐字一致
   （新增行除外）。
4. **G4 语义对账（登记非门）**：抽 15 日「反包率跳升日 vs relay_momentum=weakening→
   reversing/accelerating」交叉表，供裁决 1（判据是否升 v8）用。
5. **G5 盘中哨兵**：10-21 起前向 15 日，观察报告给「盘中反包率 vs 当日 EOD 反包率/
   次日情绪」三列；期间零打分零预警（纯展示）。
6. **G6（R3 结题门，预登记）**：偏相关 |ρ|≥0.25 且方向在 ≥3 个相位内一致、分位稳健
   （滚动窗内外同号）→ 才可提案入评分维；任一不满足 → 登记为「当日锚专用因子」结题。
