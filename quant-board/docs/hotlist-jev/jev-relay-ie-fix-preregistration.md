# relay IE 读口径修复预注册（v5，2026-10-17）

> 触发：诊断文档 `jev-relay-insufficient-evidence-attribution.md` 记录的四批 IE（相位 14 / 边际 8 /
> 梯队 3 / 钱效 42）归因结论 + 用户 2026-10-17 指令「请修复」。
> 本文是**执行前契约**：范围、决策点、影响面、验收、预算、回退。范围是「读口径与展示」修复，
> **不含**采集层回补（不可行）与判据重设计。

## 1. 背景（一句话）

四批 IE 的根因全在**原料缺口**（16 天旧采集 schema 的炸板池只有家数 / 3 天 15:00 帧未采 /
TDX 60 棒窗回放限制），但**读口径把「部分缺失」放大成「整段没有」**：炸板面整段不可算、
梯队整段缺失、钱效用 n=1 的「中位」充数、覆盖不足没有结构化标记。修的是放大环节（AGENTS §4.0）。

## 2. 改动清单

### 2.1 F1 炸板池旧 schema 家数级降级（`jev_label_jiuyan._ths_failed_counts` + `jev_relay_index.zhaban_face_line`）

- 新增 `_ths_failed_counts(db, date, dataset_id) -> (counts, found)`：读旧形态
  `limitSummary.thsPools.poolCounts`（`failed/rushing/drawdown`）+ `maxDrawdown/avgDrawdown`。
- `zhaban_face_line` 在 `_ths_failed_items` found=False 时回退家数级渲染（**不整段丢弃**）：
  `今日炸板面（家数口径·旧采集 schema：仅家数可算，个股级子项不可算）：炸板 N 家；冲刺未封 N 家；
  涨停股回撤榜 N 家（最大/均值回撤）；较昨日：炸板 a→b 家（±d）· 反复开板 不可算；分位不可算（历史含旧 schema 日）`
- **口径纪律（D1）**：跨 schema 的**家数级**对比允许（同字段语义：THS `failed` 家数），
  但必须带「家数口径·含旧采集 schema 日」标注；**个股级子项绝不跨 schema 编造**。
- **禁止**：用 `snapshot_records.payload.limitSummary.zhaban.count`（前端口径）冒充 THS `failed`。

### 2.2 F3 梯队字段级降级（`jev_relay_index.ladder_structure_line`）

- `market_metrics` 返回 None / ladder 空时，回退 `_jiuyan_ladder`（**不依赖 15:00 帧**）出桶，
  并沿用既有来源披露（`jiuyan_touch` → 「THS炸板池缺失，梯队按触板口径」）。
- 不改 `market_metrics` 的 None 契约（消费方 6 处，改契约面过大）；**D3 默认选最小改动面**。
- 连带：`梯队结构量化` 行在 3 个无帧日恢复出数；`盘面事实` 行仍 fail-visible（涨停家数确属不可得）。

### 2.3 F4 断板/溢价最小样本门槛（`jev_relay_index`）

- 门槛（**D2 默认**）：`covered ≥ 5` **且** `covered/n ≥ 20%` 才输出中位；否则改写
  `断板 N 只：样本不足（TDX 覆盖 k/n，门槛 ≥5 只且 ≥20%），今日表现不可作钱效依据`（**不输出伪精度中位**）。
  绝对门槛不可省：07-06 的 `1/1`=100% 会漏过纯比例规则。
- 同门槛用于：断板统计、隔日溢价、较昨日断板对比、三日链内同名统计。
- `relay_money_effect` instructions 增一句：样本不足/覆盖过低的中位数不得作为钱效依据（**判据显式化**）。

### 2.7 F6 叙事可复现性修复（执行中发现；不做则重判输入不可复现）

- `theme_ladder_lines` 的「驱动主类」原为 `max(set(drivers), key=drivers.count)`：`set` 迭代序受
  `PYTHONHASHSEED` 影响，**计数并列时跨进程漂移**——实测同数据两次独立进程构建 2026-09-07 叙事
  hash 不同（`383b870a` vs `46367a66`）。
- 改 `sorted(set(drivers), key=lambda x: (-drivers.count(x), x))[0]`（同数按名称升序）。
  已验证：两个独立进程对 09-07/10-16/06-24 的 hash 完全一致。
- 影响：v4 存量系列中 **16 天**叙事与现行代码不可复现（旧随机取值）；重判时一并修正。

### 2.8 F7 全市场跌停口径回填（用户 2026-10-17 追加：「先修这一条」）

**问题**（诊断 §9）：09-16 之前 93 个交易日里，84 天叙事写的是 250 只**采集池口径**跌停
（+4 天写「不可算」），系统性低估，且分位在池口径内自算：
- 07-13 池内 32 家 / 全市场 **177** 家（全市场中位 −4.17%、2245 只跌≤-5%）
- 07-17 池内 37 / 全市场 **203**； 08-19 池内 53 / 全市场 **128**

**根因**：东财跌停池只有**近 30 自然日窗口**（`market_dieban_pool._em_window_start`，窗口外不外呼），
行情快照兜底只服务当日 → 早期日回退采集池。

**改法**（离线，不需外呼）：新增 `backend/operations/market_dieban_tdx.py`，用**本地通达信日线**
（`vipdoc/<m>/lday/*.day`，32 字节定长）重算全市场跌停，由
`backend/operations/backfill_limit_down_tdx.py` 回填参考集合 `market_daily_limit_down`
（`source=tdx_local_bars`，**绝不覆盖 em_pool/快照**）。判定两道闸：跌幅达线（`is_limit_down_pct`，
与快照口径同规）+ **价格精确匹配**（`close == limit_down_price`）。

**精度**（17 个 EM 双源日实测）：仅跌幅闸偏差 +4.41（除权日假跌停/无限制新股/1 分边界）；
加价格闸后 **+1.65（+0..+4）**，远优于池内口径（−20 家量级）。残余：除权日价格巧合、
北交所目录缺口（`stock_names` 缺 920xxx 新段）、东财池剔除风险警示/退市股（项目 `limit_ratio`
无 ST 特判，与前端同规）。

**读口径同轮改造**（单一事实源）：`market_dieban_pool.SOURCE_LABELS / source_label()` +
`FULL_MARKET_SOURCES`（EM/快照/TDX）——叙事两处标签不再各写一份映射；序列列（`trajectory_line`）
按「全市场家族」逐日回退并在行尾列明实际用到的源（跨 09-15/09-16 窗口写「东财跌停池＋本地日线重算」），
仅真正无全市场源的格子才回落采集池并打 `*`。分位仍**严格同源采样**（源差 1.65 家不得混入分位）。

**0 与「取不到」分开**：有棒但无股跌停 → 写 0（真读数）；全市场无棒或当日有棒股数 < 峰值×90%
（读取窗边缘）→ 不出数、不写库（防静默少算）。

## 12. 「开长窗」执行（2026-10-18 追加；用户指令「先开长窗」）

**动因**：F5 只实现机制（D5 默认不启用），钱效 IE 仍 50/108、早期日「TDX 覆盖 1/N」——根因是
在线日线窗只有 60 根（诊断 §7）。

**方案偏离与理由（对 D5 的修订）**：线上 mootdx 长窗**不可用**——2026-10-18 实测
`offset=60/250/400` 全部返回 **0 根**（同一状态下 v5 重放的 58 天钱效数字却来自线上窗）。
故「长窗」改由**本地通达信 vipdoc 全历史日线**实现，线上降为回退：

| 项 | 改动 |
|---|---|
| `_daily_bars` | **本地优先**：`market_dieban_tdx.resolve_root()` + `read_lday(take=400)`（≈1.6 年全历史）；本地无该股文件 → 记 `_LOCAL_MISS` 后走线上回退（不铸造空棒） |

| 线上回退窗 | `_BARS_OFFSET_DEFAULT` 60 → **250**（`JEV_BARS_OFFSET` 仍可覆盖，下限 20） |
| 缓存键 | `("local", code)` / `("online:<offset>", code)`——防两种来源互相污染 |
| `_adj_prev_series` | 除权日程查询加**有界回看 45 链接**（见下） |
| 溯源 | 新字段 `barsSource`（`counts`/`localRoot`/`localLastBar`/`onlineFallbackOffset`）落 relay 文档，不入 prompt |

**理由（四条，均为已记录缺陷）**：①线上不可靠 → 同一历史日的证据取决于「重放那一刻外网是否通」；

（与 F6 同类确定性缺陷）；④与 F7 全市场跌停回填**同一数据源**（§1.2.1 单一事实源）。
**单调性**：`_close_pct`/`_bar_verdict` 均按**日期取棒**（`bars[date]`）→ 加长只增证据、不改已有数字。

**配套：除权日程外呼有界化**。`_adj_prev_series` 为窗口内**每个链接日**查一次百度除权日程
（akshare 无批量口），本地棒把窗口 60→400 后外呼放大 6.7×（实测单日重算卡在拉取
>18 分钟不返回）。消费方只用近端键（`_bar_verdict` 取 `adj.get(date)`、真连板回溯 ≤ 区间板数
（实测 ≤12）、位置/序列 ≤10 天）→ 加 `_ADJ_LOOKBACK = 45`（3.75× 余量），再远链接回退原口径
