## 0. 结论先行

1. **"中间板块"= 板块日竞价成交额 2–5 亿（中热档）**：可买封板率（非一字）最高 **19.6%** + 隔日溢价最高 **34.4%**，双优。
2. **纯封板率最大化会选中出货板**：封板率（含一字）随热度升到热板最高（热 25.7%、60 日过热板 **41.7%**），但过热板溢价仅 **12.7%**（60 日 **10.0%**）、一字占比最高。**最热板块在出货，冷门板块无人问津，甜区在中间。**
3. **个股同理**：竞价强度 top95（≥95% 限价）封板率最高 74.9%，但 **43% 是一字板（买不到）**；**mid50_95（50–95% 限价）才是可买封板甜区 42.5%、零一字**。
4. **联合最优组合**：中热 2-5亿 × mid50_95/top95 × **撤减** ≈ **47–49% 可买封板 + 40–42% 溢价**（n≈120；mid50_95 47.3% / top95 49.1%，hist 修复后口径）。
5. 9:25 可见选股（每板块竞价强度前三）方向成立但幅度温和：success 3.4%→4.6%（相对 +35%），最优排序键 **jj_ratio/jj_percent（竞价涨幅强度）> jj_amount（成交额）**。**秒板/封板时间/收盘涨幅盘后才知，9:25 不可用**——已落实。

## 2. 口径（单一事实源）

- 封板 = trial `percent ≥ 限价×0.99`（`percent` 缺位 → TDX 收盘补证）；限价按代码前缀（30/68→20、北交所→30、其余 10），ST 用 `stock_names` 名称修正（11 行）。
- 一字板 = TDX `open≥涨停价 且 low≥涨停价`（**T 字板保留**）；非一字封板 = 封板 ∧ 非一字（**可买口径**）。
- 溢价 = T+1 开/收 vs T 收盘；缺 T+1 棒 → None 不进分母（不伪装 0）。
- 板块 = jiuyan root 粗桶全链（`jiuyan_board.board_index` → `bk_name` 桥 → 近 60 日打标分组兜底，与线上读口 `get_auction_trial` 同口径）；板块竞价强度 = 每日每板块 **Σjj_amount（试盘子集**，无试盘单股无此值）。
- 交易日轴 = 本地指数日历（sh000001.day）∪ 在线指数尾棒。
- **9:25 可见性**（勘察 §6）：`jj_percent/jj_amount/jj_turnover`（end_time 时点快照）、`first_add/last_amount/max_amount/first_amount`、`pre_percent`、`start/end_time` 可见；**`percent`=收盘涨幅、`seal_time`、`boards` 盘后才知，不可用于 9:25 排序**。`jj_*` 是 end_time 快照非统一 09:25 冻结值（早撤股反映撤单时点匹配）。

### 2.1 强度计算公式与量纲

两套强度**量纲不同**：个股是归一化强度比（无量纲 %），板块是绝对成交额（元）。

**个股竞价强度 = 竞价顶板强度比 `jj_ratio`**（单源 `auction_trial_base_rate_eval.py::tier_jj`；正式脚本 `r["jjtier"]=bre.tier_jj(r)` 复用；纯函数 `jj_ratio` 在 `auction_strength.py`）：

```
jj_ratio = jj_percent / denom × 100
denom    = pre_percent  若 PRESEAL（pre_percent ≥ limit×0.99，昨涨停）
           limit        否则
```

- `jj_percent` = 竞价匹配涨幅，**百分数单位**（解析 `_cell_val` 对 `_PCT_KEYS` 做 rank×100，上游 0.0954→9.54 即 +9.54%）；`denom` = 限价（10/20/30，ST 5），同百分数。
- 含义：竞价匹配价“吃掉限价涨幅的百分之几”。10% 板匹配 +9.54% → 95.4（近顶板）；匹配 +5% → 50。
- 分档（左闭右开）：`top95` ≥95 / `mid50_95` [50,95) / `low_lt50` <50 / `no_ratio`（jj_percent 缺或 denom 0/缺，不进档）。
- denom 分两种（bre 原注）：PRESEAL 用 pre_percent 兼容 ST（昨涨幅 5%、限价已修 5%）；非 PRESEAL 昨涨幅任意（如昨 +3%），用 limit 防比值污染。

**板块竞价强度 = 板块日竞价成交额 `board_amt`**（单源 `auction_strength.py::board_amt`，评估脚本与第三源选龙共用）：

```
board_amt(date, board) = Σ jj_amount   （该日该 root 板块内全部试盘股）
jj_amount 缺值 → 按 0 计入（fnum or 0.0）；board 空 → None → 未分板块
```

- `jj_amount` = 竞价成交额，**元单位**（解析对 `_AMT_KEYS` 取 rank 原值，1398万=1.398e7）。
- 分档 `board_tier`（单源 `auction_strength.py::BOARD_TIERS`，左闭右开，元）：冷 <5e7 / 温 [5e7,2e8) / 中热 [2e8,5e8) / 热 [5e8,1e9) / 过热 ≥1e9 / 未分板块 None。

**口径警示**：
1. 量纲不同：个股归一化（除以限价，跨 10/20/30% 板可比）；板块绝对求和（未按家数/市值归一，大板块天然偏高——但板块试盘家数梯度弱，非强混淆）。
2. 板块和是**试盘子集代理量**（只累加上过试盘榜股，非全板块竞价成交额）。
3. 缺 jj_amount 按 0 计入板块和 → **低估**该板块强度（与个股档“缺值不进档”的 fail-visible 处理不同，求和聚合取舍）。
4. `jj_*` 为 end_time 时点快照，非统一 09:25 冻结值（早撤股反映撤单时点匹配）。
5. 档位边界（板块 2-5亿/5-10亿/10亿、个股 50/95）为 100 日描述性拟合，非理论推导。

## 9. 规则档 spec（供打标链落地，未改生产）

- **板块档**：主力甜区 **中热 2-5亿**；备选 温 5000万-2亿；**热/过热降权或剔除**（出货）；冷剔除（无人问津）。
- **个股档**：主力 **mid50_95**（可买、零一字）；top95 须配一字标记后才用；low_lt50 剔除。
- **姿态**：优先**撤减**。
- **目标函数**：用"非一字封板率 + 溢价"联合，**不要用含一字封板率单目标**（会选到出货板）。
- 9:25 可见性：板块 Σjj_amount、个股 jj_percent/姿态均竞价可见；一字用 `jj_percent≥限价×0.99` 近似标记。
- **公式与量纲见 §2.1**：个股 `jj_ratio`（归一化强度比）vs 板块 `Σjj_amount`（绝对额）；落地注意板块和缺值按 0 计（低估）、试盘子集代理、end_time 快照三点口径取舍。
- 现有链是「推送 ∪ 韭研龙桶」双源；本方案是**第三源（竞价强度板块前三）**，宜作并集补充而非替换，保留 `selectionSources` 留痕。

## 10. 局限

- 档位边界是 100 日**描述性拟合**，非前瞻保证；落地须预登记 + 样本外验证。
- 板块热度=试盘子集 Σjj_amount；`jj_*` 为 end_time 快照；board 用当前 standing 快照回推历史（hist 兜底对早期日轻度前视，仅影响归属非结局）；14.5% 传统行业未分板块。
- 人群限「上过试盘榜（涨停价试盘单准入）」个股，不可外推全体涨停股；未复权；区间板数为 N天M板口径；逐日波动大未控情绪周期。
- 6 例封板口径分歧（0.5%）按 trial percent 权威保留；11-13 的 9 只待 T+1 结算（自愈式重跑）。
