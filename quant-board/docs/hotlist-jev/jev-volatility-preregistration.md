## 三、计分口径（冻结）

- **calm 对** = |T+1 收盘涨幅| < 5%；
- **swing_up 对** = |T+1| ≥ 5% 且收涨；**swing_down 对** = |T+1| ≥ 5% 且收跌；
- insufficient 不计分；基线 = **全押 calm**（胜率=当日平静占比，中位 ~66%）；
- 核心指标四件套：**总胜率**（对基线 +pct）、**大波动捕获精度**（swing 判读中真 |≥5%| 占比，
  无技能基线=当日自然占比 ~34%）、**大波动召回**（真大波动股中被判 swing 比例，防全 calm
  刷分）、**假警报率**（判 swing 但实为平静）。

## 四、判据设计要点（v5-volatility 题集，开火前冻结全文）

八块读法锚全部转向波动语义（原料不变，问的问题变了）：

| 块 | 波动读法 |
| --- | --- |
| 序列 | 跳变标记/连跌终止/分位极值（99+ 或 <20）= 波动前夜；平稳序列 = calm 证据 |
| 位置+板序 | 封板收盘/断板/连板高度突变 = swing 强证据；板序全 ○ 平稳 = calm 证据 |
| 量价+板型 | 量比 >2.5 或 <0.6（异常量能）、净占比极值 = swing 证据；量比 1 附近 = calm |
| 市场 as-of + 摆动锚 | 市场极值位（峰值/谷值）= 全池波动放大期（先验 42-51% 日）；中位 = 平静期 |
| 换手/流通市值 | 高换手小市值 = 高弹性 swing 倾向 |

方向半题（swing 内判 up/down）：当日方向延续性 + 位置（低位启动偏 up、高位断板偏 down），
预期这段仅 55-65% 准确率（受消息面主导），如实冻结预期。

置信锚沿用四类证据块同向计数（v4-material-b 的⑦条款，已验证可执行）。
