## 2. 结果裁决（谁对？）

33 个交易日中 21 天（63.6%）尾盘规则档=退潮——窗口本身是退潮市，规则的"启动"多为**盘中反弹操作标签**。

以 10:30 槽为决策点、当日尾盘是否首次转退潮为结果：

| 分组 | 转退潮率 |
|---|---|
| rule=发酵（n=4） | 50.0% |
| rule=启动（n=16） | 37.5% |
| rule=退潮（n=13） | 0.0%（已退潮不重复计） |
| rule=启动 且 jev=retreat（n=26） | 23.1% |
| rule=启动 且 jev≠retreat（n=7） | 28.6% |
| retreat_eod>0.5（n=4） | 0.0% |
| retreat_eod≤0.43（n=23） | 30.4% |

- jev 的 retreat 判定在规则"启动"槽内**无区分力且方向相反**（23.1% vs 28.6%）；
- retreat_eod 概率与实际转退潮**负相关**（概率越高越不退）；
- temperature 与次日晋级率非单调（<30 组 0.593 / 30-50 组 0.962 / >50 组 0.721，样本 19/7/4）；
- heating_30m vs 下一槽炸板率变化 Spearman=-0.137（n=71，近窗子集）——无有效前瞻。

## 3. 根因分析

1. **口径错位是结构性的**：规则五档是操作决策标签（含"修复初期即启动"的宽松语境），jev 按市场全景
   （负指数+高炸板+冷却桶占优）输出"退潮"，两者语义空间不同，criteria 文字对齐无法弥合。
2. **jev 的强项与弱项**：强在"给定明确文本/清晰问题"（阶段 0 验证）；弱在"从结构化数值自行归纳
   市场状态"——数值 state 的信息密度不足以激发其判别力，输出退化为窄带常数。
3. 样本局限：市场状态分布偏斜（窗口 63.6% 退潮日），heating 高分组 n=0，多组样本 <10。
