## 二、三读数口径

### 2.1 盘中家数对比（缺口 2）

- 行：连板行情板块目录表新增「封板 今/昨」列，`N / M` 着色（今≥昨=红=收盘家数增多博弈
  确认的盘中信号；今<昨=绿=家数未跟上）。
- 今封 = KPL `zt_stocks` WS 事件按 plate 顿号归属聚合（`KPL.ztCount` → 归一索引
  `ztCountNorm`），**一票多板块各计一次**（KPL plate 口径）。
- 昨封 = 韭研档 `sector-nodes` 行 `count`（韭研 board 口径）。
- 两列口径不同（KPL plate vs 韭研 board），tooltip 如实并列，不做换算。

### 2.2 核心票集体翻红率（缺口 3）

- 定义：`compute_pulse` 每板块新增 `strongN / strongQuotedN / strongRedN / strongRedRatio`。
- 子集：**昨日连板 ≥ 2** 的板块成员，连板高度单一事实源 =
  `jev_label_jiuyan.jiuyan_streak_map(db, prev_date, dataset_id)`。
- 口径：与 `_pulse_stats` 全体红盘率同（`price/last_close − 1 > 0` 计红盘）。
- fail-visible：streak_map 不可考（异常/空）→ 子集空、字段全 None，不铸 0。
- 展示：红盘率列 tooltip「核心票（昨日连板≥2）翻红 X/Y（Z%）· 强势股集体翻红=方法论信号」。

### 2.3 成交额量级分位（缺口 5）

- 定义：`_amount_sum_history`（近 60 个交易日当日 `aggN10.amountSum` 序列，THS 池缺失日
  如实缺样本）→ `_amount_pct(hist, amountSum)`：`min_n=20`，样本不足返回
  `(None, n)`；`below/len` 经验分位。
- 口径诚实：历史样本=全天累计额，盘中实时额对比全天分位**早盘天然偏低**，tooltip 标注。
- 展示：量能 tooltip「成交额 X 亿（60 日分位 P93·重注级）」，仅 `P ≥ 0.9` 标「重注级」。

## 三、板块名录匹配诊断（板块对比页）

### 3.1 读口

- `GET /api/hotlist-jev/sector-name-check?date=`（`backend/operations/sector_name_check.py`，
  纯读零写入零模型调用）。
- 韭研侧：当日 `jiuyan_action` 档 fields（final 优先、midday 回退，与 jiuyan-action 读口同
  回退哲学）。
- KPL 名录：**当日板块排行全量**（`kpl_ranking_service.get_sector_ranking`，241 板块量级），
  不是「今日有涨停事件的 plate」子集（封板归属口径 ≠ 名录口径，用户裁决纠偏）。

### 3.2 匹配规则（单一事实源 = theme_event_digest）

1. 行政桶单列（`is_not_a_theme`，原始名+归一名双口径）：公告/其他/ST板块等本来就不映射，
   `excludedBuckets` 透出、不进未匹配统计；
2. 归一（`normalize_name`：去空白/括号/分隔符 + 剥后缀）后 KPL 名建归一索引；
3. 等值命中分级：同名（same）/ ALIASES 别名（alias）/ 经济/产业后缀桥（suffix）；
4. **双向包含**（contains，len≥2 防单字误伤）：与 `match_industry` 同哲学。真实对照实证：
   韭研「医疗医药」↔ KPL「医药」包含但非等值，等值-only 会漏；
5. 反向覆盖：KPL 名归一后与任一韭研匹配键等值/双向包含 → 已覆盖；未覆盖清单（237/241 量级，
   KPL 细分名对韭研粗桶天然大量未覆盖）如实计数透出，不静默省略。

### 3.3 真实基线（2026-10-30 韭研 final × KPL 241 板块）

- 题材板块 5：同名 2（机器人→机器人概念、商业航天）+ 别名 1（AI硬件→算力）+
  双向包含 1（医疗医药→医药）+ 未匹配 1（大消费：KPL 仅「消费电子」细分，无同级消费桶，
  名录事实非漏配）；
- 行政桶排除 3：公告(34家)/其他(7家)/ST板块(2家)；
- 测试：`tests/hotlist/test_sector_name_check.py` —— 真实档回放（test 库由生产库
  mongodump→mongorestore 全量复制，源库快照归档 `data/backups/mongo-quant-snapshot-20261101/`；
  KPL 排行归档回放 `data/backups/kpl-sector-ranking-20261101/`），零上呼零 mock。

## 六、V4-G 盯盘票清单（缺口 4，同日实施）

### 6.1 方法论锚（第 5 课原文）

- 盯盘核心票 = 板块炒作过程中的**强势股自选**（随炒作周期滚动，非单日快照）；
- 盘中用途 = 看自选强势股是否**集体翻红** → 博弈收盘板块涨停数增多（与缺口 3 同源：
  3 是聚合率，4 是个股明细）；
- 选股结构 = 龙头分档：连板领头羊 / 反包领头羊 / 20cm 领头羊。

### 6.2 口径（用户拍板 Q1a/Q2a/Q3a/Q4a，2026-11-01）

- **板块范围（Q2a）**：当日弱转强候选（`compute_pulse` candidates，昨日节点 ∈
  {weakening, collapse}）；
- **票资格（Q1a）**：①昨日空间龙一（`day_leader_rows(prev_date, space_mode=True)`，
  含断板反包候选、主板/双创 segment 分轨）②昨日连板≥2 的 N10 冻结成员（缺口 3 核心
  票子集展开）；龙一兼连板≥2 → 只保留 leader 角色；
- **角色标注（Q4a）**：龙一（含断板反包标记 `leaderSealedToday=False`）/ 核心；行带
  streak、segment、gain10；
- **报价**：TDX 实时（`_fetch_quotes`，60s 负缓存兜底），与 pulse 链同口径；不可考 →
  票 pct/red 全 None + reason 透出。

### 6.3 实现

- `compute_pulse` entry 新增 `strongCodes` / `strongStreaks`（核心票明细，缺口 3 展开）；
- `sector_pulse.get_watchlist(db, today)` + `GET /api/hotlist-jev/watchlist`（**仅当日**：
  盘中工具，历史日无盘中报价，重算会拿当前价错标读数，不提供）；
- `code→name` 单一来源 = 韭研档 stocks（昨日+今日，`_jiuyan_name_map`）；
- 前端独立页签「盯盘清单」（工作台导航）：组头=板块 + 今节点 badge + 核心票翻红 +
  量级分位 + 量比（缺口 2/3/5 读数同屏）；票行=代码/名称/角色/连板/板面/现价/涨幅/
  10日涨幅；60s 轮询（不接 WS：N10 成员未封板票不在连板订阅链）。

### 6.4 fail-visible

- 候选空 → `reason` 如实（非异常）；昨日 THS 池缺失 → `leaderReason` 透出，strong 票
  照常；报价不可考 → 票 pct/red 全 None；pulse 链不可用 → ok=False。

### 6.5 已知边界（如实留档）

- 「其他」行政桶若昨日节点 ∈ 候选节点集，会以候选身份入清单（pulse 链既有行为，
  本代际不改；是否排除待用户后续裁决）；
- 一票多板块（如 600261 阳光照明同属「其他」与「商业航天」候选）按 N10 成员口径
  逐板块入列，不跨板块去重。

## 八、语义桥（第 2 轮，2026-11-01 用户拍板）

### 8.1 问题

常规桥（same/alias/suffix/contains）是同名系匹配，覆盖不了两类真实趋同：
① 韭研「大消费」泛指桶 ↔ KPL 消费细分板块（一对多）；② 韭研「公告」事件桶 ↔
KPL「三季报增长」等业绩板块（非同名系）。

### 8.2 机制（`sector_name_check.SEMANTIC_BRIDGES`）

- **pan 泛指桥（大消费）**：成员清单互含匹配（KPL 归一名与成员词互含，len≥2，
  与 contains 同哲学），一对多（命中全部成员细分，如实全列）；
- **event 事件桥（公告）**：KPL 归一名含关键词即命中（模糊匹配，用户拍板非全词），
  关键词 = 增长/业绩/预增/扭亏；重组/中标/收购等事件型未收录，待后续裁决；
- 公告不再行政桶单列，参与桥匹配；桥未命中的行政桶仍单列；
- 反向覆盖同步：被桥命中的 KPL 板块从 uncoveredKpl 移除；stats 新增 semantic 计数。

### 8.3 成员清单来源（大消费）

- web 归类：申万大消费 9-10 个一级（农林牧渔/食品饮料/家用电器/纺织服饰/
  轻工制造/商贸零售/美容护理/社会服务，部分口径含汽车传媒）；
- 韭研档成分实证（2026-10-30 大消费 6 票）：古井贡酒/皇台酒业=白酒、泉阳泉=
  饮用水、阳光乳业=乳业、东方海洋=水产、浙江东日=商贸；
- 「消费电子」是科技属性不在成员清单，实测不误命中（测试钉死）。

### 8.4 真实结论（2026-10-30，钉在 test_sector_name_check.py）

- 公告 → 5 个：三季报增长/业绩增长/中报增长/年报增长/年报预增；
- 大消费 → 10 个：免税/农业/医美/家电/旅游/服装家纺/美容护理/零售/食品安全/
  食品饮料；
- 两桥落地后 unmatchedJiuyan 清零；KPL 未覆盖 237 → 222。
